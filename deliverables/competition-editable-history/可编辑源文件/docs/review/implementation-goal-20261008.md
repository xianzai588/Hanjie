# 焊接参赛交付目标与验收标准

本轮把现行8P-R2-t15主方案完善为匿名工艺设计说明书、分工序pWPS、制造检验卡、工程图和可用三维附件。当前提交入口为competition-entry；2026年10月8日论文格式交付包仅保留历史快照。历史计算保持原物理对象和状态。

## 验收标准

1. 工艺指令一致：实际焊长18 mm/翼/道，稳定有效16 mm/翼、128 mm/道；两道实际288 mm。稳定焊脚最低3.80 mm，对应等腰截面有效喉厚2.687 mm；实际最低喉部、双侧连续连接及段端单独验收。卸夹顺序、温度许可、气水和资源配置在正文、卡片、图纸中一致。
2. 制造可执行：补焊前壳体加工、A端面和B双测量带，明确基准提取、关键公差和位置度测量不确定度目标；浮动上驱动、球铰压环、保基准夹紧、转运锁止均有实际接口或标准件方案。
3. 屏障可执行：铜环、接料盘和退出保持现有有效工程依据；气水图落实抽吸及过滤接口、前后吹与漏水、缺气、失电、卡滞动作。无需CFD或扩展视觉算法。
4. 设计性能：首次及最终接头应有适用熔合与组织依据；完整制造残余状态不得清零。完全卸夹后在独立A/B基准下评价轴移、倾斜/包络、孔径及同状态承载。位置度预算保持28+2+6.5+13.5=50 μm；径向微珩去料上限3 μm。只有无去料且孔径直接合格时采用20 μm热分支。网格/时间工程精度≤5%，阈值附近同时检查物性和绝对余量。
5. 选型与生产：横向比较GMAW/激光外塞焊、激光深熔、微束等离子、脉冲TIG在共同连接、洁净、可达和产量约束下的取舍；小批供料3600 s、8件/班，462.5 s为焊接子程序；完整夹具循环至少702.5 s另加退出和温控延长，费用与资源按同一组织口径。
6. 提交可用：全部STEP为真实ISO-10303-21实体，PDF、图号、目录和引用一致；关键图缩印清晰，无排版溢出；正文、图名及元数据匿名。保留可编辑源与原始计算身份，不伪造实测图或记录。

文件成套与设计性能分别验收。性能通过只引用有效接头、制造及承载结果；未通过写具体超差、原因与实际修订，不能靠文案或附件数量宣布目标完成。

## 工作与计算边界

- 本轮只维护8P-R2-t15。圆环及6P保留既有对照，不启动新候选矩阵、材料矩阵、通用凝固/有限应变平台或代理排名。
- 先完成文件冲突、制造接口、选型及气水联锁，再把有限计算结果接入最终稿。
- 计算依赖顺序：热源/出生热容量适用性诊断 → 一个局部有效接头及可信冷态 → 实际去料/工序残余继承 → 一个最终完全卸夹主工况 → 同状态承载。未取得上游资格不运行下游。
- 该依赖只约束连续热—力制造计算。无实物路线允许从适用原始资料组合逐项证据，并独立完成截面、容量、接口与检测设计；同曲率实测、PQR和两点热循环是来源选项，不能设置为全部设计工作的唯一入口。
- 先由独立agent明确具体表示、输入来源、计算预算与停止条件，再运行。只作一个有原因的局部修订和必要独立离散对照。响应≤5%且足以决策即停；若需重造熔池运输、本构或接触平台，停止该表示并由独立审核给出有限纠偏，不扩大扫描。
- 不投入哈希、CI、重复全套测试或无关软件架构整理。验证只回答关键工程指令、数值适用性和交付可用性。

## 独立审核

每30分钟进行一次只读独立agent审查，并在模型适用性决定、核心结果冻结和最终提交前审查。审核检查是否改善官方五维评分、是否扩大工作、是否伪造通过、是否把实物错误设为参赛前置、源文件和交付是否一致。审核不并行修改主源，不自动重启计算。

审核自动化ID：automation。目标完成时删除该自动化；无变化时安静，仅通知具体偏离、失败、完成或需要用户输入。
