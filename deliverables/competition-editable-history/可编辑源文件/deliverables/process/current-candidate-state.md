## 制造状态顺序

壳外首层预制 → 缓冷和法向修整/首层PT → 第二层全部焊道完成 → 解除预制支承并缓冷至室温 → 起算≥24 h终端延迟PT → 连接面和孔精加工 → 清洗干燥 → 入壳定位和铜环屏障 → 对向低热组焊 → 带防护冷却 → 全部卸夹 → 独立基准测孔及最终PT → 有限孔径精整 → 干态洁净检查与封存。

计算中继承预制残余状态，仅移除实际加工材料并重新平衡；预制、孔加工及最终组焊按其真实顺序进行。设计文件按既有证据交付，实施试制按规程完成工程确认。
