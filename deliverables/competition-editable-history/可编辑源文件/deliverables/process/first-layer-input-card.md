# HJ-W-00D 独立高镍预制pWPS设计参数卡

本卡为试制工艺设计，适用QT450-10八翼座体在壳体外预制镍过渡层。先完成工艺评定，再冻结生产WPS。所列电压为工作弧压参考，逐道记录实际电流、电压、弧长、焊速及消耗量。

## 能量与供料核算

首层毛弧能1518.0 J/mm，以η=0.8工程系数核算净线能量1214.4 J/mm；该值由本卡输入守恒得到，原文献1215 J/mm参数锚的核读身份见C27。第二层以η=0.6核算247.5 J/mm。系数用于设计记账，实际截获与效率由适用依据限定。模型直接给定净热时，不重复乘效率；熔滴焓从同一净功率分配。

首层/第二层八翼弧燃92.6/154.3 s。首层最后1.2 s对应2.000 mm端区，净输入线性由2024降至1472 W，单翼净热23.08449 kJ、八翼184.68 kJ；第二层76.355817 kJ，其余作业另计。首层低供料I²情景1.916154 g/翼，体积等效余高0.45238 mm；原恒流基线1.966733 g/翼、八翼187.33 kJ保留作失败对照。第二层按新供货丝径、送进、焊速与利用率16角点得到新增体积131.441733～167.961640 mm³/翼；η=0.94名义沉积148.780881、名义最终存留78.685922，待齐平去除70.094959 mm³/翼。局部轮廓、双轨覆盖与连续熔合资格分别核查。

## 第二层采购与棒材送进决定

原厂实际列有0.045 in×36 in规格，本设计采用该规格并冻结来料直径1.123～1.163 mm。原TDS不公布尺寸公差；±0.020 mm是本设计采购验收要求，不是供方保证。既有9个STEP只读测得槽口最大投影115.168683 mm²/翼，以首层最低0.65到要求顶面1.75的整投影1.10 mm补高核算，总供料需求126.685551 mm³/翼。最低送进7.80、最高焊速2.04、η=0.90反算允许直径下界1.102495 mm；取负偏差0.020低于计算上限0.040505，保留4.756182 mm³/翼总量裕度。来料逐根测两端/中段及互相垂直方向，按1.123～1.163守界验收。总量裕度不赋予天然焊道余高资格。

每翼两条轨迹累计名义19.281772 s，净送进154.254176 mm；角点最大双轨消耗161.337276 mm。每翼一段180±0.5 mm棒，规定非消耗夹持余尾≥15 mm、前端修整2 mm及设备有效送进行程≥162 mm；最高消耗加余尾/修整合计178.337276 mm，小于最短179.5 mm备料棒，余量1.162724 mm。8翼8段，翼间离弧换棒安排在既有清理换翼预留内；这些是设计设备接口，现机夹持和换棒能力尚未核实。定长棒名义净备料1440 mm，计每段切口损失1 mm后1448 mm（备料公差上端1452 mm）。采购2根914.4 mm原规格名义共1828.8 mm、16.682084 g；每根分配4段，按上端棒长与切口需726 mm，来料长度验收≥726 mm，原TDS没有公布长度公差。名义余料380.8 mm可库存复用；本件保守成本按两根整棒计，旧名义15%备料不作为此次实际采购量。

Ø1.143名义截面积1.026082645 mm²；八翼净送进1234.033406 mm，名义消耗11.256698 g，η=0.94沉积10.581296 g。进入焓以既有1470℃纯Ni来料参考及NIST-JANAF Ni(ref)原表记账，20℃参考H=1.111526 MJ/kg；η=0.90～0.98时进入沉积焓11.260897～12.261866 kJ，从同一净76.355817 kJ中扣除，母材/熔池和损失余额64.093951～65.094920 kJ。全部供料角点来料功率68.708067～84.354929 W、495 W净功率余额410.645071～426.291933 W；正余额仅证明记账可分配。

本槽保持200～300℃预热薄层、短弧的75 A/11 V设计组合及247.5 J/mm热账，分别低于原TDS该棒径推荐下限5 A/2 V；11 V为实际短弧工作电压参考，须逐道记录。目录没有本槽边界和重熔量，不直接搬入目录热量，也不把本设计组合称为供方保证。该参数的实际截获、双轨熔合及重熔存留尚需适用输入验证；换尺寸后必须使用本次出生质量，不继承旧规格或越温域热史。详见studies/COMPETITION-DESIGN/results/second-layer-supply-decision-20261008.json及同名工程核算。

端部缓降采用可编程恒流电源和保持短弧的送进，弧压与消耗量连续记录。I²情景是末段供料计算输入，覆盖棒实际熔化还受棒体温度与药皮影响，不能宣称这一关系为CI-A1厂家标定曲线。以称量、端区轮廓和连续熔合核验后冻结操作窗口。原90 A/0.5 s候选在一致取时且末端时间减半后仍超温18.8℃；现按3.2 mm面内热扩散尺度提前至1.2 s，并采用产品下限80 A，没有提高模型温度上限。

首层当前一翼炉冷计算从入炉到工件最高温20.0493℃历时24300 s（6.75 h），其中包含2 h保温、3.6 h环境降温及工件热滞后。该历时用于前工序在制容量核算；八翼整件、第二层炉冷、转运和延迟PT按各自实际历时另计。按231.3/462.5 s供料间隔计算，这一工序分别至少需要106/53个在制位置，数值表示容量需求，不表示炉台数或已经实现的产能。

既有体热源及液相导热因子3输入下，八翼整件接续首层热末态完成同一炉制度计算：入炉至室温同为24300 s，温度20.04873～20.04998℃；这是热学场，尚无对应可继承的冷态机械状态。首道起弧至室温25994.302 s（7.22064 h），扩产对照按上述两种供料间隔需要113/57个在制位置；另计此前36 min预热则首层前工序链需122/61个位置。现行小批试制采用3600 s供料间隔，首层8位、第二层9位及24 h延迟等待24位，共41位；PT停留、人工装卸、清渣及转运另配置，见HJ-P-01及HJ-M-01。

## 工序交接与处置

1. 来料确认QT450-10、铁素体主导、珠光体≤20%、无原始白口网；去铸皮、脱脂并清除石墨涂抹层。
2. 首层要求形成连续覆盖和可切削余高，冷态按槽底法向修整到0.70±0.05 mm；压痕、夹渣、裂纹不得留在保留层。
3. 第二层完成后全部工作区至少高于实际槽底1.75 mm；齐平后总层1.40～1.60 mm。宏观截面在同一基准检查首次熔合、分道重熔和低碳层存留。
4. 起收弧区不自动计入有效长度。预制层与18 mm最终实际路径采用同一角度基准映射，两端各1 mm过渡排除后按16 mm稳定连接检查。若16 mm稳定区不能覆盖保留界面，修订首层覆盖、供料及末段控制；不把外缘实际18 mm扩写成20 mm，也不以削短稳定区回避熔合缺口。
