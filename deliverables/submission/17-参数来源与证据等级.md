# COMPETITION-R1 参数来源与证据等级

| 参数/结论 | 当前值 | 来源等级 | 对核心结论影响 | 口径 |
| --- | ---: | :---: | :---: | --- |
| 焊接电流 | 75 A | B | 中 | 工艺设计窗口；需 WPS/PQR 固化 |
| 电弧电压 | 12 V | B | 中 | 工艺设计窗口；非实测记录 |
| 焊速 | 1.5 mm/s | B | 中 | 工艺设计窗口；非实测记录 |
| 预热/层间 | 150 / 200 ℃ | B | 高 | 文献窗口低端与过程门控 |
| 电弧效率 | 0.55 | C | 中 | 能量模型假设，影响净热输入 |
| 沉积效率 | 0.85–1.00 | C | 高 | 守恒边界假设，按下界反算固定送丝 |
| 参考许用应力 | 60 MPa | C | 高 | 人工载荷筛查值，绝非焊缝真实许用应力 |
| 位置度热残余 | ≤0.008 mm | C | 高 | 设计目标，未由热—结构或实测闭合 |
| 胀套重复性 | 0.003 mm | C | 高 | 设计分配，未实测 |
| 测量扩展不确定度 | 0.002 mm（直径） | C | 高 | 能力目标，未认证 |

等级定义：A=当前项目内有独立可复核记录；B=公开资料/工艺窗口支持的设计输入；C=工程假设或设计分配。60 MPa 只用于条件筛查；任何文字、图表不得将其解释为材料或焊缝许用值。
