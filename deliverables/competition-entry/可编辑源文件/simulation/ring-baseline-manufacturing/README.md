# 圆环最终组焊：热过程与卸夹条件响应

本目录计算当前 `SUBMISSION-RING-20261008-R2` 的真实圆环最终热输入，并计算卸夹后对独立固有应变输入的冷态响应。已完成的数值证据用于决定温控、连接资格和控形输入；完整预制残余应力/塑性场尚未取得，不能把条件响应改写成完整制造通过。

## 工件与工艺输入

预制几何来自 `cad/generated/ring-baseline/ring-precoat-eight-windows-17solids.step`：QT 座体和八个 CI-A1 第一留层、八个 Ni99 第二留层。座体 R20～74.98 mm、z100～115 mm，壳体 R75～80 mm、高200 mm。两层保留各自实体和材料区，不以一片已融合材料替代。

| 项目 | 热过程输入 | 冷态支承输入 |
|---|---|---|
| 最终焊缝 | 两道、八段，每段实际20 mm | 八段最低有效连接18 mm |
| 焊脚 | 根道2.8 mm、最终包络4 mm | 最低有效焊脚3.5 mm |
| 焊序 | 每道1→5→3→7→2→6→4→8，单枪串行 | 完成后的有效连接几何 |
| 速度与净功率 | 1.65 mm/s、495 W，即300 J/mm | 不用温度峰值推定收缩 |
| 时间与能量 | 320 mm、193.939 s起弧、96 kJ；固定18 s待机设计情景 | 独立输入幅值100 με及组合扫描 |
| 界面 | 名义共享面共形节点；出生前界面为自由表面 | 名义有效接合面共享节点 |

预制—壳体间0.02 mm未焊径向间隙保持自由。核验实际壳内三角片在 z100～115 mm 的边上线段最小半径，而非仅检查节点或面心。当前热网格最小半径74.990945 mm，新安全冷态 coarse 为74.991663 mm；均大于座体最大半径74.98 mm，且座体留层与壳体无直接共享节点。几何连接是假定有效界面的计算输入，连续熔合须对应工艺断面取得资格。

## 热过程计算

`run_ring_manufacturing.py` 使用 P1 四面体温度场、温变导热/比热、显式潜热及按实际焊序出生的根道/盖道。输入焊材参考焓为20℃的零焓，出生新增质量的升温由495 W净输入承担。每个接受步保存输入、存储和环境损失的平衡及非线性残差；不裁剪温度、不清零高温历史。

源中心根道 r75/z115 mm 对应实际接头根部，与座体边相差0.02 mm；盖道有效源中心 z117 mm。高斯宽1.270170592 mm、深0.923760431 mm是明确登记的工程源形输入，盖道中心也不是机器人 TCP 或枪距指令。源功率在全部已占据金属体积（QT、第一层、第二层、NiFe、Q235）上分配并归一守恒，不局限于预先存在的焊缝体。

热边界为空气20℃、h=15 W/(m²·K)、发射率0.7，以及有有限热容量和水侧换热的铜环。金属—铜接触取50 W/(m²·K)。最后停弧后同时满足等待≥120 s和整件最高温度<55℃，产品才能离开留站铜环，关闭铜接触；这两个退出门从主yaml的 `fixture_feasibility` 读取。取首个满足双门的实际接受冷却步，本组退出为停弧后140 s。此后自然冷却至整件最高温度<21℃才记完整最终热循环。活动单元面采用所有者 XOR；已闭合的内部接合面不重复计算辐射/对流。

当前热网格62,486节点、247,346四面体。主组起弧步1 s；同一网格的首段以0.5 s、6000 J进行必要时间复核，峰温相差2.391%。固定18 s待机只是被计算的设计情景，16次起弧局部 Ni99 窗最高温度逐次登记；首轮保守按15～35℃筛查，第二轮按15～100℃，分别最高32.114578℃、46.162187℃。若窗口起弧不满足温度门，需按温度联锁增加实际等待，不能将全件温度或其它窗口温度替代该窗口起焊温度。

正确最终组焊主组完成16段/96 kJ，最后停弧 t=463.939394 s；退出留站工具为 t=603.939394 s、全场最高48.668031℃，符合≥120 s与<55℃双门；整件冷至<21℃为 t=2643.939394 s、最高20.999621℃。该冷却时间来自设定边界的计算，现场仍执行实际温度联锁。全场峰1421.769108℃、孔壁峰50.965208℃；QT/第一留层/第二留层/Q235/NiFe峰分别709.726/920.635/1104.979/1421.769/1421.769℃。Ni99与Q235峰未覆盖登记固相线1435/1474.85℃，当前工程源形不取得双侧连续熔合资格；不能将这个未标定源形的结果等同于真实300 J/mm工艺的物理失败。

热物性见每个结果的 `material_inputs`。CI-A1 第一层采用高镍工程热物性代理，Ni99 导热使用已登记的0.75倍端元敏感性输入；这些参数没有取得批次相图或实测源形资格。因此峰温不足以直接签认300 J/mm双侧熔合，也不能反推预制或最终残余收缩。

## 冷态响应与孔径

`cold_response.py` 解经典三维线弹性固有应变方程，只使用六个零反力坐标规范约束；胀套、压头、铜环等工装均不提供机械夹持。材料 E/ν 与当前圆环承载分析统一：QT 169 GPa/0.27，Q235 206 GPa/0.30，两预制留层与最终焊材200 GPa/0.30。留层和焊材模量为工程设计输入，不给其凭空分配已合格屈服/断裂容量。

六个实际计算模态为：最终平均收缩、最终一阶/二阶不对称、最终单段差异、预制留层一阶变化、预制单窗变化。预制模态表示最终过程引起的**非零留存固有应变变化**，没有导入完整预制残余应力/塑性历史，不能叫状态继承。平均收缩影响孔径，二阶模态影响失圆，一阶模态影响孔轴；三个指标一起报告。

| 100 με输入模态 | 位置度Ø/μm | 孔径变化 min～max/μm | coarse原始局部VM/MPa |
|---|---:|---:|---:|
| 最终平均 | 0.006361 | −0.063826～+0.090066 | 148.049 |
| 最终一阶 | 0.231877 | −0.004438～+0.002611 | 146.816 |
| 最终二阶 | 0.003424 | −0.039800～+0.038323 | 145.363 |
| 最终单段 | 0.058662 | −0.017805～+0.014105 | 141.894 |
| 预制一阶变化 | 0.281426 | −0.000492～+0.000576 | 59.322 |
| 预制单窗变化 | 0.071582 | −0.004259～+0.010498 | 59.904 |

主响应使用当前独立构建的安全 coarse：`simulation/ring-baseline-structure/results/p1-current-coarse-safe`，60,703节点/243,112单元，包含当前 STEP DATA、R2和支承输入身份。有限空间复核使用保留的安全 medium：112,771节点/472,391单元；该旧快照原始构建身份不可补造，明确记录快照路径/文件摘要，并核尺寸、材料体积、共享面和真实间隙。最新 builder 不将身份缺失快照当作其缓存。

medium三个关键模态的最终一阶、预制一阶孔轴响应与主档分别相差1.58%、2.00%；平均模态接近对称零值，孔轴绝对差0.004664 μm。原始局部应力峰仍相差21.45%、17.17%、13.16%，部分接近零的孔径分量也未满足5%；不作整体精度已收敛的声明。没有因此再扩展算例族。

组合窗口先叠加应力张量再算 von Mises，绝非单独模态应力峰相加。示例输入“平均100 + 最终一阶25 + 预制一阶变化25 με”得到位置度Ø0.132523 μm、孔径变化−0.064003～+0.090329 μm、组合原始峰187.904 MPa；其数学初始孔径区间为40.000064～40.024910 mm。这个点是带输入幅值的响应示例，真实工艺是否落入此处取决于经过资格确认的固有应变/残余状态。平均1000 με已对应约1.48 GPa线弹性峰，不能把数学轴线容许幅值当作工艺可用范围。

采样为A基准96点、B基准两截面96点、孔壁17×192点；同时取直轴拟合及截面中心包络，并列孔径变化。`conditional-window.csv` 保存120个输入组合的孔轴、孔径窗口及每种材料的组合应力。`material_feasibility_established` 与完整制造通过标记保持与资格证据一致。

## 复算与文件

Python依赖为 NumPy、SciPy、PyYAML、scikit-fem、PyAMG、gmsh、threadpoolctl、Matplotlib；主热组使用 pypardiso/Intel oneMKL。Linux gmsh 需要 libGLU/libXft。PARDISO仅复用未改变的稀疏图符号分析，每次数值矩阵变化仍重新分解，并独立核线性残差。

在仓库根目录、依赖可正常导入的环境下运行：

```bash
python -m pip install -e '.[manufacturing]'
PYTHONPATH=src python simulation/ring-baseline-manufacturing/run_ring_manufacturing.py --level coarse --dt 1
PYTHONPATH=src python simulation/ring-baseline-manufacturing/run_ring_manufacturing.py --level coarse --dt 0.5 --stop-time 12.1212121212121
PYTHONPATH=src python simulation/ring-baseline-structure/build_support_mesh.py
PYTHONPATH=src python simulation/ring-baseline-manufacturing/cold_response.py --level coarse
PYTHONPATH=src python simulation/ring-baseline-manufacturing/cold_response.py --level medium --key-only
python simulation/ring-baseline-manufacturing/assess.py
python -m pytest tests/test_ring_manufacturing.py
```

冷态主源网格由圆环结构目录的 `build_support_mesh.py` 当前安全 coarse 入口产生。保存于git的JSON/CSV/PNG直接可审查；安全 medium 的原始 `simulation/ring-baseline-structure/results/medium/mesh.npz` 是保留的不可补造快照，按结果所录文件摘要、材料、体积和实际间隙进行审核，复算中档使用此源。其他大体积NPZ为可复算中间数据，仓库忽略规则不提交这些数组，重新绘制完整场图需要先运行对应计算。

网格缓存检查 STEP 的 DATA实体段、当前工艺版本及尺寸/策略；HEADER导出时间变化不触发重建。输入不同即拒绝使用旧缓存，不将旧结果换版本名。热计算不加载已有结果代替求解；`assess.py` 拒绝不符当前版本/根部瞄准/实际间隙的输入。

## 诊断归档

`results/diagnostic-static-interface` 保存被淘汰的独立网格/罚连接结果。其根道提前采用盖道接合面积，且部分内部接合面重复计算环境损失；旧冷态连接罚刚度还随网格改变。这些结果均不进入当前 assessment。

`results/diagnostic-gap-penetrating-cold` 保存旧 coarse 冷态结果；其壳内真实片边最小R74.964547 mm，侵入名义间隙。新安全主网格替代此源，不把无共享节点误当成几何无交叠证明。铜保持至最终冷态的旧冷却支路，以及遗漏120 s最低等待的55℃单门支路，均另存诊断；只有满足≥120 s和<55℃双门后退出、再自然冷却的结果进入主热组。

固有应变方法依据经典焊接固有应变响应思想；输入校准需对应工艺与接头。可参见 [Yang, Welding Journal 100 (2021), DOI 10.29391/2021.100.013](https://s3.amazonaws.com/WJ-www.aws.org/supplement/2021.100.013.pdf)，其中热源与残余响应的实验/截面校准要求适用于本目录的输入资格。
