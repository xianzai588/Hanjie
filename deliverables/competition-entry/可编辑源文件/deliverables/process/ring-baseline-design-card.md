# HJ-S01 完整圆环基准与工序接口设计卡

## 1. 基准对象与采用理由

以完整 QT450-10 圆环作为本次参赛说明书的结构基准。圆环保留中心 Ø40 轴承孔，环体内半径 R20、外半径 R74.98、厚15；装配后底面 z100、顶面 z115。Q235B 机壳内半径 R75、外半径 R80、总高200，底面 z0。名义直径间隙0.04、单边间隙0.02，定心由独立工装与壳体基准完成。

采用完整圆环，使零件形态、孔加工、入壳装夹和检测对象先形成一套可阅读、可制造的基准。八翼开口方案另作结构减重与热应变传递调整的改进候选，其槽根、承载路径和独立预制仍有各自的设计任务。先完成圆环的参赛设计，能使改进方案的收益和代价有明确的比较对象。

| 项目 | 名义设计值 | 设计用途 |
| --- | --- | --- |
| 座体材料与几何 | QT450-10；R20～R74.98；厚15 | 完整环形座体，不设八翼开口 |
| 壳体材料与几何 | Q235B；R75～R80；高200 | 独立安装与检测基准 |
| 座体轴向位置 | 下表面z100、上表面z115 | 装配高度、夹具支承和焊枪可达性入口 |
| 名义直径/径向间隙 | 0.04 / 0.02 | STEP内无干涉；制造限值另按尺寸链规定 |
| 孔轴位置度要求 | Ø0.05，相对A、B | 冷却、完全卸夹后，在15 mm孔长内评价 |
| A基准 | 壳体下端独立安装平面 | 不取座体端面或夹具压环作为A |
| B基准 | 壳体内壁建立的轴线，按A定向 | 不以孔内胀套自身轴线代替B |
| 最终连接布局 | 8段×18 mm有效区；实际每段20 mm、两道 | 每道有效144 mm；两道实际320 mm；保持完整座体 |
| 周向顺序 | 1→5→3→7→2→6→4→8 | 对称分段输入，段间按温度控制 |

名义 Ø40 是本次实体的几何尺寸。焊前孔尺寸、孔径合格区间和尺寸链中的加工分配由共用制造检验卡确定；名义模型共轴不代替焊后位置度计算。Ø0.05 的既定预算不因换用圆环而扩大，焊后大余量镗孔不作为控形方案。

## 2. 材料层次与独立预制位置

设计材料链为 **QT450-10 → CI-A1类ENi-CI首次镍层 → 裸Ni系第二覆盖层 → NiFe系最终连接金属 → Q235B**。首次铸铁界面与最终精密组焊分别设计。

独立预制在座体最终孔加工和入壳之前进行。具体位置是**圆环外缘的待连接区域，在机壳之外处理**。这里的“壳外处理”指座体尚未装入机壳，便于预热、清渣、修整、检查和清洗；它不表示在壳体外壁进行塞焊。

首层用于建立铸铁与镍系层的首次连接；中间修整控制实际保留层；第二层提供后续连接的镍系工作面。第二层覆盖宽度需覆盖最终焊脚、焊枪偏差和重熔区域，最终接头同时核查QT首层界面、层间和Q235B侧的连续熔合。电弧扫过面积、名义接触面积与承载有效面积分别记录。

圆环采用八个局部预制窗，与最终八连接段同中心布置。窗口中心R71.98处弧长24±0.5，径向宽6.0±0.1，深1.50±0.10，名义内底圆角R1.5，外缘贯通R74.98。孔区与完整环体保持，槽下剩余QT厚度至少15−1.60＝13.40。有效连接18 mm、实际焊接路径20 mm，均位于预制窗内。

首层冷态修整按槽底法向保留0.70±0.05；名义内角修整半径R0.80。局部窗两端也保留至少0.70首层，第二层端部内缩，避免直接接触QT端壁。三轨覆盖所需的临时首镍保护带在内缘外延0.5、两端各延1.5，保留至第二层完成。外缘超出座体的部分由独立可拆铜背衬承托，完成覆盖和冷却后修整齐平；去除实际余料并保存相应应力释放状态。

预制成品名义STEP含1个切槽QT实体、8个首层实体、8个第二层实体，重读17实体全部有效，第二层与QT的有限面直接接触面积为0。母件总装STEP继续保持座体与壳体两个独立实体。临时保护带、焊道余高和最终去料分别记录，成品名义实体不代替沉积形貌。

## 3. 圆环独立预制参数与为什么采用

| 项目 | 首层CI-A1类ENi-CI | 第二层低碳裸Ni覆盖层 |
| --- | --- | --- |
| 焊材 | 药皮焊条芯径Ø3.2 | 裸棒Ø1.20±0.02 |
| 电流/电压 | 110 A / 23 V | 75 A / 11 V |
| 净热效率设计输入 | 0.80 | 0.60 |
| 主轨迹 | 中心R71.98，沿24 mm窗受控小摆动，覆盖6 mm槽底与内缘保护 | 名义R69.98、R71.98、R73.98；实件按各窗实测槽缘和中径修正三轨 |
| 行进速度 | **75 mm/min，±2%** | 2.00 mm/s |
| 供料输入 | 0.15～0.17 g/s诊断范围，随电流比例变化 | 7.20±0.20 mm/s；沉积效率0.90～0.98 |
| 起停覆盖 | 起端110 A补0.5 s；主弧末1.2 s从110线性降至80 A；止端80 A补0.5 s | 三轨采用共同的实测槽窗起止角；24/71.98仅为名义记账角度 |
| 单窗弧时 | 主弧19.2 s＋保护1.0 s＝20.2 s | 23.333148＋24＋24.666852＝72 mm，弧时36 s |
| 八窗弧时/名义净热 | 161.6 s / 322.2208 kJ | 288 s / 142.5600 kJ |
| 冷态加工目标 | 法向0.70±0.05；保留临时周界保护至二层完成 | 总料高≥1.75再齐平，总成品层1.40～1.60；第二层至少0.65 |

首层75的选择来自供料与覆盖量，而不是沿用八翼焊速。最大矩形槽＋0.20余高包络为24.5×6.1×(1.60＋0.20)＝269.01 mm³；按8.89 mg/mm³工程密度需要2.391499 g/窗。临时保护带最大体积为`[(24.5×0.5＋2×6.1×1.5)＋π×0.5×1.5/2]×0.75`＝23.796073 mm³，另需0.211547 g，总目标**2.603046 g/窗**。

最低供料按最短23.5 mm、速度＋2%、0.15 g/s及末段降流积分，再计两端保护输入。75 mm/min得到**2.869706 g/窗，裕量0.266660 g（10.24%）**；同样保护制度下80 mm/min为2.696912 g、裕量3.61%，90与100则不足。75相较80增加9.6 s/件主弧时间，热量发生在壳外和精密孔最终加工之前，用较小的离线时间代价换取覆盖余量。最大槽需求与最短路径供料是保守独立角点包络，未声称同一实际窗口同时取两种长度。

效率和诊断供料是设计输入；首件及每批通过冷态称量核验熔敷供料资格，各窗同时检查至少0.20余高、槽底/圆角覆盖和临时保护带形貌。受控小摆动与端部补弧用于覆盖槽底和起停区域，其实际行程、供料和熔合按局部检查记录，不能用平均厚度代替连续连接。清渣和层厚检查在机壳外完成。

第二层**按每窗实测槽几何引导**：内轨距实测内缘1.0、外轨距实测外缘1.0，中轨取实测中径，三轨起止角取该槽窗的实测端面角度。名义R69.98/71.98/73.98及24/71.98角对应23.333148＋24＋24.666852＝72 mm/窗、576 mm/件，仅用于名义供料、弧时和热量记账；实件记录实际行程并以同一公式核算，不能对最短窗仍强行使用名义24 mm角度。

径宽5.9～6.1对应相邻轨距1.95～2.05；熔宽下限取`max(2.8，实测最大轨距＋0.8)`且不超过3.0，最宽槽因此需至少2.85，保持搭接至少0.8。首镍保护仍按实测内缘法向0.5、实测端面法向1.5布置，不增大保护带。外缘超出部分靠可拆背衬承托。内角、端部及全径向覆盖由首件宏观截面确认，并逐窗核查轮廓与留层。名义17实体说明成品材料分区，未替代全公差下熔池过程。

在名义24 mm窗口下，最低丝径、最低送丝及最低沉积效率给出新增体积248.025850 mm³/窗。把端部1.5及两侧0.5外展纳入最大27.5×7.1＝195.25 mm²覆盖面积，名义低供料平均新增厚度约1.2703 mm；与最低首层0.65合计平均1.9203 mm。该体积余量支撑1.75目标的供料设计；实际验收逐窗确认局部最低料高、搭接和覆盖，再加工齐平。

两层名义弧燃合计**449.6 s、净热464.7808 kJ、熔敷45.0698 g/件**，尚未把升温、清渣、加工和冷却称为弧燃时间。这些数字均由本圆环窗口计算生成，不套用八翼首层15.329 g、100 mm/min或既有八翼热史。

## 4. 工序顺序与交付检查

| 顺序 | 工序 | 本工序形成的结果 |
| --- | --- | --- |
| 1 | QT来料核验、毛坯检查、粗加工 | 材料与基体组织入口、完整座体毛坯 |
| 2 | 在机壳外加工八局部窗 | 24±0.5×6.0±0.1、深1.50±0.10、R1.5内角；独立槽底测量基准 |
| 3 | 自由支承升温、首次镍层、按制度清渣及应力缓解、受控冷却 | 首次界面、真实预制状态及清理记录；温度制度按焊材与基体设计 |
| 4 | 首层中间修整和截面/层厚检查 | 实际保留层与去料几何；保存切削后的应力释放状态 |
| 5 | 第二镍层、受控冷却、连接面修整 | 镍系工作面和最终重熔所需的覆盖/隔离厚度 |
| 6 | 最终孔加工、预制件检查、清洗干燥封存 | 入壳前完成高温预制与去料操作，精密孔和内腔清洁入口形成 |
| 7 | 壳体A/B基准定位、座体入壳、胀套及支承夹紧 | 独立定心、轴向位置和初始孔轴实测状态 |
| 8 | 洁净防护、8×20 mm实际路径、两道对称分段连接 | 每段有效18；320 mm、96 kJ、193.939 s设计弧燃；详见HJ-W-S01 |
| 9 | 温度控制、冷却、完全卸夹、独立冷态测量 | 孔径、孔轴位置度、延迟裂纹及洁净度评价 |

独立预制的升温、清渣、两次覆盖、修整和缓冷按前工序生产能力核算；最终组焊的弧燃、段间温控、装卸和检测按在线工位核算。两者不能共用一个总节拍，也不能把离线等待从生产能力中删去。最终组焊的≤100℃候选层间制度不移作独立铸铁预制的统一温度制度。

小批规划以稳定1件/h供料为目标：首层、第二层各预留10 h热工序占用、各10个独立温控在制位置，再设24 h延迟PT的24个位置，共44个在制位置加检测工位。首件跨日完成，稳定库存后可支持8件/8 h供料；10位置不是10炉，也不是10件/h。10 h是包括装卸、清理和缓冷的保守计划时隙，工件道前/层间按独立预制200～300℃设计，并以实际温度决定转序。若改为240 s/件供料，相同预约时隙将需要150＋150＋360＝660位置或等效并联容量。分阶段组织库存是本轮可实施的生产安排，不能用分钟级弧燃冒充整条预制线能力。

## 5. 分段连接与完整环的代价

在R74.98处，全周弧长约471.11 mm；八个18 mm有效连接段合计144 mm，实际起停路径每段20 mm、每道160 mm。全周与分段的有效长度比3.27、单道实际长度比约2.94。最终组焊采用两道320 mm而不是把144×2当作实际弧燃路径。短段连接的取舍同时考虑承载面积、起停区、热输入和可达性。

完整环的名义QT体积246080.97 mm³，按设计密度7200 kg/m³得到1.772 kg；既有八翼座体约0.996 kg，完整环多0.776 kg。完整环增加的材料使独立预热、搬运和冷却容量需要重新核算。它也取消了翼间开口和槽根，改变了刚度、热扩散及焊接收缩的传递路径：承载上可能有连续环体的优势，控形上也可能把更多外缘收缩传到孔区。用同一载荷、同一支承和真实连接范围的计算评估这些变化，不以“环体更重”直接推出Ø0.05合格。

分段焊缩短连接范围，却保留完整QT环；八翼开口改变座体本身的承载与热应变路径。二者可以组合，但不是同一项设计。连接段数与长度先按所需承载面积、疲劳热点和可达性确定，再优化热输入，不能只为降低总热量缩短有效接头。
