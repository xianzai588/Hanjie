# HJ-W-S01 完整圆环座体最终组焊pWPS

本卡用于QT450-10完整圆环座体与5 mm Q235B壳体的最终精密组焊。座体名义厚15 mm、外半径74.98 mm、Ø40孔；在壳外完成八个局部高镍预制窗口、修整及孔加工，见HJ-S01。采用两道脉冲GTAW与NiFe55类实心棒，按ISO 15609-1组织工艺设计内容。规程状态为试制pWPS，接头评价及首件确认按HJ-M-01执行。

| 起停补偿 | 每段有效区两端各延长1 mm，实际路径20 mm/段/道；根道和盖面均包含这段补偿。起弧区、弧坑及渐变区位于有效18 mm之外，按专用试样确认完整稳定区 |
| 两层过渡 | CI-A1高镍首次层、法向修整、低碳裸Ni第二层；八个局部预制窗口及75 mm/min主弧、两端各0.5 s保护补弧和三轨第二层按HJ-S01和圆环预制JSON，覆盖最终20 mm路径、两端检查区及内缘/端部临时保护带。首件/每批冷态称量确认供料资格，逐窗检查余高及周界覆盖 |

## 2 焊接参数

| 参数 | 根道／盖面设计值 |
| --- | --- |
| 方法与极性 | 自动脉冲GTAW，DCEN；工件轴线竖直、固定，机器人绕轴运动；不摆动 |
| 焊材 | NiFe55类TIG实心棒，Ø1.60±0.01 mm；典型Ni55/C0.01/Si0.13/Mn0.70 wt%，按实供分类和批次证书验收 |
| 电极与保护气 | W-La20 Ø2.0，尖端60°、平顶0.3；弧长2.5±0.5；高纯Ar，名义10 L/min、许可8～12 |
| 电流波形 | 峰值100 A、基值50 A、占空50%、20 Hz；名义平均75 A |
| 弧压、焊速和送丝 | 参考弧压12 V；焊速1.65 mm/s±2%；送丝3.50±0.05 mm/s，设备分辨率≤0.01 mm/s |
| 成形 | 根道目标焊脚2.8 mm；盖面完成至名义4.0 mm，最低有效焊脚3.50、几何包络≤4.30；两侧连续熔合及有效喉部与成形分别检查 |
| 净线能量与记账 | 名义净300 J/mm；毛弧能545.45 J/mm、设计效率0.55。瞬时U(t)I(t)积分、除以实际路径长度记录毛弧能，端区也进入能量账；全路径300 J/mm给出96.0 kJ名义净热预算 |
| 焊序 | 根道1→5→3→7→2→6→4→8；盖面同序，段内沿圆周连续运动；每段实际20 mm，不削减中间有效18 mm |
| 温度 | 组焊不预热，起焊15～35℃；每段起弧前测本段QT侧固定点及前道邻近点，全部≤100℃；超温等待至≤90℃，缺信号禁起弧 |
| 轻击 | 基础工艺不启用最终随动轻击；设计预算不计其变形或疲劳增益 |
| 过程监测 | 核对装配间隙、路径起终点、能量及温度；焊缝跟踪偏差≤0.05 mm为设备目标。断丝、缺信号、越温或气水异常停弧并保持防护 |

圆环首层允许受控小摆动覆盖槽底和内缘保护带，按每窗余高及周界覆盖检查；最终GTAW仍按短段不摆动。首层完整制度的供料裕量在最短窗、速度上偏及低供料情景为10.24%，80 mm/min在同样补弧条件下仅3.61%；增加9.6 s/件主弧时间换取覆盖宽容度，高温工序仍在最终孔加工之前。

选择这组参数，是将镍侧和钢侧的连续连接放在可控制的短段内，并利用对向焊序分散环体收缩。有效长度负责传力，端区补偿负责起停，二者在图纸和记录中分别标注。250～350 J/mm可用于工艺评定比较，本卡采用300 J/mm作为确定的设计输入，改变能量时同步评价接头与孔轴。

## 4 防护、完全卸夹与验收

完整环体隔开上下腔，孔又被定位芯占用，下腔气流采用底工装独立进气与回气。两接口经密闭工装穿出处通向外部，回气接过滤抽吸；不在产品上另开气孔。确认进/回气实际通流与近常压后起弧，未开通、缺流或回气堵塞禁起焊。原八翼开放腔平均气速不作为圆环数值依据。水冷铜环、连续密封和朝上接料盘承担阻粒，气流仅辅助回收。起弧前检查八路水流，总≥0.60 L/min；铜瓣≤45℃、下座≤48℃、壳体密封带≤180℃；水气与密封任一异常停弧。铜环顶z99.5、圆环下表面z100，名义轴向净隙0.5 mm；盘和水气接口在座体下方，下工具从开放壳底装入工位后固定站内；退出时产品带托环抬离，不要求大铜瓣/盘穿Ø40孔。圆环专属工装HJ-F-S01～S03采用实际分段整体背承、3°固定反锥、主动退锥及双柱上桥。真实截面/底座/预紧连接/上桥冷态径向上界5.639 μm，接触坐实分配0.250后5.889，距6.5 μm径向分配余0.611供机台摇摆；冷态设计不覆盖热态或实机重复性。尺寸、BOM、装入与退出按HJ-F-S01～S03及圆环工装卡，不复用旧八翼工装详图。

最后停弧≥120 s且规定热区<55℃后按HJ-F-S01～S03执行：压环卸载/止挡开、胀套退锥1.5、铜瓣径退1.10、上工具提升260、托环接管/解窝、产品抬140、RF20底盖锁定、沿+y横移360 mm；下反锥/铜盘固定站内、盘朝上、洁净罩连续覆盖。托环和封底保持至20±1℃，再解除剩余外部约束，按独立A/B测孔。有限精整分支的焊接热残余允许上限13.5 μm，内部目标12 μm；其余分配28＋2＋6.5 μm按位置度直径计，目标总值48.5 μm、距50 μm限值1.5 μm。这里的6.5 μm是精整轴线变化直径；工装的6.5 μm径向夹紧分配已在28 μm非热位置度直径项内计入。

先检查孔轴、孔径及孔壁。孔轴由焊接控形承担；局部欠尺寸才执行最大径向3 μm的有限精整，之后复测并干态检查。PT、专用接头试样、经资格的UT及洁净方法见HJ-M-01、HJ-Q-01～03。

## 5 小批工位规划

设计组织目标为稳定供料8件/8 h，即3600 s/件。圆环每层预制热链预留10 h工艺时隙：按最高道前温300℃至20℃、50℃/h环境缓降计5.6 h，加2 h保温，再预留2.4 h升温、转运和热滞后；环境斜率只用于容位规划，交接以工件实际冷态确认。每层10个独立温控在制位置；第二层后24 h延迟等待配24位，三项合计44位。这个配置支持跨日预制库存向单头组焊供料；每层10位指可独立计时的工艺位置，不是10台炉或10件/小时。实际温度与占用记录更新后按n=ceil(t占用/3600)调整。

每阶段PT人工480 s、历时上限4080 s的规划口径配2个停留位；操作工位与停留位分开。最终焊站预留900 s/件：弧燃193.939、16段次辅助清理/转位288、防护保持120，余298.061 s用于温控等待和转运。1个焊站、1个装配位、1个独立湿检工位、1台CMM和1个干态检查位对应3600 s供料目标；微珩分支使用独立封闭回收位。温控先于节拍，超过时隙则增配相应位置或降低供料速率。

两层热时隙20 h加延迟等待24 h，已占44 h计划历时，加工、PT停留与转运另计，首批按跨日组织。圆环10 h/层和900 s最终站是明确的资源预留，不写成已经计算的圆环冷却历时或现场实测节拍。
