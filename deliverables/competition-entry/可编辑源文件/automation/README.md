# 当前圆环自动化方案与合成控制回放

当前入口读取 `project/submission-baseline.yaml` 的工艺版本、八段两道布局与最终组焊参数。数字回放用于核对工艺入口和联锁逻辑，设备通信数始终为零。

1. `vision/`：数字图像中的偏移与姿态恢复，保留识别质量门。
2. `path-planning/`：每道按 1→5→3→7→2→6→4→8 执行，实际20 mm/段、有效18 mm/段；两道实际路径320 mm。输出圆弧定义、局部坐标和产品坐标；局部原点在座体上表面孔中心，产品原点在壳体下端A面中心，当前两者Z差115 mm。焊缝参考路径还需经过机器人工作站变换与TCP标定。
3. `anomaly-detection/`：合成100/50 A、20 Hz、50%峰值占空比的瞬时电流，默认400 Hz采样；窗口判断也接受明确标注的周期平均电流。瞬时电流逐完整周期评价峰值与基值，持续两周期偏差形成事件。速度窗口为1.65 mm/s±2%，弧压11～13 V，送丝3.50±0.05 mm/s；电流/电压容差属于设计监测窗，详见基准文件末尾 `monitoring_design`。窗口固定，不用本件序列自动估偏置。
4. 温度信号逐点区分 `first_start`、`interpass_start`、`arc_on` 和 `cooling`。首段起弧15～35℃、续焊起弧15～100℃，起弧越界立即禁止请求；弧燃/冷却读数不被误当层间起弧温度。
5. `app/`：调用现有工作站联锁，并叠加当前圆环温控门。除20秒注入片段外，还在内存生成16段次整件候选反馈，每段严格20/1.65 s弧燃，逐点保存段/道身份及起弧前阶段。同步瞬时UI按相邻时间戳积分，段末间隔截至真实段边界；净热除以速度积分的实际路径，检查300 J/mm±2%和段路径20 mm±2%。周期平均电流不能代替同步瞬时UI参与这一积分。联锁读取上一已许可段的能量评价，异常锁存后停止后续请求；12.6 V虽处于弧压窗内，积分得到的约315 J/mm仍会停止续焊。150℃起弧及送丝偏移同样会被拒绝。所有温度、气水、屏障、夹具与防护门输入明确为合成输入。
6. `traceability/`：写库前核对工件编号、会话编号、工艺版本、工序和来源；重算本件检测结果并核对原始信号绑定，拒绝工件或结果错配。同一工件可有多个会话，已经存在的会话不得被另一组信号覆盖。当前数据写入 `weld_sessions_v2` / `anomaly_events_v2`，旧表保留历史身份。

运行：

```bash
python automation/app/run_demo.py --count 1000
python automation/anomaly-detection/run_benchmark.py --normal-count 100 --injected-count 100
python -m pytest tests/test_current_ring_automation.py -q
```

当前20秒合成片段在 `anomaly-detection/results/W2026-001-signals.json`，与旧 `data/samples/` 输入分开。整件结果只保存 `app/results/complete-weld-replay-summary.json`，包括正常、能量偏移和送丝偏移案例；未许可段的候选波形不计为执行。正常整件弧燃总时长193.939 s是最终组焊弧燃时间，不含实际温度等待、装夹与检验节拍；0.05 s起弧检查间隔和25/85℃读数均为合成场景输入。没有工艺版本的旧样本只进入历史窗口回放，输出 `historical_unversioned_window_replay`，不得写入当前圆环追溯表。现有困难视觉基准仍在 `vision/results/difficult-summary.md`，保留其数字样本身份。

合成试验的检出率、误报率只评价这批注入片段；不作为实际设备或接头质量的实测结果。后续接入需要校准相位同步、采样时间、传感器量程、焊机通信和机器人坐标变换。

两个虚拟控制入口仅接受 `source_type=simulated`，不会为 `physical` 记录补入合成夹持或水路反馈；实采信号的追溯入口仍保留真实 `physical` 来源。
