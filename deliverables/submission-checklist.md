# 参赛提交核对清单

更新：2026-10-06。按[最小修复与参赛路线](competition-route.md)执行。当前尚未发布最终技术包，deliverables/submission保留的是历史交付，不能直接发送。

## 技术冻结

- [ ] 所选预制焊材、成分、方法、极性及热制度来自同一产品/工艺依据；不混用裸Ni99与药皮镍焊条参数。
- [ ] 实际翼端全宽连续首次QT熔合、第二层及最终双侧熔合、最小截面、残层和稀释均验证。
- [ ] QT首次PMZ容量及冷却硬化处理有适用依据；平衡FCC比例、Ni200轧材或填料体积均不代替界面容量。
- [ ] 预制残余状态保留，修整与孔加工按实际去料释放，再组焊、冷却、解除全部外约束；没有任意清零历史。
- [ ] 同一有效制造家族的空间、时间及工具域精度符合≤5%及绝对预算；上下界、内区敏感性不跨未审查分支。
- [ ] 需微珩分支28+2+6.5+P≤50 μm、P≤13.5 μm、径向去除≤3 μm；无去料且孔径直接合格方可采用20 μm分支。
- [ ] 同一制造残余状态的额定加载/卸载、最大主拉、塑性增量、槽根/焊趾/PMZ及疲劳资格需求完成；工况明确。
- [ ] 四工艺使用可实施接头、同等有效面积/载荷及完整站占用比较，不按任意权重宣称TIG最优。
- [ ] 铜衬、气水路、密封和撤出按温升/公差最不利组合验算；微珩排管全长差压容量，UT凝胶另列方法边界。
- [ ] CMM独立A/B、基准等效及不确定度预算完成；UT声路、可达/盲区和验收细则有依据。

## 说明书与图纸

- [ ] 只有一套采用参数；历史300 J/mm、未采用285 J/mm和旧预制卡不作为并列生产指令。
- [ ] 正文是工艺设计说明书：先设计决策、再工程验证、再制造与检验；过程日志移附录。
- [ ] 采用真实送丝/热量/界面/控形/承载图表，不伪造金相、设备日志或实测曲线。
- [ ] 关键件有制造详图、基准/配合/表面及热处理要求和零件明细；区分功能示意、总装和零件图。
- [ ] 正文、工艺卡、工程图、STEP使用同一采用几何、温度制度和焊序；PDF逐页渲染检查。
- [ ] 关键文献已读核对、引注与参考表对应，无馆际调取备注；作者、题名、年份、DOI无冲突。
- [ ] 匿名检查覆盖正文、页眉页脚、图名、书签、PDF元数据及附件，身份资料不混入技术包。

## 发布与学校提交

正式构建：`python deliverables/build_submission.py`。有效接头、完整位置度与承载等已有门槛通过后，才重建最终目录；禁止把构建条件改为True或取消检查来取得ZIP。

- [ ] 包内说明书、WPS及图集均为当前采用方案；报名、盖章材料按官方原附件单独处理。
- [ ] 固定题报告与设计图路线允许，格式/篇幅不限；不套用铸造自编代码条款。
- [ ] 学校负责人核对最新原件和校内截止；10月20日前报名、10月25日含当日提交。
- [ ] 同校2～4名学生、1～2名教师及报名/推荐信息由参赛方确认，本工具不代填身份或发送邮件。
- [ ] 校方按官方要求汇总作品及盖章表，技术稿与报名身份信息分别核查后发送。
