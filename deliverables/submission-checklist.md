# 参赛提交核对清单

更新：2026-10-08。按[参赛设计路线](competition-route.md)核对完整圆环基准、八翼创新候选及材料包。构建结果写入 `competition-entry/验证与交付状态.json`；本清单按实际完成情况逐项填写。

## 作品内容

- [ ] 正文覆盖工艺、材料、结构、质量与自动化五维；每项关键设计说明问题、作用、依据和实施代价。
- [ ] 完整圆环为提交基准；HJ-S01、圆环模型和 `project/submission-baseline.yaml` 对象一致。
- [ ] 八翼开口、HJ-001～021 和既有模型明确列为创新候选及相关工装详图，保留原计算对象。
- [ ] 壳体 Q235B、Ø160×200 mm、壁厚 5 mm，座体 QT450-10、Ø40 孔及 Ø0.05 mm 位置度与题面一致。
- [ ] 座体厚度、安装高度、孔 H7 控制窗、装配间隙、载荷谱和颗粒判据分别注明为设计选值。
- [ ] 外塞焊、激光、等离子、GTAW 比较说明各自条件，选择理由对应接头、控形、洁净和生产组织。
- [ ] 材料链和三道工序统一：CI-A1 高镍 SMAW 首层、低碳 Ni99 第二层、NiFe55 最终 GTAW；首层药皮与裸棒成分分开。
- [ ] 工艺卡列明方法/极性、焊材、参数、温度、清理、保留层、段序、检验与处置。
- [ ] 八段短焊净热、送丝和弧燃核算正确；装卸、转位、温控等待与设备/人工资源另列。
- [ ] 位置度预算、完全卸夹测量状态、有限微珩上限和 CMM 不确定度统一。
- [ ] 洁净链覆盖焊接、冷却、撤夹、转运与后序检查；产品采用干态检查，牺牲样用于方法资格。
- [ ] 金相/HV、PT、专用 UT、精度、颗粒、承载与疲劳方案说明对象、频次、判据和不合格处置。
- [ ] 单头工作站布置、装夹、气水、能量、温度及退工具联锁可读、可执行。

## 计算与表达

- [ ] 圆环与八翼的结果分别登记；温度历程、残余孔形、局部应力及热工位容量没有跨实体引用。
- [ ] 基础计算解释选型；八翼历史超差算例用于说明修订，不作为圆环验收结论。
- [ ] 仿真、理论计算、文献数据、设计目标和后续试制项目在图表及正文中有清楚名称。
- [ ] 参考文献题名、作者、年份、DOI/网址和文中引注一致，方法适用范围与接头材料相符。
- [ ] 没有将生成的示意图标为实测金相，没有编造实测曲线或质检记录。
- [ ] 正文减少排障日志、重复免责声明和无关软件指标，重要判断保留理由和数据来源。

## 文件与版式

- [ ] 正文 PDF、说明书、工艺卡、图集和 ZIP 均来自本次构建。
- [ ] 实际页数、图号和包内文件与 `验证与交付状态.json` 相符，不沿用历史页数。
- [ ] 摘要、目录、正文、参考文献、图题、表题、单位、字号和页眉页脚统一。
- [ ] 科学图使用统一配色和清楚单位，缩至最终版面仍能读懂；表格无裁切、断字或多余网格。
- [ ] PDF 已逐页渲染检查，链接、目录和正文交叉引用对应最终稿。
- [ ] STEP 标明母件/过渡层/工装的实际内容，可编辑 Markdown、YAML、绘图与构建脚本一并收录。
- [ ] 技术包匿名检查覆盖正文、图名、页眉页脚、书签、元数据与附件；报名身份资料另列。
- [ ] 独立 agent 已审核内容一致性和版式，发现的问题已记录并修正。
- [ ] 新修订已推送远端并核对提交及材料文件，方便后续接续。

报告与材料包入口：

```bash
python deliverables/report/build_technical_report_pdf.py --competition-entry --with-drawings
python deliverables/build_competition_entry.py
```

`build_submission.py` 保留原八翼工程发布检查；本次固定题报告与工程图按 `build_competition_entry.py` 整理。工程试制确认按现行工艺卡执行。
