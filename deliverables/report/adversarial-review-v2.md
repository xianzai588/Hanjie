# Technical Report V2 - 恶意评委式技术审查

## 审查结论

本轮没有发现需要推翻主线的 P0 技术硬伤。报告最重要的防守点已经具备：基准不自引用、FE 不冒充高保真焊接仿真、蒙特卡洛不冒充独立证据、视觉返回率不冒充工程通过、参赛提交与制造放行分层。

## 只修关键缺陷后的答辩口径

一句话总答：

> 当前数字证据把自动 TIG + 镍基填充、六点短焊段和 S3 排为继续验证候选；降阶模型支持柔顺结构，但独立二维代理 FE 给出反例，所以最终结构不在没有三维/物理证据时提前定案。

## 不应在最终稿中新增的主张

- 不把 `P_FE` 写成真实焊后位置度或 CMM 结果。
- 不把 1000 次蒙特卡洛写成真实失效概率或第三种独立验证。
- 不把视觉检测返回率写成定位精度或工程通过率。
- 不把数字误差预算写成已测得的不确定度。
- 不把候选 WPS、候选填充牌号或数字图纸写成制造放行文件。
