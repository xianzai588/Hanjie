# 无实物工艺设计路线：独立预制修订

第一届辽宁省大学生材料焊接与铸造工艺设计大赛，焊接固定命题。

## 1. 交付方式和设计决定

按官方实施方案第5页的研究报告及设计图路线组织作品，不制作实物。说明书包含工艺选型、材料连接、焊接结构、质量评价和自动化方案；WPS与图纸是核心附件，不用软件测试数量代替工艺设计质量。

本轮设计接口为：**独立CI-A1首次预堆 → 首层中间修整 → 原低碳Ni99第二层 → 连接面和最终孔加工 → 自动GTAW入壳组焊 → 冷却、完全卸夹 → 同制造残余状态承载与卸载。**

保留八翼、柔顺槽、微台阶、独立A/B、锁止胀套、铜环与气幕、封闭清洗回收。最终孔的焊接变形仍受13.5 μm分配约束，完整位置度为28+2+6.5+P≤50 μm，不扩大机加工去除量。

旧制造家族的加密结果P=15.584 μm，总位置度52.084 μm，超差2.084 μm；空间与时间响应差分别16.56%、5.38%。首次界面与最终双侧连接也未闭合。因此旧家族不进入本轮采用结论，当前稿仍是设计修订稿。后续试制项目列为工程确认，不以“没有实物”为由停止设计计算。

## 2. 商品焊材核实

Kobelco原厂综合目录344～347页列CI-A1预热100～300℃、Ø3.2对应80～130 A、AC/DC+；CI-A2预热150～350℃、Ø2.6对应60～90 A，明确涉及球墨铸铁。CI-A1典型熔敷成分C1.0、Ni96、Fe1.8、Si0.2、Mn0.6%；CI-A2典型C1.2、Ni54.6、Si0.3、Mn1.6%、Fe余量。上述为典型熔敷成分，不是焊芯纯度，也不是供货批次保证值。

同一目录要求短直道、对称/跳焊、道后及时轻击并规定焊条复烘。UTP原厂铸铁目录另给冷焊道间≤60℃，不能把UTP冷焊制度与Kobelco温焊预热拼成“同一已评定WPS”。

本轮选择CI-A1作首次层优先设计输入，CI-A2作为材料对照。第二层仍采用原低碳裸Ni99材料，减少MMA焊条引入的碳在最终熔池中的继承；第二层混合和实际稀释必须按新首次层重算。供方全焊缝拉伸例值不作为本件PMZ容量。

## 3. 新成分的相平衡计算

实际执行Oikawa、Ueshima公开Fe–Ni–C数据库计算，采用pycalphad；CI-A1/CI-A2分别计算原熔敷成分及输入20% QT两种情景，均计算允许石墨与抑制石墨两种分支。按明确列出的C/Fe/Ni质量重新归一化，其余元素及未列成分不悄悄并入Fe。

允许石墨分支包含抑制石墨的可行状态，故其Gibbs能不应更高。本轮检查该关系，独立核对被替换低能状态的采样切平面稳定性，再输出相分数与转变区间。高温格点间隔10℃，表中给区间，不给伪精确单点。

| 输入情景 | 允许石墨固/液相线℃ | 抑制石墨固/液相线℃ |
| --- | --- | --- |
| CI-A1-QT0 | 1330～1340 / 1390～1400 | 1210～1220 / 1390～1400 |
| CI-A1-QT20 | 1330～1340 / 1340～1350 | 1110～1120 / 1340～1350 |
| CI-A2-QT0 | 1270～1280 / 1350～1360 | 1080～1090 / 1350～1360 |
| CI-A2-QT20 | 1240～1250 / 1320～1330 | 1080～1090 / 1320～1330 |

CI-A1输入20% QT时，抑制石墨分支在25℃得到渗碳体质量分数24.25%；与旧低碳裸镍配混结果不同，需重算首次层、低碳第二层和最终混合，不能继承原稿“高镍即免白口”的解释。嵌套Gibbs可行性复核结果：通过。

这些是指定成分的平衡及亚稳边界，不是实测白口比例。Si/Mn影响、凝固与冷却动力学、首次PMZ位置和输运稀释需与接头热循环相结合；不以高FCC比例直接判接头韧性或承载通过。

## 4. 真实座体升温与节拍

对已有全翼浅槽下界1.40 mm的QT实体进行有限元热传导，孔与槽保留真实CAD轮廓；不把整个座体温度瞬时设为200/300℃。模型仅包含入壳前QT座体，采用现有温变Cp/k、全外表面对流20 W/(m²·K)、发射率0.7的开敞炉内边界。炉温从20℃按给定速率爬升，工件各节点随传热升温。该几何下界算例用于预制热制度筛查，不能冒充名义1.50 mm制造残余应力家族。

先执行3℃/min，200/300℃炉温的到温时间分别67/98 min。随后依据较小的全程温差，修订为12℃/min并实际重算；到温条件为最低温度≥炉温-10℃且全体温差≤10℃。采用独立时间加密和同BREP空间重网格检查，达到工程精度即停止本项计算。

## 5. 两层厚度的最小几何修复

原第二层送丝按公称径计算时，两层最小新增1.706 mm，对最大槽深1.60 mm仅有0.106 mm余高；要求0.10 mm后只剩0.006 mm，不能容纳棒径、起停和轮廓波动。本轮增加首层中间修整，以实际槽底为基准保留0.70±0.05 mm，避免首层天然焊道厚度控制第二层存留量。

第二层完成后的最小总高度设为槽底以上1.75 mm，对最大槽深仍有0.15 mm加工余高。最终连接面齐平后总层1.40～1.60 mm；第二层最不利厚度=1.40-0.75=0.65 mm。最终累计重熔0.40 mm后仍至少余0.25 mm第二层。层间混合带与重熔、实际覆盖面积同时核算，不能仅凭这组几何尺寸判冶金通过。

槽底与首层高度按逐翼实测轮廓的设计检验方法闭合，入壳前完成切削、PT安排和清洗干燥。切削计算只删除实际材料并重新平衡，预制残余应力不清零；最终微珩仍限定径向≤3 μm。

上述尺寸链针对平直连接工作区。本轮已生成R1.5真实槽及首层法向等厚0.70 mm的实体CAD，首层修整圆角为同心R0.80；不能把首层全区直接铣成平面，否则圆角附近第二层可能接触QT。原升温网格未包含此圆角，本轮低温升温图不作为圆角处的熔合或应力证据。

实际执行CAD布尔分区：首层体积678.037 mm³，第二层629.487 mm³；材料替换体积差-0.001485 mm³（相对1.07e-08）。QT/首层几何曲面面积1053.454 mm²，第二层/QT共享面面积0 mm²。导出的STEP中17个材料实体均通过几何有效性检查。名义4.0 mm焊脚径向内界R71.0与圆角平直切点R70.48之间有0.52 mm几何间隔，仍需结合焊趾偏差和实际重熔范围核查。

![HJ-DRW-017 名义曲面预制与中间修整断面补图](docs/report/figures/design-precoat-normal-offset.png)

曲面CAD及补图给出名义尺寸、材料分区和修整面，尚未代替公差家族、接头热循环与PMZ承载计算。实际几何界面面积不直接用作已熔合的有效面积。

工艺卡见HJ-W-00C。MMA电压、沉积输入和空间热源尚未形成采用窗口；本轮没有把GTAW源宽度当焊条弧形、枪距或激光离焦，也没有填写一套无依据的生产电参数。

## 6. 下一项设计计算和采用判据

第一项仍是**新首次QT界面**，而不是整件重复长时计算。用CI-A1实际含碳熔敷材料、实际沉积形貌/轨迹和可追溯热源输入，检查整个翼端和起收弧区域；连续有效连接及PMZ容量成立后，保存预制状态、中间修整及最终孔加工存留状态。

随后核查第二层及最终双侧连接、剩余第二层与质量稀释，进入同一制造家族的基准、独立空间加密、独立时间加密和孔径下界。所有工具完全解除后按独立A/B评价孔形和位置度，最后同状态加载与卸载。合格才将新路线替换入统一说明书、WPS和图纸；没有有效接头时不填写“已满足全部设计指标”。

无实物作品提交为匿名说明书、设计工艺规程、工程图集和精简计算附件。后续车间试制的截面、硬度、PT/NDT及承载试验作为规定的工程确认方法，不制作冒名实测图或评定报告。报名及盖章附件由学校按官方要求另行处理。
