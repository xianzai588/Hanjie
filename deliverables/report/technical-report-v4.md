## 摘要

<!-- PLACEHOLDER_EXEC_SUMMARY -->

本项目面向 Q235B 薄壁圆柱壳体与 QT450-10 球墨铸铁主轴承座的异种材料连接，目标是控制焊后 Ø40 轴承孔轴线位置度不超过 Ø0.05 mm，并避免焊渣和飞溅进入壳体内部。

**V4 当前状态**：
- 设计输入已冻结（`design-inputs-frozen-v4.md`）
- 验证协议已编写（`FE3D-BASE-verification-protocol.md`）
- FE3D-BASE 建模进行中
- Gate B 验证待运行结果

**V4 与 V2/V3 主要差异**：
- V2：降阶模型 + 二维 FE 代理，网格收敛未通过（29.224%）
- V3：修复接头几何、基准定义、误差预算闭合
- V4：**仅实施 FE3D-BASE**，建立数值可信度基线，禁止未经验证的结构扩展

## 1. 题面约束与验收目标

官方固定条件为：壳体 Q235B，外径 Ø160 mm、高 200 mm、壁厚 5 mm；主轴承座 QT450-10，中心轴承孔 Ø40 mm；焊后位置度限值 Ø0.05 mm；内部不得出现可能落入压缩机内部的焊渣或飞溅。

本报告的数字指标都使用"模型内判定"措辞。只有焊后完全冷却、解除夹具、建立基准并完成合适精度的 CMM 或经校准专用检具测量，才能给出实测位置度。

## 2. 材料与焊接性边界

## 3. 工艺路线与热管理

### 3.1 候选工艺：自动 TIG

选型理由：
- 热输入精确可调，熔合比低，控制白口/裂纹
- 无熔滴过渡飞溅，天然满足内腔洁净约束
- 枪体小，环形可达性好
- 焊接机器人标配，成本低

## 4. FE3D-BASE 几何与边界条件

- 外径 Ø160 mm，高度 200 mm，壁厚 5 mm

**轴承座**（Baseline 结构）：

- 结构类型：**连续环形座体**（非分段）

- 腿长 3.5 mm

### 4.2 边界条件（冻结）

- 壳体底面：固定支撑（ΔZ = 0, ΔθX/Y = 0）

- 释放时机：冷却至 50°C 后

**热边界条件**：
- 初始温度 T₀ = 150°C（预热）
- 对流换热 h = 10 W/m²·K（空气）
- 环境温度 T_amb = 20°C
- 辐射发射率 ε = 0.8

## 5. FE3D-BASE 分析流程

### 5.1 Phase 1: 热分析

1. 预热至 150°C（均匀场）
2. 移动 Goldak 热源，按 S3 顺序逐段施加
3. 层间等待至 ≤200°C
4. 完全冷却至 50°C

### 5.2 Phase 2: 结构分析

1. 热应变 + 弹塑性本构
2. 夹具约束保持至冷却 50°C
3. 释放夹具约束
4. 继续冷却至 20°C

### 5.3 Phase 3: 后处理

1. 提取 Ø40 孔内表面节点坐标（释放后、20°C）
2. 最小二乘拟合孔轴线
3. 计算轴线位置度相对名义位置
4. 提取应力、变形、温度历程

**孔轴线位置度提取算法**：详见 `FE3D-BASE-verification-protocol.md` §孔轴线位置度提取算法

## 8. 焊缝疲劳与寿命评估

### 8.1 疲劳热点与设计对策

| 疲劳热点 | 成因 | 设计对策 |
| --- | --- | --- |
| 焊段起止端 | 应力集中系数高 | 延迟收弧填满弧坑，端部打磨 |
| 焊缝根部未焊透区 | 局部熔透不足 | 坡口与钨极对中控制 |
| 熔合区硬脆组织 | 白口/马氏体裂纹萌生 | 镍基填充 + 预热缓冷 |
| 整体不平衡激励 | 焊缝非对称布置 | 六点周向对称 + S3 跳焊 |

### 8.2 疲劳设计基线

- 环向角焊缝按 IIW 名义应力法取 FAT 63–80 等级
- 压缩机工况应力谱需实测载荷谱标定
- 镍基焊缝良好延性与低残余应力是疲劳裕度来源

### 8.3 验证试验计划

实物阶段按三级验证：
1. 接头级：轴向载荷疲劳试样（R=0.1，10⁷ 循环，≥3 件）
2. 部件级：焊后壳体组件振动台耐久试验
3. 整机级：装机耐久试验后内窥复检

**边界**：实测载荷谱与接头疲劳数据回填前，不作为寿命达标证明。
