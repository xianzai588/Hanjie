# 面向 Ø0.05 mm 位置度的 QT450-10/Q235B 主轴承座异种焊接热—结构协同优化与数字质量控制

**版本**：V4.1-UNIFIED  
**日期**：2026-09-03  
**赛道**："中铁山桥杯"焊接工艺设计赛道 · 固定命题：某型压缩机主轴承座与壳体连接  
**状态**：V4 基线收敛版；V2/V3 参数不一致已清理

---

## 执行摘要

本项目面向 Q235B 薄壁圆柱壳体（Ø160×200×5 mm）与 QT450-10 球墨铸铁主轴承座的异种材料连接，核心挑战是在承受高频振动载荷前提下，将焊后 Ø40 轴承孔轴线位置度控制在 **Ø0.05 mm** 以内，并确保内腔不进入焊渣/飞溅。

### 核心技术路线

**工艺选型**：自动 TIG + ERNiFe-CI 镍铁基填充（75 A / 12 V / 1.5 mm/s，线热输入 330 J/mm）

**设计方法**：三维热—弹塑性有限元 + 参数化接头优化 + 误差预算闭合

**四个关键创新方向**：
1. **参数化柔顺接头设计**：通过结构刚度匹配降低焊接变形
2. **温度门控自适应跳焊**：动态优化焊段激活顺序
3. **焊前装配预偏置补偿**：基于热—结构模型预测的反向补偿
4. **数字质量闭环**：视觉定位 + 在线监测 + 追溯放行

### 当前验证状态

| 项目 | 状态 | 证据等级 |
| --- | --- | --- |
| 工艺参数窗口 | 设计完成 | 设计卡（待 WPS） |
| FE3D-BASE Baseline | 实施中 | Gate B 待验证 |
| 结构公平对比 | 计划 | Gate B 通过后 |
| 自适应跳焊 | 提出 | 待对照实验 |
| 预偏置补偿 | 提出 | 待闭环验证 |
| 误差预算闭合 | **未闭合** | 0.035 > 0.025 mm |

**V4 明确边界**：当前误差预算最坏情况为 **0.035 mm 径向（Ø0.070 mm 位置度）**，尚未满足 Ø0.05 mm 目标。后续热—结构优化与焊前预偏置补偿的直接目标，就是关闭这 **0.010 mm 径向预算缺口**。

## 1. 命题解析与总体方案

### 1.1 题面约束

官方固定条件：
- 壳体：Q235B，Ø160 mm × 200 mm × 5 mm 壁厚
- 轴承座：QT450-10，中心轴承孔 Ø40 mm
- **位置度限值**：Ø0.05 mm
- **洁净约束**：内部不得有焊渣/飞溅进入压缩机腔
- **疲劳载荷**：高频振动工况

### 1.2 技术挑战层次

| 挑战 | 根本原因 | 本方案对策 |
| --- | --- | --- |
| 异种材料冶金相容性 | QT450-10 石墨组织 + 白口风险 | 镍铁基填充 + 低热输入 TIG |
| 焊接热变形 | 薄壁壳体 + 非对称热输入 | 三维 FE + 结构/顺序优化 |
| Ø0.05 mm 位置度 | 误差预算未闭合（0.035 mm） | 柔顺结构 + 预偏置补偿 |
| 疲劳寿命 | 焊段端部应力集中 | 镍基韧性 + 端部修整 |
| 内腔防护 | 焊接飞溅 | TIG 工艺特性（无飞溅） |

### 1.3 验收目标层次

**最低功能要求**（Gate 0）：
- ✅ 焊透、无裂纹、无未熔合
- ✅ 内腔洁净（无焊渣/飞溅）
- ✅ 位置度 ≤ Ø0.05 mm

**工程竞争力要求**（Gate 1）：
- 🔄 误差预算闭合（当前 0.035 → 目标 0.025 mm）
- 🔄 疲劳寿命满足设计基线（IIW FAT 63-80）
- 🔄 稳定重复制造（P95 满足目标）

**高奖竞争要求**（Gate 2）：
- ⏳ 至少 2 个创新有定量 baseline 对照
- ⏳ 核心 FE 通过网格收敛验证（< 5%）
- ⏳ 每个强结论都有证据 ID 追溯

## 2. 异种材料焊接性与工艺选型

### 2.1 QT450-10/Q235B 焊接性边界

**QT450-10 侧风险**：
- 石墨球组织在熔合区碎化
- 快速冷却形成白口（硬脆、易裂）
- 基体铸造缺陷（缩孔、夹渣）

**Q235B 侧风险**：
- 薄壁（5 mm）易过热变形
- 壳体椭圆化影响装配基准 B
- 热影响区晶粒粗大

**冶金对策**：
- 镍铁基填充（ERNiFe-CI）：韧性好、止裂强、稀释率低
- 低热输入：330 J/mm（75 A / 12 V / 1.5 mm/s）
- 预热/层间控制：150 °C / ≤200 °C

### 2.2 工艺路线公平对比

| 评估维度 | 自动 TIG | CMT-MAG | 激光填丝 |
| --- | :---: | :---: | :---: |
| 白口/裂纹控制 | ◎ | ○ | ○ |
| 变形与位置度 | ◎ | ○ | ○ |
| **飞溅/焊渣风险** | **◎** | ○ | △ |
| 环形可达性 | ◎ | ○ | △ |
| 疲劳潜力 | ◎ | ◎ | ○ |
| 成本/成熟度 | ◎ | ◎ | △ |

**选型结论**：自动 TIG 在热输入控制、**洁净度**、可达性四项同时占优，确定为主候选。

### 2.3 材料参数（温度相关）

详细材料参数表见 `simulation/fe3d/design-inputs-frozen-v4.md`。

| 材料 | E (20°C) | α (20°C) | σ_y (20°C) |

| QT450-10 | 169 GPa | 11.0×10⁻⁶/K | 310 MPa |
| Q235B | 206 GPa | 12.0×10⁻⁶/K | 235 MPa |

| 参数 | 值 (mm) | 说明 |

| **径向间隙** | **0.01~0.04** | H7/h6 定位间隙配合范围 |
| 翼宽 | 18.0 | 焊段承力宽度 |
| 翼根槽宽 | 4.0 | 柔顺槽 |
| 座体中心刚性区 | Ø82 | 刚度核心区 |
| 焊段长度 | 18.0 | 六点布局 |
| 焊缝形式 | 角焊缝 | 脚长 3.5 mm |

**关键修正**：
- ❌ V2 错误：R73.8 mm（1.2 mm 间隙过大）
- ✅ V4 正确：R74.98 mm（0.02 mm 名义间隙）

**装配配合说明**：
> H7/h6 为定位间隙配合（locational clearance fit），非过渡配合。采用小间隙精密定心设计。实际装配前需测量壳体内径及圆度，通过翼端精加工/选配保证间隙落在设计范围。

### 3.2 独立基准系统

**功能装配基准**（GB/T 1182-2008，ISO 5459）：
- **A**：壳体安装基准平面
- **B**：由 Q235B 壳体建立的理论中心轴
- **C**：独立周向定位特征

**受控特征**：Ø40 轴承孔轴线

**位置度框**：`POSITION Ø0.05 | A | B`

**关键原则**：C 仅用于装配周向姿态，**不进入 Ø40 孔轴线的位置度框**，避免受控特征自引用为基准。

### 3.3 夹具设计

**V4 统一配置**：
- **中心定位**：锥形心轴（1:50 锥度，自动找正）
- **径向支撑**：6 点可释放弹性支撑
- **轴向预紧**：500 N 轴向力
- **释放时机**：冷却至 50±5 °C

**关键修正**：
- ❌ V2 错误：Ø39.96 mm 定位销（刚性、重复性差）
- ✅ V4 正确：锥形心轴 1:50（自动找正、重复性 ≤0.008 mm）

**必须输出**：

## 5. 承载刚度与疲劳评估

### 5.1 疲劳热点与设计对策

| 疲劳热点 | 成因 | 设计对策 |
| --- | --- | --- |
| 焊段起止端 | 六段环缝端部刚度突变 | 延迟收弧填满弧坑；端部修整 |
| 焊缝根部 | 局部熔透不足 | 坡口对中控制；小试金相确认 |
| 熔合区硬脆组织 | 白口/马氏体 | 镍基填充 + 预热缓冷 |
| 不平衡激励 | 焊缝非对称布置 | 六点对称 + S3 跳焊 |

### 5.2 疲劳设计基线

**设计基线**：环向角焊缝按 IIW 名义应力法取 **FAT 63-80 等级**（2×10⁶ 循环参考强度）作保守评估。

**验证试验计划**（实物阶段）：
1. 接头级：轴向载荷疲劳试样（R=0.1，10⁷ 循环，≥3 件）
2. 部件级：焊后振动台耐久，跟踪位置度漂移
3. 整机级：装机后内窥复检焊缝

**边界**：本节为疲劳设计基线，实测载荷谱与接头疲劳数据回填前，不作为寿命达标证明。

## 6. 温度门控与装配预偏置控制（创新方向）

### 6.1 焊前装配预偏置—焊后变形联合补偿

**关键修正**：
- ❌ V2 错误概念："轨迹反变形补偿"
- ✅ V4 正确概念："焊前装配预偏置补偿"

**控制链**：
```
视觉/CMM 测得初始偏心
        ↓
热—结构模型预测焊后收缩
        ↓
求解最佳预偏置 δ_pre
        ↓
微调心轴/定位平台
        ↓
重新测量确认
        ↓
机器人沿真实接头轨迹焊接
        ↓
焊后测量
```

**状态**：⏳ 提出，待闭环验证

### 6.2 温度门控自适应跳焊

**对比基线**（公平比较）：

| 方法 | 对比意义 |
| --- | --- |
| S1 连续 | 最弱基线 |
| S2 对称 | 工程常规方案 |
| S3 固定跳焊 | 当前方案 |
| **温度门控动态策略** | **V4 创新** |

**评价指标**：
$$
J = w_1 \tilde{P} + w_2 \widetilde{\Delta T} + w_3 \tilde{t}
$$

其中 $\tilde{P}, \widetilde{\Delta T}, \tilde{t}$ 分别为归一化位置度、最大周向温差、总周期时间。

**状态**：⏳ 提出，待对照实验

**明确立场**：
> 不提前标榜"AI 自适应"。只有当动态策略在同一批扰动上明显优于固定 S3，才立为创新。
