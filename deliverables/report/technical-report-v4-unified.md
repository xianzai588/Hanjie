# QT450-10 主轴承座—Q235B 壳体焊接工艺设计说明书

第一届辽宁省大学生材料焊接与铸造工艺设计大赛 · 焊接固定题

## 0 设计对象、边界与交付结论

题面对象为 Q235B 钢壳（外径 Ø160 mm、高 200 mm、壁厚 5 mm）与 QT450-10 球墨铸铁主轴承座（中心孔 Ø40 mm）的圆周连接。官方指标是焊后轴承孔轴线相对壳体基准的位置度直径 ≤ Ø0.05 mm，以及不得有可能落入内腔的焊渣或飞溅物。本说明书交付 pWPS、工装与洁净防护工程图、材料与冶金计算、全件热—结构有限元输入/结果和试制放行程序。固定题允许提交研究报告、设计图或实物，校方报名附件另行填报；试制工艺评定按§7执行。

推荐 **8P-R2-t15、两道脉冲 TIG**：八段各18 mm，总焊长144 mm；根道与盖面各一遍，名义净线能量300 J/mm，名义总净热86.40 kJ，弧燃174.5 s。选型同时比较承载、控形、冶金、洁净和节拍。在相同设计载荷谱下，8P焊缝组静态筛查应力39.13 MPa，6P为52.17 MPa；采用相同资格目标曲线时累计损伤分别为0.495和1.173。材料批次、截面与疲劳资格目标在后续A类实物试验中确认。

## 1 方案选择与工艺参数

### 1.1 工艺横向比较

外周塞焊 GMAW、激光深熔、微束等离子、脉冲 TIG 与钎焊按热输入、铸铁侧稀释风险、洁净防护、设备投资、间隙适应性与小批量节拍比较。激光和等离子热输入较低，但对壳体—座体间隙、光束可达性和铸铁快冷组织更敏感；外周塞焊洁净隔离最好，但需专用冲孔模具且疲劳细节需单独评定。钎焊可避免大范围母材熔化，但整件加热增加控形负担，使用钎剂时须另设残留隔离措施，本接头适用的交变载荷数据也需建立。脉冲 TIG 的熔滴受控、无药皮熔渣、易设置铜环，适合本题的设计样件和柔性试制线。下表按1～10分作工程决策辅助，分数越高越有利；依次采用20%、20%、20%、15%、10%、10%、5%的设计权重。

## 2 材料、冶金与裂纹控制

### 2.1 成分当量的正确使用

Schaeffler图仅在原图 Cr_eq约0～40、Ni_eq约0～30范围内读相区。原图采用 Cr_eq=Cr+Mo+1.5Si+0.5Nb、Ni_eq=Ni+30C+0.5Mn。Q235B、QT450-10和NiFe-55的成分在项目文件中作为工程输入，必须用来料光谱/质保书替换；牌号本身不提供固定化学成分。母材当量点仅作为配混起点，不用于反推供货母材原始组织。14个直接稀释对照算例按NiFe55、Q235B与QT450-10质量分数配混，明确标记图外点；图外成分用Ni–Fe–C机理文献与逐层稀释计算评价。

Kobelco《Specific 4th edition》3-7页Fig.2.3是本图域和斜向分区的原始依据：[原始技术手册](https://www.kobelco-welding.jp/images/education-center/pdf/Specific_4Ed.pdf)。Ni–Fe–C焊缝的独立研究显示，NiFe与纯Ni焊缝都可由奥氏体枝晶开始凝固，但NiFe焊缝的枝晶间可能析出渗碳体，纯Ni更有利于石墨析出；球铁热影响区仍可能形成马氏体：[Alizadeh‑Sh等，2024](https://doi.org/10.1007/s11661-024-07399-4)。移植边界：该文基材为高Si固溶强化铁素体球铁、填充为45%Ni NiFe丝与纯Ni丝，与本题QT450-10＋55%Ni组合不同，仅作定性方向证据。因此本文的冶金结论是“焊缝主体具有高镍奥氏体倾向，QT侧PMZ/HAZ仍需金相、显微硬度和裂纹检查”，不写成全熔合线单相奥氏体。

过渡层按质量守恒逐层计算，而不是把第二层视为供货棒材原始成分。Ni99采用供方WWNA99典型熔敷成分Ni99.62/C0.01/Si0.05/Mn0.17 wt%；QT与Q235仍取设计输入。第一层QT稀释10%～20%、第二层重熔首层10%～15%、最终熔池Ni层占10%～20%及钢侧占5%～10%时，计算结果如下。

| 首层Ni99/QT熔敷金属 | 0.374%～0.738% | 79.71%～89.66% | 单独控制PMZ与HAZ，不能当纯镍 |
| 第二层过渡金属 | 0.0464%～0.1192% | 96.63%～98.62% | 降低最终重熔带碳量 |

### 2.2 冷焊与随动热态轻击

TWI铸铁指南支持镍/镍铁填充、短焊道与趁热轻击[4]。本件将Ni99隔离、低热输入、≤100℃层间及缓冷共同执行；400～500℃为设计轻击窗口。18 mm焊段弧燃10.91 s，段首提前进入温窗，因此配置独立随动轴，在焊接过程中覆盖段首与段中，停弧后加速扫完段尾。枪与丝在停弧后0.20 s内同步上提40 mm，轻击结束后枪丝先升至120 mm，再升轻击头，随后抽吸刷净及转位。名义18 s段间时间包含上述动作，温控等待计入实用节拍。

按100 Hz、最小接触宽0.72及最大速度18，点距≤0.18 mm、重叠≥75%。供气压力不能直接代替冲击力；额定力、压痕宽深与温窗覆盖分别验收，缺信号或覆盖异常停止该段，不为轻击重新加热。气动尾气导入上排烟罩。

新版分材料热焓的180°对向同步候选已完成16段次轻击温窗计算，每段沿程0.5～17.5 mm均由其自身温度历程规划；轨迹上温度为422.2～464.4℃，最高扫尾速度16.29 mm/s、加速度222.2 mm/s²，停弧后最长1.12 s完成覆盖。第一段根/盖面另以0.05 s热步复核，与0.125 s温窗交叉时刻的最大差0.060 s。此项通过证明随动动作可满足设计温窗；单枪与对向方案最终按完整冷态控形、节拍及资源占用比较。实机由逐点测温触发，首件按HJ-W-02校准测温、接触力及成形。

根/盖面送丝棒端分别为R73.20/z116.00、R72.70/z116.70，棒材从电弧前侧进入，15 mm后导管转为竖直；枪—丝实际净隙2.169 mm。温窗所需间距内，实体采样并用运动位移上界补齐连续间距，扣除热态工作位姿误差合计0.10 mm及圆头径向热增长0.02 mm后，工具净隙下界0.411 mm；各工作落点标定误差≤0.05 mm。工具竖直上提由低位横臂/球心、喷嘴及远置驱动的轴向/径向分离约束保证。H13横臂按200 N峰值计算弯曲431.5 MPa、弹性挠度0.288 mm，低于600 MPa设计许用；驱动行程补偿横臂挠度，压痕深度由工件表面测量。工具材料参考Uddeholm H13原始技术数据[30]的45±1 HRC热态曲线，500℃屈服强度保守按900 MPa选材下限。

随动气动轻击架构可参照Li等[28]的装置控制思路，其TiCN熔覆性能不移植到本件；100 Hz气动往复技术参考MECCO/COUTH[29]，采购及工艺评定仍按本件圆头、热态力和压痕规格。全件位置度和疲劳核算不计轻击增益。Ni99前工序采用壳体外开放夹具和独立Z高度、直达圆头工具，按HJ-W-00/HJ-W-02确认自己的温窗覆盖，不套用组焊内腔轨迹。

## 3 接头、工装与洁净防护

### 3.1 柔顺接头与位置度路径

题面未规定轴承座厚度，本方案按15 mm设计。八条径向柔顺槽等分45°，槽宽4 mm、圆端R2、最深R39；翼片与中心环合并后的32处竖向转接棱均实际加工R2圆角，切断外缘环向收缩向孔区的刚性传递路径。主轴承孔当前焊前窗口为40.010～40.014 mm，焊后目标40.000～40.025 mm。在20±1℃、完全卸夹状态下先检位置度；位置度不合格件不得用终镗纠正轴线。修订模型以40.014 mm制造孔径起算，两级网格完全卸夹孔径上界分别为40.02892和40.02928 mm，超出目标上限；原焊前窗口不能直接冻结为生产尺寸，正在以焊前尺寸补偿和微量珩磨边界共同复核。孔轴控形与孔径验收分别判定，正式工艺尺寸由完整冷态验证确定。

控形由“柔顺槽＋精密胀套＋对称焊序＋低热输入”共同承担。 设置预载与热反力背承分开：GTAW夹持研究显示，增大夹持力不保证减小卸夹后的残余变形，因此本方案维持100 N低预载，并通过背承刚度限制轴移。[44] 芯轴刚体/可变形模型的差异亦提示必须独立验算工装柔度。[45]厚15 mm与合并后R2过渡共同改善承载刚度，整件静载校核按相同壳体安装边界和参考载荷执行，结果见§5.1。工装定心、卸夹与孔轴拟合采用相同A/B基准。微珩安排在封盖前、防护与顶部抽吸在位状态下执行，磨屑即时收集；微珩后重新做内窥与颗粒检验。

胀套为17-4PH六指开缝结构，接触带z100.2～114.8，带上弹性颈自z115.4起，Ø40.20、长30、厚0.80、有效宽≥19 mm。末端由45钢整体实心反锥全长背承，半角10°、下端R19.074/上端R16.50，带内名义最小壁0.896 mm；两端各延伸0.4，机加工长15.4 mm，覆盖最大0.284 mm设置行程。胀套根部z145.4～155.4，经上承力筒及门架的正向止挡锁止；M12仅设置及上退1 mm。100 N为预载上限，热收缩容量5000 N不作为装夹预载施加；500 N端面压环独立传力。详图HJ-006、HJ-013。

### 5.3 检测分工

PT检查表面开口裂纹。首次QT/Ni99界面、第二层和最终接头各取宏观/金相截面；HV0.3以200 μm为基础步距，窄PMZ先由金相定位，再以错列多排实现50～100 μm法向投影采样。压痕实际间距按ISO 6507-1执行，测量对角线≥20 μm，不把低于光学方法能力的压痕当有效读数；硬度须与白口层、碳化物及裂纹位置对应；UT仅在同材料对比块、频率、角度、扫查覆盖和D级特殊应用程序完成后使用——ISO 17640 本身适用域为厚度≥8 mm铁素体钢，镍基焊缝超声须按 ISO 22825 专用程序执行，因此不能用常规5 mm薄壁全熔透标准直接套用；CMM执行A/B独立基准与扩展不确定度判定。铸铁侧组织不是PT/UT可直接排除的缺陷，必须有宏观金相和硬度证据。

### 5.4 无损检查执行细则

HJ-Q-01检验卡将方法开发与工序验收分开。Ni99预制焊后≥24 h进行PT复查，组焊冷却卸夹后对八段、弧坑、两侧焊趾及邻近10 mm母材带做100%表面检查。采用同体系可见着色、溶剂去除型渗透/清洗/显像材料，如SKL-SP2＋SKC-S＋SKD-S2；在15～35℃下，本设计渗透停留15～30 min，擦除多余液体、干燥后薄层显像，于10～30 min观察记录；工位白光照度设计值≥1000 lx。供方步骤要求清洁干燥、溶剂布擦及薄层显像；本设计窗口在首件程序中确认。[26] 裂纹或线性指示拒收，其他指示清洗复查定位，保存照片、段号及处置记录。

超声采用同15 mm QT、5 mm Q235、R75曲率、Ni99层厚和两道焊缝的专用对比块，在首次QT/Ni99及最终两侧熔合线分别布置0.5 mm深、3 mm长、槽宽≤0.2 mm人工平面反射体，并保留宏观截面已定位的未熔合对照。以2与5 MHz双晶纵波、45°与60°作初始筛选，从QT顶面及壳体侧沿焊段和横向交叉、两侧入射，检查段中、端部及近表面覆盖。方法资格目标为所有目标反射体最大声程信噪比≥12 dB、重复幅度差≤2 dB；选定方案保存增益、参考曲线、探头/楔块与覆盖图，记录阈值取参考曲线−6 dB。人工反射体和阈值均为本设计目标；ISO 22825:2017规定镍基及异种接头的方法开发路径，本身不提供验收等级。双晶纵波的晶粒噪声控制方向参考TWI奥氏体钢研究，不转写成QT/NiFe接头检出性能。[27] 平面缺陷拒收，覆盖不足或几何回波无法区分时调整检测工艺，完成资格后再进入生产WPS。

PT和耦合剂检查使用独立检验接料盘遮蔽下腔，检查后擦洗、干燥并清点回收物，再做过滤膜与内窥检验，防止检测工序引入化学残留和颗粒。首次界面的白口/碳化物网仍按宏观金相与HV评定。

## 6 自动化、节拍与安全联锁

沿线移动的焊接机器人、固定定位窝、双路温度、弧压/电流/送丝采样、气幕/保护气流量、水路泄漏、气幕歧管压力和夹具位移共同接入安全PLC；焊段识别与跟踪以 HJ-001 的 C 周向标记为视觉基准——起弧前相机复核段位与间隙，施焊中激光焊缝跟踪偏差超阈值即停弧，不依赖示教轨迹的离线复现。缺少任一温度、气流、漏水、底口、防护、夹紧或轨迹信号，起弧拒绝；停弧后≥120 s且热区<55℃、压环卸载、胀套回退1 mm、四瓣密封径向回缩1.10±0.05 mm条件满足且上止挡张开、胀套上提260 mm反馈和A基准托环锁止齐全后，才允许壳体连托环上提140 mm。

跟踪设备按横向偏差≤0.05 mm、分辨率≤0.01 mm、更新频率≥50 Hz选型，越限或信号中断立即停弧并保持工装与防护。起弧前视觉检查0.01～0.04 mm装配间隙；首件以标准间隙块、段位标记及真实弧光条件校准跟踪能力。上述数值为工作站设计控制值，按设备验收程序确认。

PLC按“装夹确认→首次起弧→段间续焊→保持冷却→撤内托→保留壳底冷却→全部卸夹检测”状态执行。下表为I/O与状态判据；模拟门控函数对应这些判据，工作站制造时逐路做断线、越限和执行反馈试验。

两道8段的弧燃174.5 s；焊接站还承担16段热态轻击、清理和转位，名义焊接站工作约462.5 s，温控等待另计。装配和CMM各按120 s设计；PT与UT的占用单列；按§4的热场释放时刻、转运时间和冷却时间配置定位托盘与环境缓冲位。工作站图HJ-008给出工位及资源关系，实际出件间隔由焊接、冷却资源和检测三者中的瓶颈确定。

对向双头候选采用同一8P两道和总能量，其累计弧燃仍174.5 s、同时施焊时间87.3 s、八阶段名义站占用231.3 s。对应配置两套电源、送丝、随动轻击及测温链，合计保护氩气16～24 L/min；每头分别确认保护气8～12 L/min、热输入与路径，缺一路信号即停止两头。按相同检测时间输入需18个PT等待位、3个UT工位、1个CMM、8个洁净检验位置及8个总检测人员当量，不能沿用单头的投资和下游资源。最终选型以完整冷态控形精度和上述占用共同决定；小批量线按实际需求配置工位，未配置并行检测时，以检测瓶颈确定出件间隔。

检测节拍不以CMM的120 s代替全部NDT。PT工位按施液2 min、擦除/显像2 min、判读2 min、检后擦洗2 min配置人员操作，另加渗透15～30 min和显像10～30 min，单件历时设计为33～68 min。按462.5 s出件间隔、68 min占用上界，配置至少ceil(4080/462.5)=9个PT隔离等待位；化学品操作区与CMM清洁区分开。专用UT每件按600 s作设备容量设计输入，至少两工位并行；CMM每件120 s为独立环节。HJ-Q-02提取、过滤、干燥及全膜扫描另按1800 s设备/位置占用、480 s人员操作设计，至少4个并行位置并配足扫描能力。总检测人员操作为PT480＋UT600＋CMM120＋洁净480=1680 s，维持上述出件间隔需至少4个人员当量。疑似颗粒成分复核及首件方法资格另计，实际首件以计时修正容量。小批量单工位试制可以顺序完成，单件总历时完整计入热冷却、NDT及整腔洁净检验，不把462.5 s称为整件完成时间。

Ni99预制在独立前工序完成：两层×八段名义弧燃144 s、净热44.35 kJ；按16次各18 s轻击、清理和转位，单头预制站占用下界432 s，温控等待、装配和24 h延迟PT另计。全流程累计弧燃为144＋174.5=318.5 s。若按单头组焊462.5 s供料，至少1个预制焊站；按双头候选231.3 s供料，至少2个单头预制焊站，实际温控使占用增加时继续按产能补齐或延长出件间隔。以8 h单班、次日同一时刻供料安排24 h延迟检验库存，单头/双头组焊分别至少63/125件；小批量按真实订单批次预制，不要求满负荷维持上述库存。

预制PT通过后再精加工连接面及孔、清洗封存，以合格座体库存供应组焊工位。HJ-W-00送丝初值为首层7.4、第二层11.3 mm/s，按Ø1.20棒、2.0 mm/s焊速及6 mm覆盖宽计算，与首层0.60～0.70、第二层0.90～1.10 mm目标闭合。预制、机加工、延迟检验和组焊分站列示；单件从铸件到完成检验的历时包含这些工序及所有等待。本方案面向小批量柔性试制，设备数量和出件间隔由订单、温控和检测容量共同确定。
