# 整改执行计划：一条主线、三个工程接口

更新：2026-10-06。按用户最新要求收束任务。本轮唯一主工程路线为：**独立高镍预制解决铸铁首次连接，8P低热输入GTAW控制最终焊接变形，铜环实体屏障保护内腔洁净。** 方案方向确定，性能通过状态由相应计算与检验决定。

## 1. 完整工序

壳外QT座体备料与开槽 → CI-A1高镍MMA首层 → 首层法向修整 → 低碳Ni99第二层 → 缓冷、连接面修整及最终孔加工 → 清洗干燥与预制件检查 → 装入壳体、胀套定心和铜环屏障就位 → 8P对称跳焊 → 带防护冷却 → 完全卸夹、受控退工具 → 孔形、连接与洁净检查。

独立预制允许采用适合铸铁的预热与缓冷，热加工及切屑清除在精密孔最终加工、入壳之前完成。最终组焊将热量集中用于镍过渡层与钢壳连接。铜环、静密封和接料盘封闭落物路径，气幕及顶部排烟辅助收集，防护保持到残留物受控收集和退工具完成。

## 2. 三项任务及交付接口

| 主任务 | 已选设计与向后交付 | 必须闭合的证据 |
| --- | --- | --- |
| 独立高镍预制 | CI-A1首层、冷态法向保留0.70±0.05 mm、低碳Ni99第二层；交付清洁、加工完成且保留层明确的座体 | 首次QT界面连续连接、PMZ与裂纹控制、第二层重熔及最终连接存留；实际切削后的残余状态进入组焊 |
| 8P低热输入GTAW | 8P-R2-t15、两道、1→5→3→7→2→6→4→8、柔顺槽与内锥胀套；交付完全冷却卸夹的连接件 | 先满足双侧连续有效连接，再核验孔轴、孔径、槽根及接头承载；净250～350 J/mm是待确定窗口 |
| 铜环实体屏障 | 导热/水冷铜环＋静密封＋接料盘；辅助上升气幕与顶部排烟；交付受控退工具后的干态内腔 | 热/机械完整性、全周封闭与退出路径、无新增磨屑；按既有洁净标准检查，后序局部用液遵守HJ-018回流边界 |

焊后孔轴判据不变：需有限微珩时28+2+6.5+P≤50 μm，P≤13.5 μm，径向去除≤3 μm；内部热轴设计目标12 μm。仅无去料且孔径直接合格时可用20 μm分支。禁止焊后精镗修正位置度。

## 3. 接下来只按这一个顺序推进

1. **先关闭预制接口。** 复用已完成的材料、曲面CAD、质量/能量与升温结果，只针对CI-A1一翼检查空间热源适用性、起停端连续连接、层间重熔和保留层。先排除物理输入错误，再作必要的离散检查。不同材料、更多炉温及通用求解器开发停止扩展。
2. **再关闭8P控形接口。** 使用合格局部接头和真实加工后状态，完成最终焊接、冷却、完全卸夹及同状态承载。局部修订只围绕熔合、热输入、对称顺序和现有工装约束。关键响应离散差≤5%且绝对余量明确后立即固化云图与表格。
3. **完成屏障与整线接口。** 复用铜环/盘体及已修订液路，核对焊接至退出全过程；将预制离线时间、组焊占用和检测瓶颈写入一张工序表，不把纯弧燃时间当整线节拍。
4. **统一比赛交付。** 主说明书按三个问题解释工程方案，WPS、装配图、检测卡使用同一接口。旧失败算例集中用来说明修订原因；只有通过证据进入达标结论。

CI-A2、6P、全周焊、外塞焊、激光和微束等离子仅保留已有横向比较及备用依据，不安排并行计算。只有主路线在适用物理模型和合理工艺修订后仍不能满足硬指标，才记录具体失败接口，激活一个对应备用方案。单个未收敛算例或两档温度失败不能代替路线判定。

不继续增加材料库、炉温矩阵、蒙特卡洛、代理排名或通用算法。需要的新工作必须直接改变上述一个接口的工程决定。源文件和历史结果保留，历史任务表不再构成当前待办。

## 5. 当前事实与唯一近期任务

已完成名义曲面保留层、首层物料/热量、炉内升温及铜环配套后序全管回流容量等子项。尚未完成新主线的首次连续连接与完整制造验证。旧制造结果约52.084 μm超过50 μm且离散误差超限，保留为修改依据；不沿用其通过结论。

**唯一近期计算任务：CI-A1一翼A/B/C三工况。** A为200℃、1.215 kJ/mm；B为300℃、1.215 kJ/mm；C为300℃、1.03275 kJ/mm（−15%）。焊速采用文献100 mm/min，净功率分别2025/2025/1721.25 W，包含熔滴进入焓。来源为El-Banna等2000表3（DOI 10.1016/S0167-577X(99)00204-9）。这是同类工艺热输入锚，不宣称已标定本件热源空间尺度。产品目录和Pascual 2009分别支持产品工艺范围与球铁高镍SMAW方向。

只计算本座体一个翼片的首层沉积，保留QT座体真实热容量，不装壳体。复用R1.5曲面和质量闭合沉积包络；空间分布与包络形状仍是明确的模型假设。报告连续带、QT侧有限熔化深度、起停非有效长度和热循环。端部不自动计入有效连接，得到所需余量后检查实体能否容纳；不能用删掉失败采样点保住18 mm有效区。几何不足时优先考虑预加工余翼或错位重叠短道，再决定材料切换。

A/B/C是最多三个设计决策工况，不代表完成+15%热输入、物性扰动或全部离散验证。B/C的有效区和局部响应若支持同一设计决定，推进制造验证；若物理适用且离散可信仍不能形成可实施有效区，结束CI-A1这轮并仅复核CI-A2。温区越界或数值失败先归为模型问题，不伪装成材料失败。

制造推进与完整强度分别判断：热熔合几何、存留层和用于变形计算的热机械物性/连接边界具备依据后，即可继续预制残余状态、实际切削、第二层、组焊及孔形计算。PMZ容量待定仅阻止完整强度与最终达标发布；它不单独阻止制造链。最终发布仍需有效接头、精度和完整承载证据。


本轮执行记录：净能量修正后的A/B/C已实际执行，均在起弧局部触发当前温区限制，不能按材料失败裁决；CI-A2一次参考检查亦出现同类模型限制。前期低实际入热的完整历史已排除出采用依据。当前保持进行中，只修正沉积包络和有效源模型的适用性，不追加候选矩阵，也不以此转为项目外部受阻。
