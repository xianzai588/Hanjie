# 最小修复与参赛路线

冻结日期：2026-10-06。用户已确定无实物，按焊接固定题说明书、设计工艺规程及工程图路线执行；实物试验写作后续车间确认，不伪造已完成记录。冻结的是修复顺序，不是宣布MMA、8P或285 J/mm已经通过。

## 1. 最小改动的主路线

**独立镍系预制 → 连接面及最终孔加工 → 八段对向低热输入自动GTAW组焊 → 冷却与完全卸夹 → 同残余状态承载 → 工艺说明书与工程图发布。**

保留8P-R2-t15真实座体、柔顺槽、独立A/B、实心反锥、锁止胀套和铜环/气幕/封闭回收。保留全宽槽1.50±0.10、加工后总层1.40～1.60、第二层≥0.50的几何接口。微珩≤3 μm、热轴13.5 μm和完整50 μm预算不放宽。

先修复首次QT界面，连接合格后才复算整体；不推倒夹具、不回退18×6矩形槽，不扩大相同热源的功率矩阵。旧39.49孔/0.25 mm径向终镗、薄裙贴壁、图外当量组织结论不恢复。

## 2. 少量候选与换路线条件

| 路线 | 最低成本判别 | 决断条件 |
| --- | --- | --- |
| A，优先验证：独立高镍MMA预堆，随后自动GTAW | 所选产品成分/极性/电流表；一翼真实槽两层分条覆盖、边缘起收弧、连续首次熔合、QT冷却组织与界面容量 | 只保留200℃、300℃两种均匀预热探针；两者均不能满足接头/后序条件即转B，不扩电流矩阵 |
| B，结构备选：外塞焊 | 8翼每翼2孔、16×Ø6、壁5、R75的有效面积与压力壳密封/可达/内侧熔透风险 | 孔位/孔边距、实际熔合、外圆过渡层及配合独立设计；不把顶部浅槽挪作外塞焊接头 |
| C，对照：已有GTAW预制 | 现有350 W局部短道、预热与600 W超温边界 | 保留失败作为选型依据；没有新设备/热源依据不扩大同源扫描 |

A的200/300℃是Kobelco镍焊条低温预热100～300℃范围内的项目候选，不是已评定窗口。只在孔精加工、入壳之前预制，允许清渣和彻底清洗；独立预制道间/缓冷按具体焊材和热循环确定，不套最终≤100℃温度门。

本轮已核实原厂CI-A1成分和Ø3.2的80～130 A、AC/DC+输入，重新执行含碳熔敷材料相平衡及两种真实座体升温计算。修订接口为首次CI-A1 MMA→首层中间修整0.70±0.05→原低碳Ni99第二层；见[无实物设计执行稿](report/design-only-execution.md)及[HJ-W-00C](process/independent-precoat-design-card.md)。UTP的冷焊≤60℃道间不与Kobelco温焊拼用。升温复验仅验证预制热制度，不代替首次熔合或整件控形。

首次QT连续熔合、全翼覆盖、有效面积、第二层及最终双侧熔合、残镍层和PMZ容量必须同时成立。供方全焊缝拉伸、Ni200轧材和FCC平衡比例均不能代替首次QT界面容量。

没有可信MMA热源与熔敷输入时先解决输入，不能把旧GTAW热源改名后宣布MMA通过。药皮镍焊条也不能沿用裸Ni99/C0.01%材料表。具体采购未定之前不发布生产电参数。

B的16孔只作需求探针，不是已采用接头。外壁施工缩短内腔飞溅路径，但直接QT界面冶金仍须解决，熔透孔也不是天然完全隔离。若压力壳、孔边距或内侧洁净无法满足，淘汰该接口。

## 3. 四工艺的公平比较

执行`python deliverables/competition-route-probe.py`生成`route-probe-results.json`。它算的是需求、已有TIG热量、预热显热和排液容量，不算或宣称焊缝资格。

本轮已执行的统一圆环组需求模型：I=A·R²/2，轴向峰值Fa/A+2M/(A·R)，横向平均Fr/A，二者向量模作为连接需求；它不是局部VM，也不是原稿焊缝组应力的同一公式。Fr=Fa=5000 N、M=250000 N·mm、R=75下：

| 接口需求探针 | 假定有效面积mm² | 峰值合牵引需求MPa |
| --- | --- | --- |
| 6P、焊脚下界3.50 | 267.286 | 47.488 |
| 8P、焊脚下界3.50 | 356.382 | 35.616 |
| 16×Ø6有效圆面 | 452.389 | 28.058 |

16孔填满5 mm壳厚需新增体积约2261.947 mm³；尚未证明这些圆面确为有效连接，所以不能按较低需求宣布外塞焊胜出。约0.996 kg未开浅槽座体按现有工程Cp积分，20→200/300℃存储显热约86.972/139.523 kJ，未计夹具、沉积层及炉损，也不代表实际预热时间。

已执行真实液路容量为125.781 mL/min、Re136.88，对两倍供液120的余量4.82%；独立数值求根核对压力损失合计2000 Pa。降到1.8 kPa不满足两倍余量，因此应控制杯口至瓶入口净差压，不能只看杯负压表。

| 方法 | 同等比较接口 | 必须补齐的实际输入 |
| --- | --- | --- |
| 外GMAW/激光塞焊 | 16×Ø6实际熔合面，R75，壁5 | 孔位/有效直径、全深连接、焊材、密封、背面屏障、净热/单孔时间 |
| 激光深熔焊 | 与8P有效焊喉和半径对齐，不仅比焊脚 | 激光类型、实际光斑/焦点、耦合、加丝、连续熔合和内腔隔离 |
| 微束等离子 | 同等有效焊喉、144 mm连接长度 | 喷嘴/弧模式、峰基波形、气路、耦合、焊速和实际熔敷 |
| 脉冲GTAW | 8×18，两道，焊脚下界3.50 | 285/300仅候选；双侧融合和残层先验证；波形与平均热源分开 |

比较原始指标：有效面积、新增金属、净热、前后工序弧燃与占用、检验容量、设备/耗材成本、飞溅隔离。未知报价列设备清单/询价项，不填写猜测金额；未知焊速不填“预计超快”。不使用任意权重雷达图裁决。

当前GTAW宽道基线预制88.704 kJ、144 s，组焊86.4 kJ、174.5 s，两者都计入总工艺，不因分站消失。预热显热不是炉电耗，不能据此写预热节拍。双头231.3 s只是焊站间隔，整线节拍须包含CMM、PT/UT及微珩容量。

## 4. 接头合格之后的最少制造验证

1. 全翼覆盖与最小真实连接面积确定后，反馈显式镍层及首次PMZ容量；不沿用满片出生即连接，不调大弹簧许用制造通过。
2. 保存预制应力、塑性及出生参考；连接面/孔加工仅移除实际材料并重新平衡，不把机加工等同应力清零。
3. 制造家族至少基准、独立空间加密、独立时间加密、同网格孔径下界四项；间隙/温度/接触内部出现分支变化时补关键点。
4. 工具传热域按现有分级复核，响应差≤5%，且离散/物性误差不吃掉绝对位置度余量；达标后停止，不沉迷求解器。
5. 全部解除孔内工具、上压环、铜环/盘和壳底，独立A/B评价；需微珩时28+2+6.5+P≤50 μm且P≤13.5，孔径和去除上限也同时满足。
6. 同一制造残余状态下加载卸载，检查主拉、塑性增量、槽根/焊趾/PMZ及卸载孔形。载荷Fr=Fa=5 kN、M=250 kN·mm明确为设计工况，疲劳反推资格不冒充实测寿命。

旧1200℃全材料瞬时塑性清零不能直接带入采用路线：材料出生、液化丧失偏应力、固态回复分开。缺退火动力学时用有据边界比较，不因日志能重建就认可物理历史。

计算预算：A仅两个局部热制度探针，B一个结构需求探针；未取得接头资格不做整件长时重算。其后一次一个重型任务，四项主家族之外的计算必须回答明确敏感性问题。预算不是保证几次就能过；硬约束失败即修订物理方案或换路线。
