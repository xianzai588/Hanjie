# HJ-Q-01 异种接头无损检查设计规程

排液方法边界：HJ-Q-03/HJ-018孔成形牛顿液的154.5 mL/min管路容量不移植到非牛顿UT凝胶。PT/UT按每次≤5 mL定量施液，下一次施液前抽尽并原位干燥；凝胶采用专用回收程序，不以杯负压表或短孔流量代替方法资格。

组焊后PT/UT采用HJ-Q-02独立闭底接液盘及孔口堵盖，液体、显像剂与耦合剂不得进入不可清洗内腔。盘最小有效容积47.7 mL；ID上限4.10、湿段≤1 m满管回流13.2，加完整5 mL定量批、上罩/接头1及储备2，故障需求21.2 mL。下一批施液前排尽并原位干燥；不套孔成形0.10 s停机进液量，也不以牛顿流量认证凝胶排液。表中表面清洗限于独立座体前工序或封闭检测区，操作异常隔离，不整腔清洗补救。

对象：QT450-10 / CI-A1首层 / 低碳Ni99第二层 / NiFe55 / Q235B主设计接头，接口按HJ-W-00C/00D及HJ-W-01统一；8×18 mm实际路径、稳定有效8×16 mm、两道角焊缝。首次QT界面、层间与最终两侧分别为检测对象。方法资格由具有相应资质的检测人员完成并形成首件检查记录。

| 工序 | 执行与验收要求 |
| --- | --- |
| VT与尺寸 | 100%检查八段、两端弧坑、焊趾及邻近母材；每段实际18 mm内扣两端各1 mm后稳定有效16 mm，稳定区最低焊脚≥3.80 mm、局部有效喉厚≥2.69 mm（3.80/√2的工程取值），双侧连续熔合。宏观截面分别量不等焊脚、凹陷后的最小有效喉部、镍侧及钢侧连接，不以总增重或几何面积代替。总层1.40～1.60及首层法向保留0.65～0.75；平直区累计重熔≤0.40时几何总残层≥1.00、第二层≥0.25，圆角及实际成分过渡区另检查。裂纹、烧穿、未填弧坑进入工艺评审，不自动补焊。 |
| PT时机及范围 | 首层按规定缓冷至室温、法向修整后做冷态PT，合格再进行第二层；第二层全部焊道完成并按规定缓冷，记录工件降至室温的时刻，以该时刻为起点单列≥24 h终端延迟PT，合格再进入连接面及孔预加工；最终组焊冷却完全卸夹后PT。覆盖各段焊道、弧坑、两侧焊趾和邻近10 mm母材带；表面清洗干燥，无油污、氧化层和遮盖层。 |
| PT材料与窗口 | 同体系可见着色、溶剂去除型渗透剂/清洗剂/显像剂，如SKL-SP2＋SKC-S＋SKD-S2或经确认的等效组合。15～35℃，本设计渗透停留15～30 min，擦除多余渗透剂，干燥后薄层显像；显像10～30 min内观察并记录，禁止用强溶剂冲洗检查面。白光照度≥1000 lx为本工位设计验收值。 |
| PT判读与处置 | 裂纹或线性指示拒收；圆形/成串指示清洗复查定位，分清开口缺陷与铸铁表面背景，由检测与工艺人员记录处置；禁止把模糊背景直接记为无缺陷。检查前后清点物料，清除化学残留并完成后续颗粒/内窥检查。 |
| UT对比块 | 按ISO 22825编制本接头专用程序。对比块采用相同材料批次/组织、15 mm座体、5 mm钢壳、R75曲率、独立首层/第二层厚度与两道焊缝。分别在首次QT/CI-A1界面、最终镍侧及钢侧熔合线设置0.5 mm深、3 mm长、槽宽≤0.2 mm的人工平面反射体；同时保留已定位宏观截面的未熔合对照。尺寸为本设计方法资格目标，非ISO规定的验收等级。 |
| UT初始选型 | 2与5 MHz双晶纵波、45°与60°方案作对比块筛选；扫查从可达的QT顶面及壳体侧进行，沿段长和横向交叉、两侧入射，覆盖段中与弧坑。以实际试块证明声束入射、近表面盲区、衰减与几何回波，选取最终频率/角度/焦距。 |
| UT资格与记录 | 所有目标反射体在最大声程下信噪比≥12 dB、重复幅度差≤2 dB，扫查覆盖完整；这些是本设计资格目标。保存参考曲线、增益、探头/楔块、入射位置和覆盖图。记录阈值取参考曲线−6 dB，定位指示至焊段/深度/长度；疑似平面缺陷拒收并复核。不可识别的几何回波或覆盖缺口先调整检测工艺，不直接进入生产WPS。 |
| 后续工序隔离 | HJ-015闭底整盘OD149.40±0.05、壁厚1/底厚2，盘面z96、唇口z99，独立外部支架定位；缩态密封外径≤149.6，从壳底竖直装入，就位后以20～30 kPa充气贴合壳壁，不沿壳壁滑擦。Ø4排液至独立瓶，PT棉签定量施液、UT定量耦合；失吸/密封压异常停止施液并保持盘就位。完成后抽尽、原位干燥、封回液口，壳底对接密闭收集筒，保持盘朝上与抽吸，泄压缩径后整盘竖直向下撤出。整盘与孔成形下杯分工序装入，不同时叠放。正常件执行干态内窥和封存；过滤膜/整腔提取仅用于全周期未清洗牺牲件。无损检查不能替代首次界面金相/HV评定。 |
| 安装与撤出详图 | HJ-016：壳体先脱离固定焊接芯轴，转入独立NDT托环。加厚环裙z88～97/壁2，槽中心z93、宽6.20±0.05、径向深0.75±0.02，模压密封扣脚＋分瓣压圈；Ø1充气口/焊接Ø2管与Ø4排液分路。支杆Ø12×258，双导向距50，偏心≤0.10/倾角≤0.05°，升降额定200 N。收集筒ID152.00±0.05、顶z−20/底z−170，法兰OD174与OD180托环底面端封；行程125±0.10、波纹管额定130，整盘收入筒内后封口脱开。扣除加厚圈的有效接液容量47.73 mL；正常产品下腔不作整腔清洗。 |

依据：ISO 3452/GB/T 18851；ISO 22825:2017用于镍基与异种焊缝方法开发，标准不包含验收等级。PT材料步骤参考Magnaflux SKL-SP2 2025-07及SKD-S2 2023-11原始TDS；15～30/10～30 min和照度为本设计工位窗口。TWI 2008双晶纵波研究针对奥氏体不锈钢，支持降低晶粒噪声的方向，不把其检出性能移植成QT/NiFe接头实测结果。

第二层终端延迟PT采用本设计24 h检查窗口，从工件完成缓冷并降至室温的记录时刻起算，不与冷却历时重叠。首层冷态修整后PT检查修整面开口缺陷，第二层终端PT检查两层预制热循环结束后的可达表面；埋藏首次界面按宏观/金相与专用UT评价。按HJ-P-01配置一次24 h等待和24个隔离位，最终组焊按本卡冷却完全卸夹后检查。控温、缓冷及裂纹控制依据正文文献[3–6,28,29]；24 h为本设计窗口，不作为上述来源规定的逐层等待要求。

专用UT资格通过后逐件执行内部缺陷检查；600 s/件仅为工位容量规划输入，实际声束覆盖、检出能力和计时确认后冻结。首件宏观/金相/HV验证冶金与工艺，PT检查开口缺陷，两者不能逐件替代内部检测。对比块或覆盖不满足要求时，调整检测程序、可达性或接头并重新资格，覆盖缺口不得直接判合格。

HJ-020增加壳体外侧R80、z114～135扫查带，逐段18mm及端部各2mm。顶面4mm足迹、中心R≤69及60°情景最多到R71.60，外侧约3.38mm须由外侧路径交叉覆盖。22.04mm最远几何声程只用于可达预检，实际折射声束与浅层盲区按同材料曲率对比块核定；首次、层间、最终镍/钢侧及圆角/端部均分别记录。

## UT探头包络与薄层方法资格

保留已有2/5 MHz双晶纵波和45°/60°起点，在同曲率对比块中确定一套主探头及必要的一套补充声路。顶面接触鞋的径向足迹设计≤4 mm、周向≤8 mm，中心R≤69；探头壳体、楔块、电缆和供耦合接头均列实际外包络。壳外接触鞋按R80曲率配作，扫查带z114～135完整保留。4 mm是顶面可达设计约束，采购及程序记录填写实际接触鞋尺寸，不能将它写成已有探头实测参数。

| 目标区 | 深度/层距与声路 | 方法资格记录及判据 |
| --- | --- | --- |
| 首次QT/CI-A1、槽底及圆角 | 平直区相对加工齐平面的法向深度1.40～1.60 mm，首层厚0.65～0.75；顶面覆盖内侧、壳外补外缘3.38 mm及端区 | 反射体位于该目标界面，记录真实声速、折射、最小/最大声程和近表面盲区；槽底、圆角和两端各留独立反射体/截面定位对照，不以层间天然回波代缺陷 |
| 首层/第二层及分道重熔区 | 平直区首层上界相对齐平面深度约0.65～0.95 mm，按实际槽深和留层确定；两界面间隔仅0.65～0.75 mm，分别制块/设门 | 在实际薄层深度分别确认目标反射体可识别及定位，不将0.5 mm人工槽跨越两界面后的一次回波当作两层均覆盖；保留无缺陷背景和相邻层界回波对照 |
| 最终镍侧/钢侧及焊根 | 两道焊缝稳定16 mm、最低有效喉厚2.69 mm，累计重熔上限0.40 mm；从顶面及壳外交叉入射 | 根道/盖道后缺陷分别定位；记录实际探头包络与焊趾净隙、壳体5 mm声段、曲率及不同材料声速产生的折射，不以22.04 mm直线声程替代 |
| 两端、弧坑及局部几何变化 | 实际18 mm和两端各2 mm周围扫查覆盖，稳定区与过渡区分列 | 对应反射体在至少一条已资格声路下可识别，实际接触鞋/电缆不遮挡段端；覆盖图注明探头中心范围、步距、角度及盲区边界 |

所有目标反射体仍采用最大声程SNR≥12 dB、重复幅度差≤2 dB和完整覆盖目标。对比块把缺陷位置与宏观截面同号绑定，记录人工反射体是否保持单一界面定位；近表面盲区超出目标、无法区分背景或足迹不满足几何时，修订声路/检测可达性后重新资格。生产600 s/件按冻结的实际程序计时。方法资格和检出结果由首件实测记录确认。
