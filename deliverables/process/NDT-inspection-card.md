# HJ-Q-01 异种接头无损检查设计规程

排液方法边界：微珩牛顿液的125.781 mL/min管路容量不移植到非牛顿UT凝胶。PT/UT按每次≤5 mL定量施液，下一次施液前抽尽并原位干燥；凝胶采用专用回收程序，不以杯负压表或短孔流量代替方法资格。

组焊后PT/UT采用HJ-Q-02合格局部接液罩及孔口堵盖，液体、显像剂与耦合剂不得进入不可清洗内腔；表中表面清洗均限于独立座体前工序或封闭检测区，操作异常隔离，不整腔清洗补救。

对象：QT450-10 / 两层Ni99 / NiFe55 / Q235B；8×18 mm、两道角焊缝。方法资格由具有相应资质的检测人员完成并形成首件检查记录。

| 工序 | 执行与验收要求 |
| --- | --- |
| VT与尺寸 | 100%检查八段、两端弧坑、焊趾及邻近母材；宏观截面确认焊脚≥3.50、过渡残层≥0.80、表层界面距离≥0.10 mm。裂纹、烧穿、未填弧坑进入工艺评审，不自动补焊。 |
| PT时机及范围 | Ni99前工序焊后≥24 h复查；最终组焊冷却卸夹后检查。覆盖各段焊道、弧坑、两侧焊趾和邻近10 mm母材带；表面清洗干燥，无油污、氧化层和遮盖层。 |
| PT材料与窗口 | 同体系可见着色、溶剂去除型渗透剂/清洗剂/显像剂，如SKL-SP2＋SKC-S＋SKD-S2或经确认的等效组合。15～35℃，本设计渗透停留15～30 min，擦除多余渗透剂，干燥后薄层显像；显像10～30 min内观察并记录，禁止用强溶剂冲洗检查面。白光照度≥1000 lx为本工位设计验收值。 |
| PT判读与处置 | 裂纹或线性指示拒收；圆形/成串指示清洗复查定位，分清开口缺陷与铸铁表面背景，由检测与工艺人员记录处置；禁止把模糊背景直接记为无缺陷。检查前后清点物料，清除化学残留并完成后续颗粒/内窥检查。 |
| UT对比块 | 按ISO 22825编制本接头专用程序。对比块采用相同材料批次/组织、15 mm座体、5 mm钢壳、R75曲率、Ni99层厚与两道焊缝。分别在首QT/Ni99界面、最终镍侧及钢侧熔合线设置0.5 mm深、3 mm长、槽宽≤0.2 mm的人工平面反射体；同时保留已定位宏观截面的未熔合对照。尺寸为本设计方法资格目标，非ISO规定的验收等级。 |
| UT初始选型 | 2与5 MHz双晶纵波、45°与60°方案作对比块筛选；扫查从可达的QT顶面及壳体侧进行，沿段长和横向交叉、两侧入射，覆盖段中与弧坑。以实际试块证明声束入射、近表面盲区、衰减与几何回波，选取最终频率/角度/焦距。 |
| UT资格与记录 | 所有目标反射体在最大声程下信噪比≥12 dB、重复幅度差≤2 dB，扫查覆盖完整；这些是本设计资格目标。保存参考曲线、增益、探头/楔块、入射位置和覆盖图。记录阈值取参考曲线−6 dB，定位指示至焊段/深度/长度；疑似平面缺陷拒收并复核。不可识别的几何回波或覆盖缺口先调整检测工艺，不直接进入生产WPS。 |
| 后序隔离 | HJ-015闭底整盘OD149.40±0.05、壁厚1/底厚2，盘面z96、唇口z99，独立外部支架定位；缩态密封外径≤149.6，从壳底竖直装入，就位后以20～30 kPa充气贴合壳壁，不沿壳壁滑擦。Ø4排液至独立瓶，PT棉签定量施液、UT定量耦合；失吸/密封压异常停止施液并保持盘就位。完成后抽尽、原位干燥、封回液口，壳底对接密闭收集筒，保持盘朝上与抽吸，泄压缩径后整盘竖直向下撤出。整盘与微珩下杯分工序装入，不同时叠放。正常件执行干态内窥和封存；过滤膜/整腔提取仅用于全周期未清洗牺牲件。无损检查不能替代首次界面金相/HV评定。 |
| 安装与撤出详图 | HJ-016：壳体先脱离固定焊接芯轴，转入独立NDT托环。加厚环裙z88～97/壁2，槽中心z93、宽6.20±0.05、径向深0.75±0.02，模压密封扣脚＋分瓣压圈；Ø1充气口/焊接Ø2管与Ø4排液分路。支杆Ø12×258，双导向距50，偏心≤0.10/倾角≤0.05°，升降额定200 N。收集筒ID152.00±0.05、顶z−20/底z−170，法兰OD174与OD180托环底面端封；行程125±0.10、波纹管额定130，整盘收入筒内后封口脱开。扣除加厚圈的有效接液容量47.73 mL；正常产品下腔不作整腔清洗。 |

依据：ISO 3452/GB/T 18851；ISO 22825:2017用于镍基与异种焊缝方法开发，标准不包含验收等级。PT材料步骤参考Magnaflux SKL-SP2 2025-07及SKD-S2 2023-11原始TDS；15～30/10～30 min和照度为本设计工位窗口。TWI 2008双晶纵波研究针对奥氏体不锈钢，支持降低晶粒噪声的方向，不把其检出性能移植成QT/NiFe接头实测结果。

专用UT资格通过后逐件执行内部缺陷检查；600 s/件仅为工位容量规划输入，实际声束覆盖、检出能力和计时确认后冻结。首件宏观/金相/HV验证冶金与工艺，PT检查开口缺陷，两者不能逐件替代内部检测。对比块或覆盖不满足要求时，调整检测程序、可达性或接头并重新资格，覆盖缺口不得直接判合格。
