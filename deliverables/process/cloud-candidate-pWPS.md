# HJ-W-01-C285 云端候选设计规程

修订C1，设计审阅卡。对象为QT450-10座体15 mm与Q235B壳体5 mm，八段各18 mm、两道对向GTAW。此卡对应285 J/mm候选计算输入；完成控形、冶金连接、同残余状态承载和制造内部区间核验后确定正式选型。6P、8P与连续方案保留比较，不以本卡预定胜出。

| 项目 | 候选值与工程执行要求 |
| --- | --- |
| 前工序 | 按HJ-W-00预制两层Ni99，24 h PT后加工连接面和孔、清洗干燥；第一次QT/Ni99熔合单独评价PMZ/HAZ |
| 接头层厚 | 加工后总Ni99≥1.20 mm、第二层≥0.50 mm；根道重熔设计上限0.30 mm、两道重熔并集≤0.40 mm，最终剩余总层≥0.80 mm；厚度、熔合与稀释分别记录 |
| 方法与填充 | 自动脉冲GTAW/DCEN、NiFe-55类Ø1.60±0.01 mm实心棒；送丝3.50±0.05 mm/s、焊速1.65 mm/s±2%；Ar99.999%、名义10 L/min |
| 候选电参数 | 峰95/基47.5 A、占空50%、20 Hz、名义12 V，平均71.25 A；为285 J/mm净能量对应的设计电参数，尚未经电弧/熔池标定，不能把平均热源计算称为波形熔合验证 |
| 能量定义 | 毛弧能518.182 J/mm；η=0.55时净285 J/mm，净功率470.25 W/头；在线能量积分瞬时U(t)I(t)，η是模型假设，实际波形或η改变须重新标定 |
| 焊序/节拍 | 根道1/5→3/7→2/6→4/8、盖面同序；每对同时焊18 mm，用时10.909 s，段对间名义等待18 s；累计弧长288 mm、累计单头弧燃174.545 s、双头同时弧燃87.273 s；末次停弧时刻213.273 s，冷却/卸夹另计，不把弧燃时间当整站节拍 |
| 总能量 | 名义82.080 kJ；段1两道各+5%输入不平衡时82.593 kJ。候选求解器保留此不平衡 |
| 成形与熔合 | 根道几何焊脚2.8、盖面总4.0 mm；NiFe/Ni99及NiFe/Q235两侧都须连续熔合；总沉积面积或节点峰温不替代有效熔合面积 |
| 温控/轻击 | 起焊15～35℃、层间≤100℃，超温待≤90℃；沿程400～500℃圆头轻击、避开QT及熔合线，≤200 N/压痕≤0.05 mm；窗口与时序为设计限制，精度核验后冻结 |
| 夹具 | 胀套刚度密度2500 N/mm³、初始预载100 N、独立压环500 N；机械止挡设计5000 N；工具热域划分2/4前段响应差9.90%，4/8差6.15%，均未通过5%门槛；需进一步加密并检查整件反馈 |
| 候选孔径 | 本次三组均为焊前40.008 mm；下界与内部区间尚需实际计算。不得把此单点认定为40.006～40.008 mm完整窗口 |
| 位置度路线 | 有限微珩：28+2+6.5+热变形及有效数值/区间储备≤50 μm，热额度13.5 μm；直接孔径合格且不去除材料：28+2+热变形及储备≤50 μm，热额度20 μm。两路线禁止混用 |
| 孔径与精整 | 孔径减/加测量U满足40.000～40.025 mm时走不去除路线；否则有限微珩局部单边≤0.003 mm/直径增量≤0.006 mm，禁止以大余量终镗控轴 |
| 防护与NDT | 沿用刚性盘、水冷铜瓣、闭合密封圈及气幕/抽吸；PT/UT依HJ-015/HJ-016云端审阅C1独立整盘，单次≤5 mL；微珩回液ID≥3.90/长度≤1 m/μ≤5 mPa·s/净排液压差≥2 kPa，实流量与颗粒/泄漏资格待补，先原位排液、干燥、闭合再撤出；正常产品干态内窥与物料清点，液体提取限牺牲样 |
| 计算验收 | 必须完整焊接、冷却、卸胀套/压环和壳底后密集孔形测量；空间、时间、工具域关键响应差≤5%；保留实际残余应力/塑性再加载—卸载，不以收敛替代强度通过 |

285 J/mm候选尚未完整验证，当前正式包继续保留原发布状态。旧家族16.56%空间差、5.38%时间差和52.084 μm预算均保留为未通过证据。
