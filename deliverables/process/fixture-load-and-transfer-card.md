# HJ-F-01 胀套承力与基准保持转运卡

配套HJ-003、HJ-004、HJ-006、HJ-012、HJ-013、HJ-014。下工装和实心反锥固定在焊接定位窝；胀套沿固定反锥向上退出，上驱动径向浮动，独立压环球铰传递500 N。机器人移动到各固定窝施焊，工件及供回水路不作绕轴旋转。

侧向反力上界取所有径向压缩力之和≤5 kN，不把每10个结构状态留存的向量峰值当作完整峰值。独立实体有限元施加5 kN侧向力、170 kN·mm支承矩及双头各200 N轻击的完整三维力臂；E取180 GPa下限。h2/h1.5两网格分别28108/63823节点，最大径向轴移3.7/3.8 μm，差1.46%；最大等效应力26.64/30.79 MPa，低于355/1.5 MPa。加实际根部螺栓及法兰弯剪柔度、0.25 μm界面轴移分配后，容量包络合成5.6 μm，覆盖6.5 μm夹紧预算。

局部均匀压缩与整体轴移分开核算。5000 N、热态E≥180 GPa、μ≤0.20时，实心芯径向压缩0.236 μm，上承力筒/门架/止挡的轴向压缩按锥角换算0.551 μm，末端块0.060 μm，界面增量0.250 μm，合计1.097 μm；等效密度2767 N/mm³覆盖焊接模型2000 N/mm³。上承力总轴向载荷2460 N包括500 N压环，止挡头及两止挡强度另核算。

精度目标为基准转移2、工装轴线2、定心2、夹紧6.5、搬运永久变化0.5及支点1 μm径向分配，合计14 μm。完全卸夹热残余另列，微珩孔轴变化另列；不重复预算。热态支点差和芯/胀套热膨胀须由接触热历程核算，与弹性刚度资格分开确认。

托环按六点外侧承托，以R82.5圆弧展开得单跨86.39 mm；计最大ID150.24及3 mm外槽削弱，保守将整周有效径向宽取11.88、厚20、E180 GPa，每跨100 N简支中载。I=11.88×20³/12=7920 mm⁴，δ=PL³/(48EI)=0.9 μm。托环平面、重复定位及运输永久变化按2 μm基准资格目标验收，六点承托不以径向摩擦夹持代替正向支承。

壳体—托环保基准夹紧采用30°/150°/270°三只上缘压钩，每只75±5 N轴向、总225±15 N，触点R77.5/z200、支柱R100，随托环运动且正向机械销锁止。座体独立副压环ID74 +0.05/0、OD104±0.05、厚12，三足R37、0°/120°/240°、径2×切6；足面z115、其余环底115.3、顶127，实际三足各166.7±5 N、合计500±20 N。两套夹紧分别反馈。

HJ-023采用3×DSNU-25-150-P-A固定工位外驱动，轴R340/22.5°、157.5°、292.5°；3根R60/Ø8/L98杆、两端球座径浮±0.30/外包络≤Ø14。外横臂R90～340截面40×20，内R60～90细端3.0×20，工作z225～245、退位z375～395。副环独立升150至z265～277并正向销锁后，原芯组才允许上提260，副环不随芯组运动。三驱动净轴力146.45/207.11/146.45 N，0.2983/0.4219/0.2983 MPa仅为理想初调值，装机按三足实测校准。两Ø16h8硬化导轨/组、衬套长30/两层跨100；一根配KPE-16(178467)静保持1000 N/独立≥0.3 MPa释放支路，另一根配Mayr ROBA-linearstop pneumatic Brake unit Size20（Ø16杆/壳OD46、5 bar释放、订型750 N）。每组移动质量≤5 kg、速度≤50 mm/s、缸压≤0.50 MPa，动态单次能量≥0.35 J、停止总行程≤1 mm按HJ-C-03订型及装机确认；制动停稳后才施KPE静态锁，工作及退位另有正向销和实际反馈。外架60×60×4/4-M8，不改钻原门架，5 kN热反力走原机械止挡。

壳体—托环保基准夹紧与托环—定位窝锁止为两套独立机构。六个外侧正向承托指全部接管且反馈锁止后，才释放托环—定位窝的三个锁止点；壳体—托环夹紧在焊接、上提与环境冷却阶段持续保持。PLC同时检查六指锁止、定位窝锁止已释放以及壳体保基准夹紧仍有效，才允许上提。

副压环运动包络按HJ-023：保留Ø14球座和3.0×20细臂，枪/丝相对杆/球座/细臂的尺寸包络最小净隙下界0.26 mm，制造及装机验收保守取≥0.25 mm。三足相对R39槽根计径浮与制造公差净隙≥0.50 mm；环独立上提跨原Ø70筒的最内足35.67相对筒最大R35.05净隙≥0.62 mm。各间隙分别验收，不能用某一处较大净隙代替全轨迹。

失电静锁延迟按HJ-C-03：Mayr 5 bar支路ID4/管长≤0.5 m、直接快速排气；KPE独立4 bar→止回→有效≥50 mL储气→释放口，失电仅由Ø0.20(+0.01)节流泄压。KPE压力降至3 bar的设计下限≥1.3 s，泄漏≤0.01 NL/min；另设失电关闭快排旁通，仅控制电源健康且确认零速后开启。市电/UPS同时失效仍由Mayr先止动、KPE被动延后静夹，端位正向销单独保持；延时和动态整停行程装机确认后冻结。

回收顺序：停弧≥120 s且全件最高温<55℃ → 枪/丝先升40、按HJ-C-03周向避让、再升至总150 mm → 副压环独立升150 mm、到位及正向销锁确认 → 上止挡张开并确认 → 胀套上退1，六指收拢 → 铜瓣径退1.10±0.05并确认 → 胀套上提260 → 关闭补氩，四抽口径退15至R93，四反馈及锁止齐全 → 确认A托环仍锁住壳体 → 转运六指接管且锁止 → 定位窝三锁释放 → 壳体与托环上提140 → 横移至环境冷却位。托环底至固定锥顶净隙4.8，壳底至铜顶40.5，胀套底至抬起壳口19.8 mm；托环ID最小150.16与撤出铜环包络149.70的直径净隙≥0.46 mm。气幕保持至壳体上提140完成后关闭；抽吸源退态可运行，腔内捕烟资格只对应R78/z210工作位。盘保持朝上原位，盘上污染按HJ-Q-02单独移除，退出后上下洁净封盖。漏水、失电和卡滞的机械保持/人工退出按HJ-C-03。壳底约束由同一托环保持到完全冷态，再保夹转入闭底全收集工位完成一次孔成形；回收干燥后解除托环，执行独立A/B下CMM。
