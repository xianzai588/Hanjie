# COMPETITION-R2 铸铁冷焊与半热态锤击专项工艺卡

适用范围：QT450-10 球墨铸铁主轴承座与 Q235B 圆筒壳体的四道自动 TIG 角焊缝。
设计依据：`studies/SCHAEFFLER-MAP/run.py`（Schaeffler 当量计算与冷焊热制度计算）、
技术说明书 §2.4～§2.6。热制度字段取自 `project/competition-design.yaml`。

## 一、热制度（铸铁冷焊）

| 项目 | 设计规范 | 依据 |
| --- | --- | --- |
| 焊接方法 | 自动 TIG，DCEN，99.999% Ar | 无焊剂、无熔滴过渡飞溅 |
| 预热 | **不预热**；起焊温度为车间环境温度，各监测点 ≥ 15 ℃ | 铸铁基体当量点 (3.95, 5.18)、Ms +468 ℃，淬硬倾向源于基体而非冷却速度，预热无法改变 |
| 层间温度 | **≤ 100 ℃（硬联锁）** | 孔区与焊道间 31.7 K 温差即产生 0.025 mm 径向漂移，等于 Ø0.05 mm 位置度径向限值 |
| 层间温度测点 | 距焊道边缘10 mm的座体表面，接触式热电偶或红外测温 | 反映基体温度而非焊道局部温度 |
| 座体起焊前蓄热 | 20 ℃ 时 0 kJ；100 ℃ 时 25.19 kJ；150 ℃ 时 40.94 kJ（占四道净热输入的 28.7%） | 座体 0.6846 kg、比热 460 J/(kg·K) |
| 自由径向收缩协调量 | 层间 100 ℃ 时 **0.0630 mm**；层间 200 ℃ 时 0.1418 mm；预热 150 ℃ 时 0.1024 mm | r·α·ΔT，r = 74.98 mm、α = 10.5×10⁻⁶/K |
| 层间门可达成性 | 组件热容 2092 J/K；四道净热输入 142.56 kJ 按 60% 留存对应温升 40.9 K，终焊温度约 61 ℃ | S3 跳焊序列 ＋ 紫铜衬环强制吸热 ＋ 壳体底口开放对流，不设专门等待工位 |
| 焊后处理 | 停弧后覆盖耐高温保温毯缓冷至 55 ℃ 以下；PWHT 不列入主流程 | 避免终冷阶段产生附加温度梯度 |

## 二、半热态锤击（Peening）

| 项目 | 设计规范 |
| --- | --- |
| 目的 | 把熔合线残余拉应力转为压应力，消除铸铁侧白口带的冷裂纹萌生条件 |
| 时机 | 每段收弧后立即进行，焊道表面 400～500 ℃（暗红色刚消失） |
| 工具 | 气动圆头锤，Ø8 mm球头（范围Ø6～10 mm），工作气压 0.4～0.6 MPa |
| 频率 | 冲击频率 2000～3000 次/min，锤击搭接率 ≥ 75% |
| 覆盖范围 | 焊道全宽及熔合线两侧各5 mm |
| 力度判据 | 表面均匀麻点、压痕深度0.1～0.2 mm，无撕裂、无层状剥离 |
| 温度下限 | 焊道低于 300 ℃ 时禁止锤击；此时塑性不足，锤击会直接成为裂纹源 |
| 执行粒度 | 每段收弧后立即锤击，四道共24个段次逐段执行 |
| 机理量化 | 表层塑性延展 0.3%～0.8%，冷却至 20 ℃ 的应力松弛能力 570～1520 MPa（E₂₀ = 190 GPa），高于熔敷金属室温屈服强度 300 MPa，锤击层稳定处于压应力状态 |

## 三、单段时序（四道 × 六段 = 24 个段次）

| 序号 | 动作 | 控制量 |
| --- | --- | --- |
| 1 | 段前确认 | 监测点温度 ≥ 15 ℃ 且 ≤ 100 ℃；防护在位、底口开放、夹紧到位、轨迹已检查 |
| 2 | 焊接 | 75 A / 12 V / 1.5 mm·s⁻¹，弧燃 12 s（18 mm 段长） |
| 3 | 停弧 | 延迟收弧填满弧坑 |
| 4 | 锤击 | 焊道 400～500 ℃ 窗口内，按第二节规范执行 |
| 5 | 跳焊 | 按 1→4→3→6→2→5 序列转至下一段 |
| 6 | 道间确认 | 六段完成后全部监测点 ≤ 100 ℃，进入下一道 |
| 7 | 终冷 | 四道完成后覆盖保温毯缓冷至 55 ℃ 以下，随后按 §9.1 卸夹 |

## 四、试制阶段工程确认项

| 确认项 | 判定准则 |
| --- | --- |
| 焊缝金相 | 单相奥氏体基体，无马氏体、无连续渗碳体网 |
| 熔合线显微硬度线扫 | QT450-10 侧峰值 HV ≤ 350 |
| 白口带厚度 | ≤ 0.2 mm 且不连续 |
| 锤击层残余应力 | X 射线衍射测定呈压应力状态 |
| 层间温度记录 | 每段每次起弧前各监测点 ≤ 100 ℃ |
