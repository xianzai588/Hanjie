工序衔接：壳外预制与修整 → 清洗干燥 → 座体入壳及屏障就位 → 8P组焊 → 带防护冷却 → 完全卸夹和受控退出 → 精度、连接和洁净检查。高温预制热制度与最终层间≤100℃分别执行。

固定精度预算：有限微珩时28+2+6.5+P≤50 μm、P≤13.5 μm、径向去除≤3 μm；内部热轴目标12 μm。无去料且孔径直接合格时才使用20 μm分支。关键响应离散差≤5%并核对绝对余量。

CI-A2、6P、全周焊及其他焊接方法均为**休眠对照**。保留已有输入与结果，不继续并行研究。旧HJ-W-00、HJ-W-00B和旧submission不是生产指令。当前执行顺序以[主线计划](../competition-route.md)为准；历史阶段账中的next_action不自动成为待办。

制造链的推进条件为有效热连接几何、保留层及适用热机械边界；PMZ容量待定不单独阻止孔形计算，完整强度与最终发布仍须相应证据。CI-A2本轮只作一次同源模型参考检查，也触发温区限制，未切换主材料。

当前pWPS参数以project/precoat-process-design.yaml和HJ-W-00D为准；旧两轨迹物料表及热源诊断仅作历史依据。最终随动轻击为选配，主工艺不启用。参赛报告文件可独立汇集，工程验证通过状态继续如实记录。
