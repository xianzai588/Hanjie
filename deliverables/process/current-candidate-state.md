## 制造顺序与作用

壳外首层预制 → 缓冷和法向修整 → 低碳第二层 → 解除预制支承并缓冷 → 延迟检查 → 连接面与孔精加工 → 清洗干燥 → 入壳定位和实体屏障 → 对向低热组焊 → 带防护冷却 → 完全卸夹测孔 → 必要的有限精整 → 干态洁净检查和封存。

高温预制先于最终孔加工，把铸铁连接和精密控形分开组织；最终组焊减少热量及周向不平衡；完全卸夹测量直接评价孔自身的残余位置；实体屏障覆盖焊接、开启和撤工具全过程。统一操作、评价理由与记录项目见HJ-M-01。
