# HJ-W-00 两层Ni99过渡层设计工艺规程

在最终轴承孔精加工之前执行。QT侧八处18×6、深1.50±0.10、端部R1.5浅槽；铸件无油污、铸皮和已知裂纹。焊接与PT后再加工连接面和轴承孔。

室温首层pWPS来料条件：QT450-10力学牌号合格，基体铁素体主导、珠光体面积分数≤20%，无原始白口或游离渗碳体网；20%为本项目组织窗口，每批代表截面检查。浅槽去尽铸皮，洁净硬质合金工具去除污染层，脱脂干燥。组织超窗时更换来料或重评热制度，不沿用室温参数。TWI的MMA/MIG典型预热表不直接规定本件GTAW首层的免预热条件。

| 项目 | 设计参数 |
| --- | --- |
| 方法与焊材 | 脉冲GTAW/DCEN；WWNA99类ERNi-CI实心棒Ø1.2；按供方批次证书验收，典型Ni99.62/C0.01/Si0.05/Mn0.17 wt% |
| 电流、电压、焊速 | 峰100/基60 A，占空50%，20 Hz；14 V；2.0 mm/s；设计电弧效率0.55，名义净308 J/mm |
| 送丝起始设定 | Ø1.20棒，第一层7.4 mm/s、第二层11.3 mm/s，设备分辨率≤0.01 mm/s；覆盖宽6 mm；首件以层厚和熔深确认设定，焊速或覆盖宽改变时同步调整送丝 |
| 保护及温控 | Ar 99.999%，8～12 L/min；起焊15～35℃；层间≤100℃，超温待≤90℃ |
| 第一层 | 短道不摆动，单段有效长度≤18；熔敷目标厚度0.60～0.70；QT质量稀释率≤20% |
| 第二层 | 首层降温并刷净，加丝覆盖厚度目标0.90～1.10；重熔第一层质量占比≤15%；加工后总厚≥1.20，表面第二层有效厚度≥0.50 |
| 独立熔深限制 | 最终HJ-W-01熔深≤0.40，须完全留在第二层内，层间界面至少余0.10；总残层≥0.80；不得用总厚度替代第二层厚度与稀释率检验 |
| 轻击 | 表面400～500℃立即圆头轻击熔敷金属中部；避开熔合线；开放夹具采用独立圆头随动轴，按HJ-W-02的温度、力与压痕要求单独确认，不能套用组焊内腔半径；错过窗口转工艺复核 |
| 检验 | 24 h后PT；首件取首层/第二层/最终接头三级截面，量熔深、层厚与面积稀释；HV0.3线扫，检查PMZ碳化物网和HAZ裂纹 |
| 后序 | 表面检查通过后连接面及孔精加工；金属屑清洗、干燥与封存均在进入壳体之前完成 |

送丝初值按新增截面积A=η沉积·πd²·v丝/(4v焊)求得。取名义d1.20、v焊2.0及η沉积0.90～0.98，第一层厚度约0.628～0.683 mm、第二层0.958～1.044 mm；该厚度按6 mm平均覆盖宽换算，首件同时量实际宽度、层厚与重熔深度。两层×八段名义弧燃144 s、净热44.35 kJ；温控、轻击、清理及24 h延迟PT另计。该工序在独立前工序完成，以经过PT、精加工与清洗的座体库存供应组焊工位。

参数为工艺设计值，稀释率由截面面积与密度换算、化学成分复核共同确定；首次QT/Ni界面仍执行冷焊裂纹控制。两层质量混合结果见说明书§2.1。供方原件：https://www.weldwire.net/wp-content/uploads/2013/08/ERNi-CI.pdf。
