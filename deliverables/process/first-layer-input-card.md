# HJ-W-00D 首层局部工艺输入与核算卡

对象：QT450-10八翼浅槽，壳外独立预制，轴承孔最终加工之前。用途是形成可核算的pWPS候选输入，并决定下一轮局部连接计算。产品目录值、类比资料和工程设定在下表分别标明。

## 2. 熔敷与路径对应

每翼径向6 mm，以R70.48/R73.48两条不摆动周向圆弧道覆盖，宽度需求3.5 mm、搭接需求0.5 mm。实际曲面BREP逐翼检查，两条中心线名义长度19.284/19.279 mm；最终外缘18 mm焊长不能复制到内侧预制道。路径总长每翼约38.564 mm，名义累计弧燃14.832 s，八翼首层合计118.657 s。先按1→5→3→7→2→6→4→8完成一轮，再对相邻径向道采用反向行进；逐道清渣、检查端部并趁热轻击熔敷金属。真实曲面、实际弧长、起停、段端和搭接均进入局部模型；“宽3.5”是覆盖需求，不是已测焊道或热源宽度。

首层天然焊道须先形成全部曲面连续覆盖，并在所需保留区达到法向至少1.20 mm的可切削轮廓，再冷态按实际槽底修整为0.70±0.05。名义熔敷质量为CI-A1全件29.664 g、CI-A2全件16.612 g；名义CAD存留首层体积678.037 mm³，按两种备料密度量级分别约6.028/5.560 g。差额说明首层修整是实际工序，不能把自然焊道出生几何直接设成0.70 mm。平均质量充足仍不能证明圆角和起停端最小层厚。

逐道记录新增质量、覆盖范围和熔敷轮廓，不按整个填充区一次出生；电流、弧长和消耗相互对应。类比数据不作为本产品实测消耗。

## 3. 电、热、熔滴与损失的闭合

总电功率UI；工件与熔敷金属的工程总入热ηUI；熔滴功率m_dot×h入（m_dot以kg/s计）。空间源接收ηUI-m_dot×h入；电/药皮等损失与边缘未截获量分别记账。未截获功率不得重新集中，也不得将熔滴焓再加到ηUI之上。

| 名义输入核算 | CI-A1 | CI-A2 |
| --- | ---: | ---: |
| 电功率W / 工程总入热W | 2000 / 1600 | 1350 / 1080 |
| 毛线能量J/mm / 工程净线能量J/mm | 769.231 / 615.385 | 519.231 / 415.385 |
| 熔滴进入焓功率W | 300～325 | 168～182 |
| 可分配空间源功率W | 1275～1300 | 898～912 |

Fe–Ni–C焓复核表明，原0.8 MJ/kg在CI-A1两种相集合下液相质量分数仅约0.11/0.24，不能作为完全熔化熔滴入口。修订为1.2～1.3 MJ/kg工程核算区间；CI-A1完全液态的首个温度采样点为1400℃，相对25℃焓差约1.083～1.111 MJ/kg。结果未覆盖Si/Mn及真实熔滴温度，热模型必须统一焓参考。计算保留原始平衡分支，并以较低Gibbs能的完整平衡状态复核；不平滑焓值。依据见simulation/competition-r4/results/mma-filler-enthalpy-20261006/summary.json。

首层独立预制的净线能量不受最终250～350 J/mm候选窗约束。所有已列输入角点剩余空间源功率为正，说明这套电/料输入未违反总能量守恒；连续熔合与冷却组织由局部计算确定，不能从总能量表推导。

**空间热源的下一项输入**：针对此类MMA材料和槽形，采用公开截面及热循环可对应的源形式、分布尺度和起停表达；同时给出模型温区与沉积轮廓的适用范围。现有350 W GTAW入射表面源不直接改名为MMA。缺少此对应关系时，先保存本卡及守恒结果，不启动整件重算。

## 4. 道前温度和作业时间

复用已完成炉内结果，不再扩升温网格矩阵。出炉平均温度分别为190.803/290.323℃；按已保存实际质量0.988 kg、表面积0.03225 m²、温变Cp、ε0.7、空气h10～30计算，30 s转运的平均温度分别178.435～184.664/269.891～279.075℃。这是自由空气平均温度预算，不是局部最低温保证，支承接触、开门和装夹随下一轮热历史一起计算。

离炉至起弧设计上限30 s，工作面和座体测点分别检查；实际道前温度超产品上限则等待、低于下限则恢复加热，保留已有残余状态。每道轻击、清渣、转位和温控等待按真实工作站动作计时。首层弧燃118.657 s仅是弧燃需求；升温、中间修整、第二层、保温缓冷、延迟PT、孔加工/清洗与转运均另计，不沿用旧Ni99预制432 s作为新路线整站时间。

## 5. 新材料链与选材判别

同一组诊断比例：QT入首层10%～20%、首层入第二层10%～15%、第二层入最终10%～20%、钢入最终5%～10%。全部比例是用于揭示换料影响的输入情景，实际输运、重熔范围和采用窗口须另证明。

| 首层候选 | 首层C wt% | 第二层C wt% | 最终C wt% |
| --- | ---: | ---: | ---: |
| CI-A1 | 1.265～1.530 | 0.1355～0.2380 | 0.03055～0.07160 |
| CI-A2 | 1.445～1.690 | 0.1535～0.2620 | 0.03235～0.07640 |

核算同时保存C/Si/Mn/Ni，第二层与最终成分不再按原始裸棒填写。当前只推进CI-A1高镍首层；CI-A2保留已有对照，不继续并行计算。供方全焊缝480/520 MPa和指定相集合下的平衡相分数均不赋予本件PMZ容量。按同一截面核对实际层厚、累计重熔和成分过渡区，决定保留层及材料取舍。
