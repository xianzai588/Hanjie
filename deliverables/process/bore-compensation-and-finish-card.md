# HJ-Q-03 孔径补偿、有限微珩与孔轴复检设计规程

对象：15 mm长、Ø40主轴承孔。焊前40.006～40.008 mm为当前尺寸补偿核验窗口；须以完整冷态三组及同网格制造上下界的实际结果冻结。不得通过终镗纠正焊后轴线。

评价实体为QT450-10座体原有Ø40主轴承孔，控制其自身轴线相对壳体A/B基准的位置度；本方案不增加压入轴套。20℃下40.000～40.025 mm为本设计采用的H7尺寸控制等级，ISO 286-2查表仅支持公差数值，不证明特定轴承或轴套配合。该制造指标单独评价焊接控形与有限精整，不宣称已完成机型的滑动副/轴承寿命设计。

| 工序 | 操作与判据 |
| --- | --- |
| 焊前尺寸 | Ni99前工序及连接面加工完成后精加工孔。20±0.2℃测量；首件以密集轮廓扫描和周向相位平移核对截面/方向覆盖，再冻结生产量仪程序；测量值减/加孔径U均应落入制造窗口。孔轴与基准面另按图纸检验，装夹前封存保护。 |
| 完全卸夹 | 孔内胀套、压环、铜环/托盘及壳体底座全部解除。按A/B独立建基准，直轴与各截面中心包络取大。数值评价用33截面×384点及半步相位复核，B两带各192点。生产CMM采用五截面连续圆扫描及四条轴向母线，首件与加密及周向相移程序的孔径/孔轴差≤0.1 μm后冻结扫描步距；3截面×12点只作找正。容量规划360 s，不能把仿真点数直接当仪器能力。精整前孔轴加U>Ø0.05直接隔离。 |
| 孔径量仪 | 采用比较式电子孔径量仪或等效系统，Ø40范围需配扩展测指和可溯源标准环。设计分辨率≤0.1 μm，方法扩展U≤0.5 μm；分辨率与仪器重复性不能直接当整套U。首件确认参考环、重复性、线性、对准和温差预算。 |
| 温度与尺寸判定 | 孔与参考环均达到20±0.2℃。全孔最小测量值减U≥40.000、最大值加U≤40.025时不作恢复性精整；粗糙度按图纸独立判定。超上限孔直接隔离，减材工序不能修复孔过大。 |
| 微珩触发 | 仅恢复局部欠尺寸。按尺寸链核验规定的恢复范围执行；先根据实测轮廓确定局部去除量，不以整孔均匀加大代替局部高点修整。记录原孔轴、各截面尺寸和径向进给零位。 |
| 短孔稳向 | L/D=0.375，采用短孔端面稳向、宽导向鞋和浮动驱动，避免侧推力和锥形跳动；以精整前实际孔轴找正，不以壳体轴线重定切削轴。用接近目标尺寸的校整套修整磨条/导向鞋。工具供方首件确认磨料、压力、行程与表面纹理。 |
| 限量控制 | 最大局部径向去除≤0.003 mm、两点直径增量≤0.006 mm。磨条扩张设置机械/数控双限位；小步进给，逐段测量。较大截面不再扩张；全过程最大孔径加U≤40.025。达到最小测量40.0005～40.0010即停止恢复加工。 |
| 孔轴变化预算 | 任意0～3 μm径向去除的首谐波中心界乘33截面直线拟合端点权重L1，再加0.2 μm非线性储备，取6.5 μm位置度直径分配。需微珩的设计分支按28＋2＋6.5＋P≤50 μm，焊接孔轴上限13.5 μm；无需精整、孔径护栏直接合格且禁止后续精整的分支上限20 μm。上下界、内部响应及名义精整轴均进入最不利预算；名义精整变化已含在包络内，不重复相加。实际精整前后各加CMM位置度U≤Ø0.05。 |
| 清洁与返修 | HJ-015上下Ø60罩与下杯闭合，R27端面密封只接触完整中心环，不与孔壁滑动接触；面圈Ø1.00±0.02、槽深0.70±0.01、止挡净隙0.10±0.01，极限压缩0.16～0.24 mm；压紧≤120 N，供液≤60 mL/min、Ø4排液、吸压−2～−5 kPa。失吸0.10 s内停进给/供液；可回流管内液≤5 mL，下杯有效容量12.21 mL。抽尽、原位擦干、封口后，下杯经壳底竖直向下撤出，上罩/工具套袋向上撤出，不携液开屏障。磨液、磨料和金属屑不得进入不可清洗内腔。隔离异常或检出污染即隔离，不以整腔冲洗补救。超去除量、尺寸或孔轴范围进入工艺评审，不自动追加精镗或补焊。 |

孔径方法U的设计标准分量：重复性界限±0.25 μm按矩形分布，标准环证书U0.20 μm/k2，分辨率0.10 μm，残余温差±0.2℃，对准与局部线性各0.05 μm标准分量；合成扩展U约0.42 μm，规定方法资格上限0.50 μm。该表是设备/方法验收目标，试制时用真实证书及重复测量替换。

依据：Sunnen《Honing Short Bores》，明确短孔的中心线稳定、校整套、端面稳向和锥形跳动要求；[原始DF102](https://cdn.shopify.com/s/files/1/0903/7856/7977/files/DF102_c_200903.pdf?v=1756913583)。Sunnen PGE-6000资料给出0.0001 mm分辨率、±0.00025 mm重复性及Ø40所需扩展测指范围；[原始设备资料](https://cdn.shopify.com/s/files/1/0903/7856/7977/files/PGE-6000A-202208.pdf?v=1753395494)。设备示例用于说明可实现的测量能力，不替代本工位U资格确认。
