# HJ-Q-02 内腔颗粒阻隔与洁净检验设计规程

检测适用域：壳外清洗、入壳后颗粒阻隔及全周期牺牲件评价用于两种结构。原铜环/盘体的容量、见证片净隙和工位数量对应八翼装配；完整圆环逐项核对HJ-S01。

官方背景中的压缩机内腔不可清洗。本方案在焊接之前完成座体、壳体、工装及入腔附件的清洗、干燥和封存；从组焊开始，产品内腔不安排冲洗或污染后的恢复清洗。焊渣、飞溅和金属磨屑一经检出即隔离该件，回到污染源与屏障工艺评审。下述液体提取只用于方法资格及牺牲样件，不作为正常产品工序。

| 工序边界 | 执行及判定 |
| --- | --- |
| 可清洗前工序 | Ni99预制、PT及孔/连接面精加工在座体进入壳体之前完成；壳体和入腔工装分别清洗干燥。检查无屑、无液体残留后洁净封存。装配时点清工具与附件。 |
| 焊接与冷却 | 铜瓣上密封及跨瓣桥、连续下密封座、完整接料盘构成封闭颗粒路径；逐件确认配作净隙、回弹、流量和温度联锁。缺流、漏水、密封或轨迹异常停弧，保持接料盘与工件夹持。气幕辅助回收，不能替代实体屏障。 |
| 开启屏障之前 | 从上方抽吸回收焊缝、工具及盘上颗粒；检查八段下缘、瓣缝、盲孔/接头及盘面。盘保持朝上，禁止向腔内吹落污染。清除源头颗粒后才允许铜瓣回缩及胀套上退；看不清或仍有附着颗粒时不进入撤夹。 |
| 撤夹与转运 | 按HJ-F-S01～S03先上退胀套，再连A托环上提；盘原位朝上留置。套、铜瓣和工具均不刮擦壳壁。完成撤出后立即以洁净盖封住上下开口，六点正向承托转运；每次开启后复核暴露面。屏障资格必须包含开启及转运动作。 |
| NDT与微珩隔离 | PT液、显像剂、UT耦合剂及磨料不得进入内腔。以局部接液罩、孔口洁净堵盖及独立回收构成封闭操作区；微珩沿实际孔轴稳向，使用全收集短孔工具。隔离装置须先以荧光液/参考颗粒确认无旁路和撤出掉落，再允许正常组件采用该工序。尚未具备合格隔离条件时不执行可污染内腔的操作，不以之后冲洗补救。 |
| 逐件检查 | 保留全过程联锁/异常记录；封盖前干态内窥检查孔面、座体下表面、八段焊缝下缘及壳壁/底部，逐区域留图并点清入腔件。内窥辅助识别和定位，不宣称能逐件量出5 μm颗粒或0.50 mg总量。任何工艺硬颗粒或屏障异常隔离，不能以一次外观通过覆盖过程异常。 |

| 方法资格与牺牲样件 | 执行及判定 |
| --- | --- |
| 全过程资格 | 首件、换密封/夹具、调整NDT/微珩隔离或轨迹后，用专用牺牲壳体执行焊接—冷却—屏障开启—撤夹—转运—NDT/必要微珩全周期。在任何焊后清洗之前检验不可清洗区；记录各步污染源及保持/撤除屏障时刻。 |
| 局部见证片 | 盘下z82.2～83.2、R50、45°起四等分设置20×20×1 mm抛光316L片，由预清洁定位架托住，安装与取片朝上且不刮擦。全程曝光并配同批空白片。片只定位盘下局部泄漏，不代表整腔零污染；其位置及0.39 mm至水块净隙见HJ-C-02。 |
| 整腔未清洗提取 | 对完成全周期、从未接受焊后清洗的牺牲件，依次提取孔壁、座体下表面、八段下缘、整个下腔壳壁/端面及遮挡处；组件本身为采集对象，盘上捕获物单列。先分区记录再合并全腔总量。该件退出产品流。 |
| 提取初值 | 使用1 μm前置过滤、低蒸发残留且与接头/PT材料相容的异丙醇类液；三轮各0.50 L、喷淋压力≤0.10 MPa，覆盖死角并真空过滤至1 μm低析出膜。以重复提取递减确认覆盖，末轮≤累计颗粒量10%；不足则增加轮次并冻结方法。增加轮次是检验提取，不是修复样件。 |
| 检出能力 | 全膜扫描，校准≤1 μm/像素；用5/10/25 μm参考颗粒确认检出率≥95%、尺寸偏差≤2 μm。最小识别5 μm是方法能力，不是允许焊渣/飞溅残留门槛。长径用最大Feret径。 |
| 分类与拒收 | 分列5～15、15～25、25～50、50～100及≥100 μm，记录数量、最大径与来源；疑似金属/硬质颗粒以SEM-EDS等确认。工艺焊渣/飞溅/金属磨屑无论尺寸拒收；≥5 μm金属/硬质颗粒、≥25 μm其他颗粒或长度≥100 μm纤维拒收。 |
| 过程质量预算 | 牺牲样件净残留＋扩展不确定度≤0.50 mg/件，天平分辨率≤0.01 mg、定量限≤0.10 mg。5～25 μm软性非金属分类并受总预算约束；预算不是正式产品逐件已测值，也不从整机标准推导寿命。 |
| 空白与回收 | 同批及换液/膜做相同容器、液量、管路和膜空白，质量≤0.05 mg且无上述拒收颗粒；空白失败则方法无效。独立参考样回收90%～110%。负净值记低于定量限，不扣除大颗粒判合格。 |
| 资格失败处置 | 隔离同条件组件，查密封、滑动桥、盘、工具磨损、屏障开启和后序隔离。修订后换新牺牲件执行完整未清洗周期；旧样清洗后的结果不作为通过证据。保存段号、片/膜号、原始全膜图、分类、称量及联锁记录。 |

资格形成两条证据：几何/热态/运动边界与全周期未清洗牺牲样检验支持屏障过程；分区及整腔提取支持残留预算。四片局部见证、一次干态内窥或清洗后的膜检，均不能单独证明全过程未落入。无实物参赛稿给出屏障设计计算、完整动作和上述方法资格方案，不填写虚构检验值。

产能：正常件按过程记录30、十区域内窥200、工具点清30及封盖40 s，合计300 s设计容量；试制计时后冻结。单头462.5 s间隔配1位，双头231.3 s配2位。PT480、UT600、干态300 s；当前需微珩分支另计CMM前后2×360及微珩200 s，合计2300 s操作，单头/双头人员5/10当量、CMM2/4站、微珩各1站。尺寸直接合格且不精整时仅CMM360，合计1740 s、人员4/8当量、CMM1/2站。1800 s提取/扫描占用和480 s人工初估只计牺牲样件资格或指定批次抽检，由独立实验室承担，不进入每件工序。

依据：[ISO 16232:2018官方范围](https://www.iso.org/standard/70267.html)用于颗粒污染方法与记录框架，不提供本组件限值；[Leica原始技术资料](https://www.leica-microsystems.com/science-lab/industrial/cleanliness-analysis-for-particulate-contamination/)支持提取—膜过滤—显微分析路径。液量、压力、回收、质量和拒收值为本设计的资格输入。
