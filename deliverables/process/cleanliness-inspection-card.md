# HJ-Q-02 焊接组件内腔洁净检验设计规程

对象为封盖前、未注油的壳体—座体组件，覆盖轴承孔、焊缝下缘和整个下腔。焊渣、飞溅及金属磨屑一经检出即拒收，不论尺寸；检测能力不作为允许残留尺寸。下表为本工序的设计验收值，整机指标另按适用产品标准和实际机型确定。

| 环节 | 执行及判定 |
| --- | --- |
| 时点及频次 | 每件在PT/UT、必要微珩、清洗和干燥后，封盖前检查；首件、换密封/夹具及工艺变更另做盘下见证片阻隔验证。检后覆盖封存，后续开盖或污染重新检查。 |
| 阻隔见证片 | 首件在盘下z82.2～83.2、R50、45°起四等分设置20×20×1 mm抛光316L见证片，径向/切向布置，最大半径60.83，位于Ø144柱顶z80上方、R36整体盘外侧、R66.5加强环内侧；至穿盘水块底z83.59名义净隙0.39 mm。由预先制造、清洗的定位架托住，安装与取片保持朝上，不滑擦壳壁；焊接、冷却及上提回收全程曝光。配同批空白片，安装件不得产生自身磨屑。检出焊渣、飞溅或金属磨屑即判阻隔失败；不以局部见证片代替整腔提取。 |
| 提取位置 | 孔壁和座体下表面、八段下缘、壳壁及下端面依次冲洗并汇总至同一滤膜；拆除检验接料盘后提取其遮挡处。见证片结果单列，不以局部片代替整腔提取。 |
| 提取初值 | 经1 μm前置过滤、低蒸发残留且与接头及PT材料相容的异丙醇类清洗液；三轮各0.50 L、喷淋压力≤0.10 MPa，转动组件覆盖死角；真空过滤于1 μm低析出膜。首件以重复提取递减试验确认覆盖，末轮颗粒量须≤累计量10%；全部低于定量能力时按方法检出限记录。未满足则增加轮次并冻结有效程序。 |
| 成像能力 | 全膜扫描，校准像素尺寸≤1 μm/像素，目标最小识别粒径5 μm；以5/10/25 μm参考颗粒确认检出率≥95%、尺寸偏差≤2 μm。调倍率后重新确认；长径按最大Feret径，纤维同时记录宽度与长度。 |
| 分类记录 | 分列5～15、15～25、25～50、50～100及≥100 μm，报告每类数量、最大粒径与来源。反光/非反光只是初筛，疑似金属、氧化物及硬质非金属以SEM-EDS等成分方法复核，不把暗色焊渣归为软性非金属。 |
| 颗粒拒收 | 检出焊接来源焊渣/飞溅/金属磨屑，或≥5 μm金属/硬质颗粒，或≥25 μm其他颗粒，或长度≥100 μm纤维，均拒收。5～25 μm软性非金属逐类计数并受总质量预算约束；不以少数大颗粒平均化。 |
| 总质量 | 净残留质量加扩展不确定度≤0.50 mg/件，作为本装配工序污染预算；天平分辨率≤0.01 mg，方法定量限≤0.10 mg。滤膜按相容程序干燥、恒重后称量，同批空白扣除；负净值按低于定量限记录，不写负污染量。该预算不从整机标准推导轴承寿命。 |
| 空白与回收 | 每检验批及换液/换膜均做相同容器、液量、管路和膜的空白，空白质量≤0.05 mg，且无≥5 μm金属/硬质颗粒及≥25 μm其他颗粒。空白失败则该批方法无效，不靠扣除掩盖大颗粒。首件加入已知颗粒/质量的参考样验证90%～110%回收，来源辨识和提取递减另行确认。 |
| 处置与保存 | 超限件隔离，查密封、滑动桥、接料盘、工具磨损及NDT/精整后清洁；重清洗后重新执行整腔检验。保存段号、膜号、液量/轮次、空白、原始全膜图、分类与称量记录；不生成没有实际检测的照片或质量数值。 |

本件采用“无检出工艺硬颗粒＋0.50 mg总量预算”的保守过程控制，避免未知油膜厚度和轴承间隙下仅以整机总杂质质量判断磨损风险。后续机型确认时用实际油膜/间隙及整机洁净指标复核过程预算，不放宽题面禁止焊渣和飞溅的要求。

产能设计：每件提取、过滤、干燥及全膜扫描按1800 s占用、480 s人员操作估算；独立于PT的检后擦洗时间。按焊接站出件间隔配置检验位置与扫描能力，方法资格或实测计时使占用增加时延长出件间隔或增加能力；SEM-EDS疑似颗粒复核及首件方法资格另计。

依据：[ISO 16232:2018官方范围](https://www.iso.org/standard/70267.html)用于颗粒污染检测方法与记录框架，标准不提供本组件限值；[Leica原始技术资料](https://www.leica-microsystems.com/science-lab/industrial/cleanliness-analysis-for-particulate-contamination/)给出提取—膜过滤—显微成像路径及5 μm分析能力。上述压力、液量、递减、回收、质量和拒收值为本方案设计输入，首件按表完成方法资格。
