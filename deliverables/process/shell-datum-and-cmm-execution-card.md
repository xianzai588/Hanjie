# HJ-M-02 焊前壳体加工、独立基准与CMM执行卡

适用8P-R2-t15与Q235B壳体。壳体名义Ø160×200、壁厚5 mm；下端为z0，座体z100～115。以下公差、扫描与不确定度均为制造和方法设计要求，装机及首件记录填写实际值。与HJ-001/005/021/022、HJ-M-01和HJ-Q-03配套；位置度直径主路线28+2+0+20=50 μm；装夹态一次孔成形后完全卸夹验收，卸夹后零去料。

## 1 焊前加工与基准面

| 对象 | 制造要求 | 加工及检查 |
| --- | --- | --- |
| 毛坯及内腔 | Q235B来料证书；留焊前精加工余量，完成壳体纵缝或其他成形热工序后再加工基准；成品仍按Ø160、H200、名义壁厚5的题面几何 | 检查成形缝、内壁及端面，去除毛刺、氧化皮和松散物；壳体最终基准加工先于轴承座入壳 |
| A基准 | z0壳底全周环端面，平面度≤2.0 μm、Ra≤0.8 μm；非定位边缘倒钝0.2～0.3 mm，不削去有效支承环面 | 端面精车后精磨/研磨；以全周软夹持和轴向支承加工，解除夹持后检查。A不得由托环、孔轴或胀套代替 |
| B1/B2测量带 | B1：z20～30；B2：z170～180，轴向各10 mm、全周。两带内径150.00～150.02 mm，圆度≤3.0 μm，两带按A法向约束的共同圆柱包容区宽度≤4.0 μm、Ra≤0.8 μm | B1、B2与连接区在同次基准装夹精镗/校准；加工后解除夹持复测，测量带不得打标、喷涂或打磨 |
| 最终连接区 | z100～120内径150.00～150.02 mm，与B带同装夹；座体外缘149.94～149.98 mm，径向间隙0.01～0.04 mm | 其余内壁及下端装工具路径保持通径≥150.00 mm，无凸起、加工台阶和毛刺。超差在入壳前修订壳体加工，焊后不镗孔轴 |
| A/B方向关系 | 用B两带不约束拟合的诊断轴，检查A相对该轴的垂直度≤2.0 μm，作用于约150 mm有效端面跨距 | 正式检测仍以A为第一基准、B按A法向定向；诊断轴只检查加工方向，单独留存，不替换正式基准 |

A平面度2 μm相对约150 mm支承跨距的角度量级为13.3 μrad，在孔上端z115的径向投影约1.53 μm，对应基准转移径向2 μm分配的制造目标。B带中心相距150 mm，并在座体上下布置，减小孔区的基准外推；两带共同圆柱包容区定义为：方向约束A法向，选择共同横向轴位置，包住两带有效点云的同轴圆柱半径差最小值≤4.0 μm。该形状检查与下述最小二乘基准B提取分别报告，不能把加工公差直接当作CMM不确定度。

焊前完成壳体、座体和入腔工装清洗干燥、内窥检查及封存。壳体—A托环保基准夹紧采用30°/150°/270°三只上缘压钩，接触R77.5/z200，每只75±5 N轴向，总225±15 N；随行支柱位于R100，压钩正向机械销锁止。

座体独立副压环按HJ-023：ID74 +0.05/0、OD104±0.05、厚12 mm；三足R37、0°/120°/240°，径向2×切向6 mm，位置±0.03 mm。足面z115，非触点下表面z115.3、上面z127；三足各166.7±5 N、总500±20 N，分别实测校准。副环退出150 mm至z265～277，不随原芯组上提。3根Ø8杆位于R60、长98 mm，两端球座径浮±0.30、外包络≤Ø14；横臂内段R60～90截面3.0×20，外段R90～340截面40×20，工作z225～245、退位z375～395。三足浮动/制造包络相对R39槽根净隙≥0.50 mm，升环内足最内35.67相对原上筒最大R35.05净隙≥0.62 mm。枪/丝与副杆/球座/细臂运动包络最小下界0.26 mm，制造及装机验收保守取净隙≥0.25 mm；球座保持Ø14上限。净隙不足时按HJ-C-03加大中间位避让角并重做全程冷态验收。

副压环驱动为3×Festo DSNU-25-150-P-A，固定于R340、22.5°/157.5°/292.5°工位外独立架；柱60×60×4、4-M8安装。每组总体径向包络相对中心−40～+90、切向±60，不改钻原门架。三驱动净轴力146.45/207.11/146.45 N，理想气压0.2983/0.4219/0.2983 MPa仅作不计重力/摩擦的起调值，按三足实际力和总力调整，不采用同压等力。每组两根Ø16h8硬化导轨、导向衬套长30、两层跨100；一根导杆Festo KPE-16（178467）静保持额定1000 N、独立≥0.3 MPa释放支路，另一根配置Mayr ROBA-linearstop pneumatic Brake unit Size20（Ø16杆/壳OD46、5 bar释放、订型750 N）。每组移动质量≤5 kg、速度≤50 mm/s、缸压≤0.50 MPa，动态单次能量≥0.35 J、停止总行程≤1 mm的订型/装机确认与故障保持按HJ-C-03；工作及退位另设正向销和反馈。普通DSNU气缸不作自带1 kN杆锁，KPE静态锁不代替运动急停制动。

正常退出先枪/丝上提150→副压环独立升150、实际到位及正向销锁确认→上止挡张开→胀套上退1→铜瓣径退1.10±0.05→原芯组上提260。副环先升时原上止挡闭合、胀套仍夹紧；压环驱动固定在工位外，其500 N夹持与原机械止挡5 kN热反力分别反馈。托环六个承托槽/转运指保留0°起每60°；关闭补氩、四抽头退15至R93并反馈/锁止，六指正向锁止齐全后才能释放定位窝三锁，再上提壳体/托环140 mm。气幕至上提完成后关闭，退态抽吸不计工作位捕烟。完全冷态测量前解除孔内及两套外部夹紧。新增接口按HJ-022/023确认，原有限元保持原边界和名义载荷身份。

副环失电顺序按HJ-C-03：Mayr 5 bar支路ID4/管长≤0.5 m、失电快排；KPE独立4 bar→止回→有效≥50 mL储气→释放口，失电经Ø0.20(+0.01)节流泄压，压力降至3 bar的设计保持下限≥1.3 s。独立快排旁通失电关闭，仅控制电源健康且确认零速后开启。市电/UPS全失仍先动态止动、后被动静夹；泄漏≤0.01 NL/min、延时与整停行程按安装支路验收。

## 2 基准提取与测量程序

1. 在20±1℃环境内，工件完全卸夹并达到热平衡；两B带、孔区及参考器温差控制在±0.2℃，记录实际温差。支承只托住壳体自重，测头不与焊接工装建立共同轴线。
2. A面在R76、R79各作一圈连续扫描，避开倒角、伤痕及边缘；先检查形状并拟合平面。异常点按可见污染或损伤定位记录，不为取得位置度而删点。
3. B1扫描z22/25/28，B2扫描z172/175/178；用六圈数据共同拟合轴线，方向约束为A法向、横向位置由壳体点云确定。两带分别拟合中心作诊断，保留共同拟合残差；将壳体形状和孔轴偏移分列。
4. 孔扫描z100.5/104/107.5/111/114.5五截面，另作0°/90°/180°/270°四条轴向母线，覆盖有效孔壁并避开倒角。初始孔圆扫描弧长步距≤0.25 mm、母线步距≤0.20 mm，B带及A圆扫描步距≤1.0 mm。方法资格时用同次高密度点云比较这些步距与加密/相移重采样的差，目标≤0.1 μm；独立复测重复性另计入U。
5. 以五截面中心拟合孔直轴，在实际15 mm孔长z100～115两端评价该轴相对B的径向距离，同时检查截面中心包络，取两种位置度直径的较大值。位置度报告包含轴移、倾斜、截面中心、孔形残差、温度和方法U。
6. 判定采用P测量+U位置度≤0.050 mm；孔径按HJ-Q-03的U≤0.5 μm独立判定。360 s为生产容量目标，首件程序资格的额外扫描与复测不计作已经实现的节拍。

## 3 位置度扩展不确定度设计分账

各分量以下表的**位置度直径标准不确定度**计，单位μm；k=2。使用与Ø150壳体及Ø40孔位置测量相近的校准工件/标准件，根据ISO 15530-3形成任务相关预算。设备MPE、测头分辨率和零件加工公差分别记录。

| 分量 | 标准分量设计上限 / μm | 物理对象与确认方法 |
| --- | ---: | --- |
| 校准/局部尺度 | 0.20 | 对应测量任务的标准件证书及局部尺度修正残差；证书扩展U≤0.40 μm、k=2为采购目标 |
| 重复装卸及复测 | 0.40 | 包含自重支承、测头重复性和完整重建A/B；以独立装卸重复测量的直径结果估计标准差 |
| A/B提取 | 0.45 | 设计A法向标准角度≤1.5 μrad，在孔中部z107.5投影为直径0.323 μm；B横向中心标准量≤0.15 μm径向、对应直径0.30 μm，两项合成约0.441 μm，取0.45 |
| 测头姿态/局部对准 | 0.35 | 对应接触法向、测杆弯曲及两种探测姿态的补偿残差，在校准工件相同位置和姿态确认 |
| 温差与梯度 | 0.25 | 按钢α=12×10⁻⁶/K、R75 mm、残余温差±0.2℃矩形分布，直径尺度标准分量约0.208 μm，余量计局部温度梯度 |
| 采样与拟合 | 0.25 | 用同次密集点云比较冻结步距、周向相移和拟合程序；残差、边缘外推和孔中心包络分别记录 |
| 分辨率/数值舍入 | 0.15 | 0.1 μm坐标分辨率仅给出约0.029 μm单坐标标准量；本项另覆盖坐标变换和报表舍入残差 |

无显著相关项时，设计合成标准量为√(0.20²+0.40²+0.45²+0.35²+0.25²+0.25²+0.15²)=0.820 μm，扩展U约1.64 μm，方法资格上限仍为2.00 μm。实际证书、重复数据及相关项替换设计值；超过2 μm时先改善基准提取、温度或设备方法，再按原Ø0.05 mm判据评价，不扩大公差。数值1.64 μm是设计预算结果，由首件实际证书和重复测量评定。

依据：现行Ø0.05 mm完整预算、HJ-F-01基准转移分配与实际壳体/孔尺寸；[ISO 15530-3:2011官方范围](https://www.iso.org/standard/53627.html)支持使用校准工件或测量标准评定CMM任务相关不确定度。首件工程确认依本卡记录实际值，报告与图纸的设计交付独立推进。
