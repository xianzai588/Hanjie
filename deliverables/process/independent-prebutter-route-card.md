# HJ-W-00B 独立预堆备用路线设计卡

适用工序：QT座体在最终孔加工、入壳之前独立预堆；预制库存供最终组焊。该工序允许清渣、修整和清洗，最终不可清洗内腔的隔离要求保持。SMAW不是最终壳内连接方法。

| 项目 | 设计选择与依据 |
| --- | --- |
| 接口 | 沿八翼实际全宽覆盖R68.98～74.98；总面积921.349 mm²，名义槽深1.50±0.10。齐平加工前局部正余高≥0.10，最大槽深所需几何料高≥1.70；成品连接面z115，HJ015/HJ016撤出尺寸据此核对 |
| 材料方向 | 高Ni药皮焊条首层、镍系覆盖层，再独立评定最终NiFe连接。TWI支持镍系预堆后连接；Pascual2009使用97.6%Ni/C0.30%SMAW，不能以裸Ni99/C0.01%的相图替代药皮焊条 |
| 预热候选 | 独立座体350℃均匀预热、渐进升温、保温后施焊、覆盖耐火材料缓冷。350℃为公开6 mm球铁SMAW路线依据；本件15 mm、铁素体主导QT的道间与缓冷窗口按热循环另定，不套用最终组焊≤100℃联锁 |
| 备选商品规格 | Lincoln RepTec Cast1公开Ø2.5 mm/50～100 A规格；典型Ni97/C0.7/Fe2只用于成分对照。2024欧洲页内极性DC+与DC−描述、C上限0.20与典型0.7存在冲突，不能据此冻结极性及采购化学限值。选定供货证书与适用热制度后再生成生产数值 |
| 熔敷量 | 按921.349 mm²×1.70、纯Ni密度换算，几何料量13.924 g；Ø2.5芯材在100%回收极限下至少319.083 mm，即按250 mm可用芯长至少2根。这是备料下限，不是实际药皮焊条消耗或沉积速率 |
| 热量与节拍 | 预热热量采用实际QT体积和温变Cp积分；不能把总槽料量除以任意沉积率写成节拍。炉温均匀性、保温、短段交错、清渣与24 h延迟PT分别计入前工序库存容量；预热时间不转嫁为最终组焊流水节拍 |
| 工艺顺序 | 渐进预热→短段/对向预堆→按所选焊材热制度轻击及缓冷→清渣→延迟PT→连接面修整/最终孔加工→清洗干燥封存→NiFe最终连接。保存预制残余状态与实际去料释放，不将精加工等同应力清零 |
| 组织判定 | 裸Ni99、文献Ni97.6及供方Ni97典型成分已按0/20%QT配混分别执行Fe–Ni–C平衡，并修正高能求解分支；20%是输入情景，非测得稀释。Si/Mn与冷却组织、PMZ/HAZ硬化另验 |
| 接头有效性 | 以真实连续熔合足迹、最小有效截面及QT—首镍PMZ容量支持后续传力；焊条全焊缝拉伸值不直接当首次界面法向/剪切/疲劳许用值 |
| 最终控形 | 无有效首次及最终双侧连接时不输入全片绑定整件模型。微珩上限径向3 μm、热轴13.5 μm分支和Ø0.05 mm完整预算保持 |

来源：[TWI铸铁工艺指南](https://www.twi-global.com/technical-knowledge/job-knowledge/weldability-of-materials-cast-irons-025)、[Pascual2009原研究](https://doi.org/10.3989/revmetalm.0814)、[Lincoln2024原供方页](https://ch-delivery.lincolnelectric.com/api/public/content/bb8290c8a6f44f5aaba8f549968eed2e?v=e83266bd)。数值来源：`route4-reselection/route4-audit.json`及`route4-filler-phase-gibbs-checked`。
