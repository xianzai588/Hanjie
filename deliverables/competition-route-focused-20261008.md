# 八翼主方案的收束设计路线

基线：`b69e26a`／`SUBMISSION-8P-20261008`。目的：用现有材料和工具取得能回答题面问题的工程结果。执行分支：`codex/b69-focused-route`。

本文件是本轮选定的完善路线，第二层新点和无微珩分支属于设计决定，尚未替换原pWPS及b69参赛包；完成相关验证和同步后再形成新版交付。以下不用文件数、页数或程序基准代替工程结果。

## 1. 保留一条制造主线

保留8P-R2-t15中心连续环、八翼及柔顺槽，保留QT450-10、Q235B和CI-A1／DMNA099／NiFe55三种已有焊材；保留每翼实际18 mm、稳定有效16 mm和1→5→3→7→2→6→4→8的两道焊序。圆环资料作为比较附件，不反复切换主对象；激光、外塞焊和其他材料不增加新算例。

主工序：自由支承壳外首镍预制→缓冷和法向修整→低碳第二层→缓冷及终端检查→连接面与孔最终加工→清洗干燥→入壳固定工装定位→根／盖对向短段组焊→带屏障冷却及受控退出→完全卸夹后的孔轴、孔径与连接／洁净检查。

## 2. 把孔径直接合格作为主路线目标

本件不可清洗内腔，主制造路线优先取消焊后微珩，减少磨料、液路、两次孔测量与撤工具污染路径。孔H7控制窗仍为40.000～40.025 mm，不放宽官方Ø0.05 mm位置度。

| 位置度直径预算 | 原有限微珩分支/μm | 无微珩主路线目标/μm |
| --- | ---: | ---: |
| 制造、定位和装配 | 28 | 28 |
| 测量扩展不确定度 | 2 | 2 |
| 焊后精整轴线变化 | 6.5 | 0 |
| 焊接制造热残余上限 | 13.5 | 20 |
| 总量 | 50 | 50 |

20 μm分支的准入条件是全孔尺寸直接合格、孔壁合格、禁止后续去料且完全卸夹。40.006～40.008 mm不再作为已证明的补偿窗：从该材料链的冷态最小／最大孔径变化及测量守界反算焊前加工窗，再判断工艺可否采用。

历史热残余15.584 μm在此预算中的条件总值为45.584 μm；它说明取消工序值得优先研究，不能作为现行材料链通过证据。旧细时间孔径极差约25.961 μm已提示直接H7合格存在风险，须用当前结果复核。若孔径直接合格条件不成立，不得只改标签占用20 μm预算；应先修订焊接收缩、焊序／接触或补偿窗。径向3 μm微珩保持为原有限分支的备查措施，不默认恢复为主工序。

## 3. 只采用一个第二层目录对齐设计点

现有DMNA099原TDS第1页对Ø0.045 in×36 in棒给80～110 A、13～16 V。选内点85 A、14 V参考，避免继续把75 A／11 V范围外组合当作唯一施工起点。85±5 A及13～15 V是可与目录核对的观察范围，实际热量仍以同步电能及真实速度计算，不能凭位于目录范围即判熔合。

通过同步提高焊速与棒材送进，维持名义单位长度供料；保留现有直径、焊速和沉积利用率设计公差。送进相对允差向外取整，没有以收紧设备公差制造通过。

| 项目 | b69设计输入 | 本轮唯一修订点 |
| --- | ---: | ---: |
| 电流／参考弧压 | 75 A／11 V | 85 A／14 V |
| 焊速 | 2.00±2% mm/s | 2.88±2% mm/s |
| 棒材送进 | 8.00±0.20 mm/s | 11.52±0.29 mm/s |
| 净功率（η=0.60设计记账） | 495 W | 714 W |
| 名义净线能量 | 247.500 J/mm | 247.917 J/mm |
| 双轨八翼名义净热 | 76.356 kJ | 76.484 kJ |
| 双轨八翼纯弧时间 | 154.254 s | 107.121 s |
| 名义棒材消耗 | 1234.033 mm | 1234.033 mm |
| 最低总供料余量 | 4.756 mm³/翼 | 4.733 mm³/翼 |
| 最短定长棒扣夹持尾及修整余量 | 1.163 mm | 1.135 mm |

仍使用两根914.4 mm棒、每翼180±0.5 mm定长、15 mm夹持尾、2 mm端部修整及≥162 mm送进行程。热账增加0.168%，名义供料量不变；47.133 s为纯弧时间差，不改写实机节拍或费用。更高瞬时功率和更快推进会改变局部热循环，旧温度／重熔／残余场不转用。

本次核算只采用已有九组CAD的最大槽口投影和一组固定供料公差；没有生成新CAD、运行FE或展开参数扫描。计算入口：`python studies/COMPETITION-DESIGN/focused_second_layer_alignment.py`。该点取得的资格是目录范围与质量／热量记账相容，第二层连续熔合、重熔与材料存留另核。

## 4. 连接只做本件一个局部断面问题

首层仍用现有CI-A1 Ø3.2、110 A、100 mm/min、200～300℃壳外预制作为起始设计。Kobelco教材支持修圆槽底、短道、分散焊序、适度热态轻击和缓冷；不把200℃保温写为已经消除白口或完全消除应力。

一次局部评价必须同时给出：实际槽的两端、全宽和圆角覆盖；法向首层存留0.65～0.75 mm；第二层覆盖及加工后组成；最终镍侧和钢侧连续熔合；两道重熔并集与有效喉部。先解决这些能改变设计的量，再考虑整件。

现有直道和模型源半宽不能自动证明6 mm槽宽完全熔合。若已有证据不足以支持直道覆盖，先修改首层施工轨迹并单独记账，不再靠放大源半宽给模型降温。Kobelco教材允许有限摆动、约不超过1.5倍电极直径；Ø3.2对应约4.8 mm，为施工方案边界，不能直接换算成保证熔宽。临时保护带、第二层轨迹和圆角须落在首镍连续覆盖之内。

当前面源在0.5 s超域，停止该输入的重复时间步／宽度试算。采用现有原始资料能约束的工艺、覆盖及断面信息；真正缺的字段分别列为一个明确输入缺口，不要求一份完全同构PQR包办所有问题，也不把本件实物试验设为设计报告工作的总前置。无可限定的熔合断面时，不输出熔合达标结论。

最终根／盖3.42／3.78 mm/s和4.30 mm包络暂时保持。本轮最低截面非喉部余量0.318777 mm²，小于满高0.04×15 mm间隙的0.60 mm²对照；下一次局部判断必须计入实际间隙／下流分配、轮廓和不确定度。失败时明确是供料、成形、重熔还是熔合不足，只修改所对应的几何／供料／能量，不同时扩候选。

## 5. 制造计算使用一个完整拓扑

不用目前只有QT／首层的原生重启去拼接第二层、壳体和工装。初始模型一次预定义QT、首镍保留区与去料区、第二层、最终焊段、壳体和必要工装／接触；按真实工序激活和卸除，继承既存积分点历史。已有原生塑化、无应变加入、冷却、删除、重启及加载功能直接复用。

预制去料区按本件法向留层和刀面预分层，采用能界定去料误差的整单元近似，不开发通用切削历史映射。实际A/B刀面、存留层厚和删除误差须读回；误差不满足层厚／孔形精度时停止这一近似，不能清零状态或把名义零面核对当实际切削完成。

冻结一个局部基准及一次必要离散复核；局部输入和有效连接可采用后，运行一个全八翼制造—冷却—完全卸夹工况及一次能解释关键不确定性的对照。周向逐段热史不使用无依据的四分之一对称。只输出孔轴、全孔最小／最大尺寸、首次界面／焊趾／槽根应力和加载卸载变化，误差≤5%且绝对裕量足以判断即停止加密。

不同材料的高温响应、热源和凝固参照按其适用来源使用；不能由室温目录强度反推高温曲线，不能沿用被否决的factor3或把Ni201延拓当实际CI-A1证明。缺少能限定结论的输入时，停止依赖它的性能预测，继续完成其他有依据的设计工作。

## 6. 自动化采用固定路径和基础联锁

选定固定工装、单头、首件示教的固定两道路径；基本内容为8×18 mm×2、指定焊序、根／盖分别供料、工件测温、气水与夹具到位、停弧保持、退工具位置反馈及异常后禁止续焊。视觉自适应、在线参数优化和新基准矩阵不作为主方案的实施前提。

当前程序默认6段路径和旧1.5 mm/s／150℃信号必须纠正。优先修正路径和工艺入口的主对象、版本、工序及坐标，再逐项接入固定监测窗。将旧视觉／信号回放明确留在历史入口；既有算法成绩不代表当前八翼控制链。

HJ-022／023目前没有加入04装配。只补实际采用的新副压环、承托及退出接口，不重新造整个工装库；几何检查覆盖枪、棒、产品、压环、托环和固定障碍的工作及退出状态。机械止挡、固定支承及到位反馈优先形成可读的执行表，采购件包络与设备订型参数分别说明。

## 7. 交付只以四个结果收口

1. 当前局部接头的材料、覆盖、有效熔合及重熔／存留论证。
2. 当前制造状态下完全卸夹的Ø0.05 mm位置度、直接孔径合格及同状态承载结果。
3. 当前工装、路径和检测可执行的统一卡图；无损盲区有明确处置。
4. 当前正文、工艺卡、STEP和计算依据一致的主包；历史失败、圆环比较及备用微珩另册。

本轮先保存审核与路线，再保存一个真实参数核算，后续每完成一个工程决定分别提交。主包不因路线文件或纯弧时间改动重复整包生成；工程决定同步到执行源和卡图后统一重建一次。
