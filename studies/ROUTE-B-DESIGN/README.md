# 无实物条件选型

输入 `config.yaml` 引用现有工艺、材料、公差及 CAD 接口。运行 `python studies/ROUTE-B-DESIGN/run.py`，生成 `results/result.csv`、`assessment.json` 和 `run-inputs.json`；报告表格由当前证据摘要统一生成。

比较 Continuous、6P、8P 的单道诊断和四道目标情景。固定名义送丝，对原有沉积效率区间两端、参考载荷缩放及许用应力假设执行确定性组合。每个情景用自身沉积体积计算等效焊脚和承载系数，分别核算总净热输入、弧能、弧燃时间与耗材。不得把弧燃时间当总节拍或把热输入当实际用电量。

选型仅在简化连接能力约束下最小化名义净热输入；不是工艺放行。原有 432 例结构敏感性仍没有稳健排序，正式热场和整件热塑性门继续关闭。公差反算表只分配目标，不能证明夹具精度已达到要求。项目实物数据不是本研究运行依赖。
