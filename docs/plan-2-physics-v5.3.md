## 物理阻断：填丝质量与热源沉积

由仓库名义焊丝 Ø1.2 mm、送丝2 mm/s、行走1.5 mm/s计算，100%沉积率对应每单位焊长的填丝体积为 **1.508 mm²**。名义3.5 mm等脚角焊缝截面积为 **6.125 mm²**；当前网格中的全高度焊缝带约 **132.462 mm²**，分别是上述填丝量和名义角焊缝面积的 **87.84倍 / 21.63倍**。

角焊缝截面包含母材熔化贡献，不能把6.125/1.508直接解释成送丝倍率。但整个132.462 mm²区域预先赋予焊丝物性、或将其作为新增焊丝激活，都无法代表登记的实际填丝量。当前双模型因此保留为**同一失配焊缝带的敏感性实验**。

逐段激活时，空单元不导热、不蓄热；按焊枪位置激活后以20°C出生焓入账，新增空腔面有对流/辐射损失。热源在完整计算域内按原0.2权重归一化，落在空域的部分单列为未吸收能量，禁止向剩余单元集中。

名义工况输入19800 J中，激活模式吸收约14653.63 J，空域未吸收约5146.37 J（约26.0%）。所以797.15→786.96°C不能证明“预存在焊缝抑制峰温10°C”：质量、散热路径和有效沉积热量同时变化。完整计算域捕获PASS与活动材料吸收FAIL分开登记，不能用能量守恒掩盖源沉积模型不适用。

账本为 `E_absorbed + E_birth = ΔU + E_convection + E_radiation + residual`，另有 `E_nominal = E_absorbed + E_void`。出生焓非零与跨相变的独立测试均通过。所有结果保持 `solver_result_unvalidated`。

**密度处理。** 增加三种材料的固态膨胀情景 `J(T)=exp(3∫α_tangent dT)`、`rho(T)=rho_ref/J(T)`，检查 `rho(T)J(T)=rho_ref`。原材料表没有明确α是瞬时还是平均系数，所以这种解释本身仍是design_assumption；NiFe仅有常温α，常值延伸也明确标为假设。α倍率0.8–1.2只作工程敏感性，不是测量置信区间。

当前0.3求解器继续使用固定参考质量，不直接把rho(T)塞进固定体积的能量更新。否则会人为改变总质量。[COMSOL参考构形热物性说明](https://doc.comsol.com/6.3/doc/com.comsol.help.metproc/metproc_ug_theory.4.11.html)同样强调密度参考温度与质量守恒。空间密度变化必须同时处理体积变化或质量输运；本轮没有宣称实现移动网格或液相输运。

Q235/QT的情景范围受已有α表和保守固相线下限共同限制，NiFe受固相线下限限制。缺失温区返回null/missing_evidence，尤其三种材料1500°C密度均未补造。**完整20–1500°C实测rho(T)、液相密度和高温物性证据仍未取得。**

### 表面热流直接作用于首个可见材料面

改用45°入射的前后双高斯**表面热流模型**，沿s的a_front=6 mm、a_rear=10 mm及投影横向宽度b=2.5 mm保持原值，前后权重保持0.6/1.4；体积Goldak的深度参数c不再用于表面模型。这是明确的新源模型假设，不是将旧26%空域功率集中补回，也不是实验校准。

在无限s/u投影平面解析归一化，再按射线选取首个已有母材或已出生填丝表面。填丝遮挡母材后只由首面接收；尚未出生区域仍由实际存在的母材表面接收。独立射线—矩形相交oracle复核表面权重；人为删除一侧接收面时，总接收功率随之减少，不会自动归一化恢复495 W。

[GTAW热流模型对比研究](https://journals.sagepub.com/doi/10.1243/09544054JEM1886)比较过表面高斯与体积Goldak模型；这里仅据此说明表面模型具有方法依据，不转用其材料/工艺标定。45°方向、阶梯自由表面和源尺度仍需真实接头/宏观截面约束。
