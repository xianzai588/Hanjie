### 待完成（Phase 1 核心任务）

**P1A Phase 1 的真正目标不是"画出来"，而是把参数化几何规则写死。**

#### 1. 确定槽根圆角统一值

**任务**：
- 检查 R2.0 mm 是否对所有拓扑（4P/6P/8P）均几何可行
- 若不可行，选择统一最大公共值（如 R1.5 mm）
- 记录最终选择理由

**约束**：
- 不与 Ø82 核心区穿透
- 不与 4 mm 槽几何冲突
- 不产生零厚度/极窄区域

**禁止**：为了降低某个方案应力而单独调整圆角

#### 2. 明确 Wing Width 几何定义

**必须回答**：
> Wing width = R74.98 mm 外缘处的哪个几何量？
> - 弦长？
> - 切向宽度？
> - 圆弧长度？
> - 恒定宽度？

**要求**：所有 FAIR-A/B 采用完全相同定义

#### 3. 建立 3D 实体几何

**使用统一生成规则**：
```
中心刚性区 Ø82
    ↓
按 N 等分中心角
    ↓
每个翼拥有参数化中心角
    ↓
从核心区向外缘延伸
    ↓
两翼之间切除径向槽
    ↓
槽根统一圆角 R_f
    ↓
外缘到 R74.98
```

**禁止**：人工独立绘制 7 份

#### 4. 自动几何检查

**必须通过**：
- Solid 有效（`is_valid = True`）
- Boolean 成功
- 无自交
- 无零/负体积
- 无重叠
- 无零厚度区域
- 坐标系一致

#### 5. 计算实际几何属性

**必须输出**：
- Planform area (mm²)
- Solid volume (mm³)
- Calculated mass (kg)
- Nominal total weld length (mm)

**用途**：后续评价比刚度 K/m

#### 6. 更新 Geometry Manifest

**将 null 字段填充为实际值**：
```json
"geometry": {
  "planform_area_mm2": 12345.67,
  "solid_volume_mm3": 123456.78,
  "calculated_mass_kg": 0.889
}
```
