# V4.2 比赛路线与修复计划

2026-09-05；基于当前本地工作树审计，不假定与外部审查所述 main 提交一致。

## 判断与官方要求

外部审查的核心判断成立：FE3D 是预设公式代理，Adaptive 评价不公平，合成校准曾冒充物理后验，六点结论缺乏支持，误差链混合且旧表实际为 0.028 mm。更深一层的问题是：相同工况的位置度数据无法独立辨识刚度与收缩两个参数；硬度演示根本没有参加拟合。取消这些主张比继续包装算法更重要。

用户已确认设备尚未核实。原设备表中的人名、地点、订单和预约不能作为事实，已撤回。真实实验是优先争取的竞争力来源，不能写成当前具备条件，也不是官方强制交付物。

已核对上级目录《第一届辽宁省大学生材料焊接与铸造工艺设计大赛实施方案》：固定题要求 Q235B 壳体 Ø160×200×5 mm、QT450-10 环形轴承座、Ø40 孔、焊后位置度 ≤Ø0.05 mm、内腔不得落入焊渣/飞溅。必须覆盖工艺、材料、结构、检测评价、自动化五维度。固定题说明书格式与篇幅不限，可提交报告/设计图或实物。10 月 20 日前报名，10 月 25 日（含当日）交作品，由学校组织。八章结构是写作建议，不是官方模板要求；匿名条款原文位于铸造赛道，焊接作品按盲审谨慎匿名并由校负责人核实后续通知。

## 本轮修复范围

- FE3D 明确为 surrogate_result；撤销 Gate B.1，能量平衡无计算则留空。
- Adaptive 与固定序列统一 plant、预测器、评价函数和初始扰动；用同序列回放验证公平性，取消强制“必须优于/达标”的测试。
- 校准原始演示与结果写到 data/synthetic/；移除 measured 字段、硬编码后验和虚构不确定度缩减。固定刚度只辨识组合系数，输出训练残差及合成留一误差，不冒充物理独立验证。
- 结构结论 unresolved，控制与优化脚本从实际结果输出数字；七个手选点只进行有限集合非支配判断，不称全局前沿。
- evidence graph 全量标级，并增加拒绝低等级证据晋升的校验。
- 误差预算拆为产品几何、自动化路径、测量三链。产品 0.035 mm 为等效径向设计分配，未实测、未闭合；旧混合 0.028 mm 仅留纠错记录。无分布不计算 RSS/P95。
- 当前报告源只用 technical-report-v4-unified.md；旧 V2/V3 内容和提交包不进入默认构建。

统一评价重跑：扰动下 Adaptive 0.07220 mm，S3 0.06648 mm；Adaptive 更差。4P/6P/8P/Continuous 代理位置度全部超限。因此 Adaptive 暂降为候选温度安全门控，拓扑保持未定。

本轮不把真实 CAD/FE 或物理实验写成已完成。原型能运行不代表工程正确。后续仍需验证控制器的散热/热效率扰动及邻段约束、预偏置的统一保护与独立模型失配；本轮统一评价不等于这些研究已完成。

## 研究叙事与边界

两个主创新方向：公平约束下的拓扑—热工艺协同设计；物理校准驱动的温度门控与焊前预偏置闭环。证据链为支撑创新。无设备时第二方向只能称提出的待验证方法。

不能只追求变形最小：还必须有承载/疲劳、可焊性、加工与内腔洁净度约束，否则少焊甚至不焊会产生没有工程意义的“最优”。当前代理温差、应力和位移并非完整物理模型，真实预测能力不能靠测试数量建立。

暂不新增 App、Dashboard、新视觉网络或更多演示 Monte Carlo；优先建立真实几何和可信求解基线。所有日期为内部排程，设备和求解器可行性变化时调整研究范围，不改变官方截止日期或伪造通过状态。
