# 实验计划（WP5）

> 三级递进。所有试样/结构件使用唯一编号 `W2026-XXX`，原始数据只增不改（见 data/README 与 CONTRIBUTING）。

## Experiment A：材料小试样 —— 能不能焊住

- 试样：QT450-10 + Q235B 对接/角接小试件
- 检测：外观、裂纹、熔深、金相、HAZ、显微硬度、拉伸/剪切
- 输出：焊材与热输入的初步窗口

## Experiment B：工艺参数试验 —— 参数怎么定

| 因素 | 水平 |
| --- | --- |
| A 热输入 | 低 / 中 / 高 |
| B 预热 | T0 / T1 / T2（温度由焊接组定） |
| C 焊接顺序 | 顺序 / 对称 / 跳焊 |

| 响应 | 定义 |
| --- | --- |
| Y1 | 位置偏差 |
| Y2 | HAZ 硬度 |
| Y3 | 裂纹 |
| Y4 | 强度 |
| Y5 | 峰值温度 |

> 视材料与工时采用正交或分批推进。

## Experiment C：结构件验证 —— 最终能不能达标

- 样件：接近 Ø160 × H200 × t5、Ø40 孔的结构
- 流程：焊前 CMM → 焊接 → 完全冷却 → 焊后 CMM → 位置度对比
- 判据：**P ≤ Ø0.05 mm**
