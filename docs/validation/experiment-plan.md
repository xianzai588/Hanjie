# 物理验证计划（WP5，可选）

> 版本：V1.0 · 2026-09-02。由于当前没有焊机、金相/硬度和 CMM，物理验证不再是作品关键路径。相关目录保留接口，获得设备后按本计划补充；现阶段不能把数字样本当成实物实验。

## A. 材料与焊接性小试

- 试样：QT450-10 + Q235B 对接/角接小试件；编号 `W2026-XXX`。
- 候选变量：ERNiFe-CI、纯镍/镍铁过渡层、预热/缓冷、热输入窗口。
- 检测：外观、PT/UT（按工艺评定选择）、金相、显微硬度、拉伸/剪切。
- 输出：焊材、热输入、预热和冷却制度的工艺窗口；对应质保书和原始数据。

## B. 结构件位置度验证

- 样件：接近 Ø160 × H200 × t5 壳体、Ø40 轴承孔的最终结构。
- 流程：焊前建立基准并 CMM → 按工艺卡焊接 → 完全冷却并解除夹具 → 焊后 CMM → 分层拟合内孔圆和轴线。
- 判据：按比赛定义输出轴线位置度；测量不确定度、基准和重复性必须随报告归档。
