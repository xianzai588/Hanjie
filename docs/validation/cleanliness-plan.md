# 内腔洁净度验证方案

## 设计控制链

1. 工艺源头：优先采用无焊渣 TIG，限制电流/电压/焊速窗口并监控异常。
2. 空间隔离：焊前沿 `HJ-DRW-008` 路径装入低掉屑可拆卸防护罩/截留盘，保护精加工孔和 A/B 基准面；锁定后不得妨碍焊枪、送丝与保护气。
3. 焊前干运行：不引弧完成机器人全路径，检查枪体、钨极、焊丝、防护罩和夹具间隙；任一干涉即拒绝启动。
4. 方向控制：焊接、换段和冷却期间保持截留面朝上；松夹后沿规定路径退出，不翻转、不刮碰内壁，避免截留物重新落入内腔。
5. 双重核验：核对防护罩完整性与截留物，随后对内腔进行目视 + 内窥镜检查；按样件编号保存装入前、退出后和内窥原图。

## 实物放行记录

- 必填：样件号、防护罩号/材料、清洁状态、干运行结果、焊接异常、截留物数量/尺寸、内窥图路径、检查人员和时间。
- 任何防护罩破损、掉屑、退出路径失控或疑似松动物均判拒绝，不以“后续吹扫”替代原因处理。
- 防护罩材料、涂层、尺寸以及对气流/焊缝成形的影响必须先经实际接头试验确认。

## 证据边界

当前只有工艺与工装设计，没有真实飞溅/异物原始记录；报告只能写“建立了源头控制、物理隔离、受控退出和双重核验方案”，不能写“零飞溅已验证”或“洁净度已放行”。
