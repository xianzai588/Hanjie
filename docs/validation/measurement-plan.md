# 检测与测量计划（WP7）

> 四层检测体系。核心指标：**轴承孔轴线位置度 ≤ Ø0.05 mm**。不只检测"焊缝好不好看"。

## A 外观 / 无损

- 外观检查（成形、咬边、飞溅）
- PT 渗透检测
- UT 超声检测（按最终工艺选择）

## B 材料

- 金相组织（焊缝/熔合线/HAZ）
- HAZ 宽度与白口层评价
- 显微硬度梯度
- 必要力学性能（拉伸/剪切）

## C 几何（核心）

- 三坐标测量机（CMM）焊前/焊后对比测量
- 基准设定、测点布置、重复性验证（方法与检测组确认后固化）
- 输出：轴线位置度偏差、ΔX/ΔY/ΔZ、壳体变形量
- 测量流程：焊前 CMM → 焊接 → 完全冷却 → 焊后 CMM → 对比

## D 洁净度

- 飞溅与内腔异物检查规程（目视 + 内窥/拍照留档）
- 合格判据：不得存在可能落入压缩机内部的焊渣、飞溅物
