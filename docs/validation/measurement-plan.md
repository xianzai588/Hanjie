# 检测与测量计划（WP7）

> 四层检测体系。核心指标：**轴承孔轴线位置度 ≤ Ø0.05 mm**。不只检测"焊缝好不好看"。

## A 外观 / 无损

- 外观检查（成形、咬边、飞溅）
- PT 渗透检测
- UT 超声检测（按最终工艺选择）

## B 材料

- 金相组织（焊缝/熔合线/HAZ）
- HAZ 宽度与白口层评价
- 显微硬度梯度
- 必要力学性能（拉伸/剪切）

## C 几何（核心）

- CMM 焊前/焊后对比测量；视觉只用于装配和路径控制，不替代终检。
- 每次测量独立重建 A（壳体安装平面）和 B（Q235B 壳体理论轴）；C 只用于周向姿态，不进入 Ø40 孔轴位置度框。
- 沿孔深至少三个截面采点并进行稳健圆/轴拟合，报告偏移、倾斜、截面残差、异常点和整个孔轴的位置度直径。
- 统一状态：焊前基准测量 → 装配定位 → 焊接 → 冷却至 50±5 °C 设计条件 → 解除全部夹具 → 热平衡 → 重建 A/B → 焊后 CMM。
- 输出：松夹后轴线位置度、ΔX/ΔY/倾斜、壳体圆度/轴线变化、重复测量差异和测量扩展不确定度。
- 放行护栏必须由实际 CMM、测头、基准重建、采样、重复性和环境数据评定；设备 MPE 或 0.005 mm 设计裕量均不能代替不确定度。

## D 洁净度

- 飞溅与内腔异物检查规程（目视 + 内窥/拍照留档）
- 合格判据：不得存在可能落入压缩机内部的焊渣、飞溅物
