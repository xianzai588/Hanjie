# 轴承孔定位误差预算 V2

## 目的

比赛要求是 Ø0.05 mm 的位置度直径限值。数字评审先将其换算为 0.025 mm 径向总预算，再按线性最坏情况分配到定位链路；该预算是工程门的设计分配，不是实物测量结果。

| 误差源 | 径向预算 (mm) | 当前证据状态 |
| --- | ---: | --- |
| 视觉定位 | 0.010 | 数字样本；以径向 MAE 和姿态换算门限筛选 |
| 相机标定 | 0.004 | 待真实镜头/标定板实测 |
| TCP/工具中心点 | 0.003 | 待机器人标定实测 |
| 机器人重复定位 | 0.003 | 待设备重复性试验 |
| 夹具定位 | 0.003 | 当前为等效刚度假设，待装配后检查 |
| 焊接热变形 | 0.002 | 当前仅有降阶/二维代理指标，待冷却后 CMM |
| **合计** | **0.025** | 与 Ø0.05 直径限值对应 |

视觉数字门限采用 P95：径向 P95 ≤0.010 mm。姿态误差按 73.8 mm 最不利作用半径换算，角度 P95 限值为 `degrees(0.010 / 73.8)=0.0078°`；MAE 作为描述性统计保留。两项均满足才记为 `PASS`；检测器返回结果但超出任一门限时记为“检测成功、工程 FAIL”。

这些分配值尚未经过相机、机器人、夹具或焊后实测标定。制造放行时应以实际测量的不确定度预算和焊后 CMM 结果替换本数字评审分配。
