# 03 设备清单调查

> 状态：v0.3 可执行版（技术纠错后）· 2026-08-30
> **Gate 1：09-01 前全部填实。** 本表结论直接驱动[工艺选型](process/01-process-selection.md)中“学校设备可实现性”一栏评分，以及第一轮实验计划。
> 填写要求：每行必须给出「有 / 无 / 待约」三态之一 + 信息来源（哪个实验室、哪位老师）；型号拍铭牌照片存 `data/samples/`；可用时间写具体到“每周几 / 需提前几天预约”。
> 校内没有的设备，必须写明替代渠道（兄弟院校 / 企业 / 外检机构）与对接人和费用估计，不能留空。

## 4. 母材与焊材采购（与设备同等重要）

| 项 | 需要确认的问题 | 结论 |
| --- | --- | --- |
| QT450-10 轴承座 | 比赛是否发坯料？自购铸件还是铸态毛坯？供应商与**供货周期**？能否提供成分质保书？ | |
| Q235B 壳体 Ø160×200×5 | 无缝钢管改制还是卷板焊制？来源与周期？ | |
| 焊材 | 镍基焊条（EZ408/ENiFe-CI 类）、镍基焊丝（ERNiFe-CI）、不锈钢焊材的现货/货期 | |
| 备件数量 | 铸件与壳体按实验计划至少备 3 倍于最终作品数（焊废率高） | |

> ⚠ 若铸件供货周期 >2 周，**09-05 前必须下单**，否则 P4 第一轮实验（09-19 起）断粮。

## 5. 调查结果 → 选型决策规则

| 调查结果 | 对工艺选型的直接后果 |
| --- | --- |
| 激光源 + 送丝 + 机器人三者缺一 | 方案 A 降分或出局；纯激光无填丝焊球铁白口风险需文献二次确认 |
| 无 CMT/冷弧电源 | 方案 B 只能依赖外借，或降级为普通脉冲 MIG 重评飞溅项 |
| 有 TIG 电源 + 变位机 | 方案 C 最低可行动组合，保底方案 |
| 无机器人 | 自动化主线转向变位机 + 专用工装 + 视觉引导（Issue #11 架构随之调整） |
| 无 CMM | P6 验收改外检或专用检具，须在报名方案中写明测量途径 |
