# 焊接性分析（WP1）

> V0.1 目标：2026-09-05（P1）。负责人：待定。
> 本文档回答核心问题：**为什么 QT450-10 / Q235B 不能简单按普通低碳钢来焊。**

## 1. QT450-10 球墨铸铁

- [ ] 化学成分与碳当量（CE）
- [ ] 基体组织（铁素体为主）与球状石墨形态
- [ ] 热导率、热膨胀系数、线收缩特性
- [ ] 熔焊裂纹风险：白口层、马氏体、HAZ 脆硬组织
- [ ] 球状石墨高温行为（氧化、长大、进入熔池）

## 2. Q235B 钢

- [ ] 化学成分与焊接性评价（碳当量低，焊接性良好）
- [ ] 5 mm 薄板焊接特点：热输入窗口、烧穿/变形风险
- [ ] 热物性参数（导热系数、比热、膨胀）

## 3. 异种连接核心矛盾

- [ ] 熔点/热导率差异 → 熔池不对称、熔深不一致
- [ ] 膨胀系数差异 → 残余应力与焊后变形（直接威胁 Ø0.05）
- [ ] 铸铁侧白口/脆硬相 → 裂纹源
- [ ] 石墨进入熔池 → 焊缝增碳、气孔
- [ ] 焊材路线：镍基（ENiFe-CI / ERNiFe-CI）vs 铁基（E309 / ER309L 等）——文献+实验确认

## 4. 风险清单

| 风险 | 机理 | 控制思路 | 验证手段 |
| --- | --- | --- | --- |
| 白口层 | 快冷 + 高碳扩散 | 降低热输入、预热/后热、镍基焊材 | 金相 + 显微硬度 |
| 冷裂纹 | 拘束应力 + 脆硬组织 | 结构设计、焊接顺序、预热 | PT + 金相 |
| 变形超差 | 薄壳 + 局部热源 | 焊缝布局/顺序/夹具/反变形 | 仿真 + CMM |
| 气孔/夹渣 | 石墨氧化、熔池扰动 | 工艺参数、保护气 | X光/UT/金相 |
