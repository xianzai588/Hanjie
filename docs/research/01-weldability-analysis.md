# 焊接性分析（WP1）

> V0.1 初稿 · 2026-08-30（供材料组核验与纠错，不是定稿）。目标节点：2026-09-05（P1）。
> 本文档回答核心问题：**为什么 QT450-10 / Q235B 不能简单按普通低碳钢来焊。**
> 标注约定：〔共识〕= 教科书级结论；〔待文献〕= 需补文献证据并记入 [references.md](references.md)；〔待实测〕= 以质保书或实验为准。

## 1. QT450-10 球墨铸铁

- 〔共识〕GB/T 1348 规定：Rm ≥ 450 MPa、Rp0.2 ≥ 310 MPa、A ≥ 10%，基体以铁素体为主 + 球状石墨。
- 〔待实测〕实际成分以供应商质保书为准；典型范围 C 3.4~3.9%、Si 2.2~2.9%、Mn ≤ 0.3%，另有少量残余 Mg/RE 球化元素。
- 〔共识〕碳当量 CE ≈ C + (Si+P)/3 ≈ 4.3~4.7，属过共晶高碳材料，焊接冷裂与白口倾向大，焊接性本质差。
- 熔焊时的热影响区分带（球铁焊接典型特征）〔共识〕：
  1. **半熔化区（白口层）**：贴近熔合线，冷却快、石墨来不及析出，形成莱氏体 + 枝晶碳化物，硬度可达 500 HV 以上，极脆，是裂纹主要起源地。白口层厚度随热输入降低、冷却加快而增大〔待文献定量：白口层厚度 vs 热输入/预热温度曲线〕。
  2. **完全奥氏体化区**：快冷时生成马氏体/贝氏体 → 硬化脆化；慢冷则得到珠光体 + 铁素体。
  3. 球状石墨在高温下可能被氧化、溶入熔池 → 熔池增碳、CO 气孔；Mg/RE 烧损。
- 〔共识〕铸铁强度低、塑性几乎为零，不能靠塑性变形松弛应力 → 拘束应力直接叠加到脆硬区，裂纹多起于球铁侧熔合线。
- 球铁相对灰铸铁：球化元素增大白口与淬硬倾向〔待文献确认程度〕，焊材通常需选镍含量更高的体系。

## 2. Q235B 钢

- 〔共识〕GB/T 700，C ≤ 0.20%，CE ≈ 0.26~0.34，5 mm 厚度下一般无需预热，冷裂风险低，焊接性优良。
- 〔共识〕本件风险不在裂而在**变形**：Ø160×200、壁厚 5 mm 的薄壁圆筒径向刚度低，局部集中热输入易引起椭圆化、翘曲与端面的倾斜/平移。
- 〔共识〕轴承孔轴线位置度 ≤ Ø0.05 mm 的威胁链：焊缝收缩 + 壳体变形 + 装配误差 → 轴承座孔轴线偏移。控制杠杆是焊缝布局、焊接顺序、热输入总量与夹具拘束（WP3/WP4）。

## 3. 异种连接的核心矛盾（修正后的物理图像）

- 〔共识，修正原骨架表述〕两者热膨胀系数相近（均约 11~13 ×10⁻⁶/K）、热导率差异也有限，**主要矛盾不是热物理差异，而是冶金 + 力学**：
  1. **熔点与流动性不对称**：球铁熔点低（约 1150~1250 ℃）、铁液流动性好，钢约 1500 ℃ → 熔池在球铁侧易过热、熔深不对称，热源布置需偏向钢侧或采用对称热输入设计〔待文献〕。
  2. **碳迁移与稀释**：球铁高碳，若用铁基焊材且稀释率高，焊缝金属会变成高碳马氏体，硬脆必裂 → **焊材路线（镍基/奥氏体）是本项目的核心决策**，见 [../process/filler-material.md](../process/filler-material.md)。
  3. **CO 气孔**：[C]+[O]→CO，铸造表面氧化物与石墨都是气孔源 → 焊前清理规程必须进工艺卡。
  4. **力学弱侧在球铁**：低拘束设计、对称布点、逐段跳焊、锤击消应力都是围绕这一点。
  5. **洁净度硬要求**：飞溅、焊渣不得进入内腔 → 倾向低飞溅工艺 + 防飞溅遮挡 + 焊后内腔检查规程（对应 Issue #23）。

## 4. 工艺方向初判（文献共识方向，逐条待确认）

- 球铁焊接主流路线：**镍基焊材 + 较低热输入 + 严格层间控制**的“冷焊/低温焊”思路；传统高热输入“热焊法”虽降低白口但变形代价大，对本件位置度公差不利。〔待文献系统确认〕
- 焊点布局倾向多点、短段、对称、跳焊；单点热输入尽量小 → 与“焊不歪”目标同向。
- 激光类工艺冷却极快，球铁侧白口风险是其最大疑点；TIG/CMT 类电弧工艺的热输入可调范围更宽。→ 工艺对比证据见 [../process/01-process-selection.md](../process/01-process-selection.md)。

## 5. 风险清单

| 风险 | 机理 | 控制思路 | 验证手段 |
| --- | --- | --- | --- |
| 白口层 | 半熔化区快冷 + 高碳 | 预热/层间控制、热输入匹配、镍基焊材 | 金相 + 显微硬度线扫 |
| 冷裂纹 | 拘束应力 + 脆硬组织 + 球铁零塑性 | 低拘束结构、对称顺序、预热、锤击 | PT + 金相 |
| 焊缝热裂纹 | 镍基焊缝金属凝固裂纹敏感性〔待文献〕 | 控制成形系数与稀释率 | 金相 |
| 气孔 | 石墨/氧化物 + CO | 焊前清理、保护气、参数 | RT/UT/金相 |
| 变形超差 | 薄壳 + 局部热源 | 布局/顺序/夹具/反变形 | 仿真 + CMM |
