# 焊接性分析（WP1）

> V1.0 执行版 · 2026-09-02。证据来源与适用边界见 [evidence-matrix.md](evidence-matrix.md)。
> **状态：数字工程设计依据；不替代 QT450-10 质保书、焊接工艺评定或实物检测。**
> 本文档回答核心问题：**为什么 QT450-10 / Q235B 不能简单按普通低碳钢来焊。**
> 标注约定：〔机理证据〕= 有相近对象文献支持；〔设计假设〕= 本项目数字样机输入；〔物理验证门〕= 必须由质保书、工艺评定或检测确认。

## 1. QT450-10 球墨铸铁

- 〔共识〕GB/T 1348 规定：Rm ≥ 450 MPa、Rp0.2 ≥ 310 MPa、A ≥ 10%，基体以铁素体为主 + 球状石墨。
- 〔物理验证门〕实际成分以供应商质保书为准；典型范围只作为 `docs/05-design-assumptions.md` 的风险背景，不作为本批铸件实测成分。
- 〔机理证据 + 物理验证门〕高碳当量球铁具有白口与淬硬风险；具体 CE 和亚/共/过共晶属性须按质保书计算，当前不把典型范围写成本件事实。
- 熔焊时的热影响区分带（球铁焊接典型特征）〔共识〕：
  1. **半熔化区（白口层）**：贴近熔合线，快速冷却时可能形成莱氏体、碳化物或马氏体等硬脆区域，成为裂纹敏感区；相近对象证据见 E001/E003。具体硬度和白口层厚度必须由本件金相/硬度确认。
  2. **完全奥氏体化区**：快冷时生成马氏体/贝氏体 → 硬化脆化；慢冷则得到珠光体 + 铁素体。
  3. 球状石墨在高温下可能被氧化、溶入熔池 → 熔池增碳、CO 气孔；Mg/RE 烧损。
- 〔共识〕QT450-10 母材具有一定塑性（A ≥ 10%），但焊接熔合区/热影响区可能形成白口、马氏体等硬脆组织，使局部塑韧性与应力松弛能力显著下降 → 拘束应力易在脆硬区集中，裂纹多起于球铁侧熔合线。
- 球铁相对灰铸铁的具体风险差异不在本轮数字模型中定量比较；本方案仅依据 E001–E004 将高镍填充列为候选，最终仍需材料老师审核与工艺评定。

## 2. Q235B 钢

- 〔共识〕GB/T 700，C ≤ 0.20%，CE ≈ 0.26~0.34，5 mm 厚度下一般无需预热，冷裂风险低，焊接性优良。
- 〔共识〕本件风险不在裂而在**变形**：Ø160×200、壁厚 5 mm 的薄壁圆筒径向刚度低，局部集中热输入易引起椭圆化、翘曲与端面的倾斜/平移。
- 〔共识〕轴承孔轴线位置度 ≤ Ø0.05 mm 的威胁链：焊缝收缩 + 壳体变形 + 装配误差 → 轴承座孔轴线偏移。控制杠杆是焊缝布局、焊接顺序、热输入总量与夹具拘束（WP3/WP4）。

## 3. 异种连接的核心矛盾（修正后的物理图像）

- 〔共识〕两材料热膨胀系数处于相近量级（均约 11~13 ×10⁻⁶/K），但热导率、比热、密度等热物性参数温度相关，其差异不能因此忽略（仿真时均须真实输入）；本项目焊接性的主要高风险仍来自**高碳球铁侧的冶金变化 + 焊接拘束 + 薄壳变形**：
  1. **熔点与流动性不对称**：球铁与钢的热物性和熔化行为不同，熔深不对称作为设计风险输入；本项目不把未核对的熔点数字写成材料实测，热源偏置需在工艺评定中确认。
  2. **碳迁移与稀释**：球铁高碳，高稀释条件下焊缝金属易形成高碳硬脆组织，裂纹风险显著增加，因此铁基焊材不作为优先候选路线 → **焊材路线（镍基/奥氏体）是本项目的核心决策**，见 [../process/filler-material.md](../process/filler-material.md)。
  3. **CO 气孔**：[C]+[O]→CO，铸造表面氧化物与石墨都是气孔源 → 焊前清理规程必须进工艺卡。
  4. **球铁侧是裂纹敏感侧**：熔合区/热影响区局部塑韧性低、应力松弛能力弱 → 低拘束设计、对称布点、逐段跳焊、锤击消应力都是围绕这一点。
  5. **洁净度硬要求**：飞溅、焊渣不得进入内腔 → 倾向低飞溅工艺 + 防飞溅遮挡 + 焊后内腔检查规程（对应 Issue #23）。

## 4. 工艺方向初判（文献共识方向，逐条待确认）

- 球铁焊接的候选方向为**镍基焊材 + 受控热输入 + 冷却管理**；E001–E004 提供相近对象机理依据，但不构成 QT450-10/Q235B 本件的工艺评定结论。
- 焊点布局倾向多点、短段、对称、跳焊；单点热输入尽量小 → 与“焊不歪”目标同向。
- 激光类工艺冷却极快，球铁侧白口风险是其最大疑点；TIG/CMT 类电弧工艺的热输入可调范围更宽。→ 工艺对比证据见 [../process/01-process-selection.md](../process/01-process-selection.md)。

## 5. 风险清单

| 风险 | 机理 | 控制思路 | 验证手段 |
| --- | --- | --- | --- |
| 白口层 | 半熔化区快冷 + 高碳 | 预热/层间控制、热输入匹配、镍基焊材 | 金相 + 显微硬度线扫 |
| 冷裂纹 | 拘束应力 + 脆硬组织 + 局部塑韧性低 | 低拘束结构、对称顺序、预热、锤击 | PT + 金相 |
| 焊缝热裂纹 | 镍基焊缝金属仍需评估凝固裂纹敏感性 | 控制成形系数与稀释率 | 工艺评定/金相 |
| 气孔 | 石墨/氧化物 + CO | 焊前清理、保护气、参数 | RT/UT/金相 |
| 变形超差 | 薄壳 + 局部热源 | 布局/顺序/夹具/反变形 | 仿真 + CMM |
