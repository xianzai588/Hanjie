## 关键原则

1. 没有焊机、金相和 CMM 时，物理验证降级为可选工作包，不阻塞数字工程主线。
2. 所有结果必须标注为“文献证据”“设计假设”“降阶模型结果”“数字样本测试”或“实测”。
3. `P_sim ≤ 0.05 mm` 只能写成“所建模型下满足设计指标”，不能写成实物已达标。
4. 真实实验条件一旦获得，按相同样件编号和数据模式补录；不覆盖已有数字样本。
