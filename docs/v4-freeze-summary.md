## 📊 Gate B 验证门（必须全部通过）

### Gate B.1: 网格收敛

**判据**：相邻网格级主要指标变化率

| 指标 | 阈值 | 说明 |
| --- | ---: | --- |
| 位置度 P | < 5% | 两级都必须 < 5% |
| 峰值温度 T_peak | < 10% | 两级都必须 < 10% |
| 最大应力 σ_eq_max | < 15% | 两级都必须 < 15% |

**网格序列**：G51 → G61 → G71 → G81

### Gate B.2: 热场合理性

**检查项**：
- 峰值温度 1300-1600°C（TIG 熔池范围）
- HAZ 宽度 3-10 mm（> 723°C 区域）
- 热源移动速度 = 1.5 mm/s
- 层间温度 ≤ 200°C

### Gate B.3: 边界条件

**检查项**：
- 夹具约束清单完整
- 释放时机明确（50±5°C）
- 热边界条件正确

### Gate B.4: 材料参数

**检查项**：
- 温度相关性合理（单调性）
- 来源标注清晰
- 不确定性评估

**只有 Gate B.1/B.2/B.3/B.4 全部通过，才允许开展 4/6/8 结构对比（V5）。**

## ⚠️ 风险与缓解

### 风险 1：网格收敛未达标

**影响**：Gate B.1 不通过，无法进入 V5

**缓解**：
- 预留 G91 加密网格
- 优化网格过渡策略
- 检查单元类型选择

### 风险 2：峰值温度超范围

**影响**：Gate B.2 不通过，热源模型不合理

**缓解**：
- 调整 Goldak 热源参数（a_f, a_r, b, c）
- 与文献 HAZ 尺度交叉验证
- 必要时引入热源标定试验

### 风险 3：求解不收敛

**影响**：无法获得结果

**缓解**：
- 调整时间步长、增量步
- 优化非线性求解设置
- 检查接触定义、材料本构

### 风险 4：计算时间过长

**影响**：进度延误

**缓解**：
- 优化网格过渡
- 并行计算（多核）
- 简化远场网格
