### 一、V3 P0 级硬伤修复 ✅

#### 1. P0-1：R73.8/1.2mm 接头几何矛盾
**问题**：翼端半径与壳体留 1.2 mm 间隙，工程图标注"2D FE equivalent"被当成实体几何，不符合官方"贴合连接"。

**修复**：
- `geometry.json`: `wing_outer_radius` 从 73.8 改为 74.98 mm
- 新增 `assembly_fit: "H7/h6"`，单边间隙 0.01～0.04 mm
- 新增 `joint_type: "fillet_weld"`，腿长 3.5 mm
- 所有工程图删除 "1.2 (2D FE equivalent)" 标注
- 7 张 SVG 工程图重新生成

#### 2. P0-2：Ø39.96 定位销与 0.003 mm 夹具误差预算矛盾
**问题**：定位销单边间隙约 0.02 mm，但夹具定位只分配 0.003 mm 预算，尺寸链矛盾。

**修复**：
- `geometry.json`: 增加锥形心轴参数
  - `mandrel_type: "tapered"`
  - `mandrel_taper_ratio: 0.02` (1:50)
  - `positioning_repeatability: 0.008 mm`（可信）
- 夹具总装图更新为锥形心轴 + 端面定位
- 设计假设文档增加心轴参数

#### 3. P0-3：误差预算混淆装配链与自动化链
**问题**：V2 把视觉、TCP、机器人、夹具、热变形线性相加，混合了"轨迹控制"和"零件几何"两个层次。

**修复**：
- 创建 `simulation/scripts/error_budget_v3.py`
- 区分两条独立链路：
  - **装配/制造尺寸链**：壳体 → 夹具 → 偏心 → 焊接(0.012) → 回弹 → 最终孔轴线
  - **自动化路径控制预算**：视觉(0.018) → 标定 → TCP → 机器人 → 焊枪轨迹
- 生成 `docs/validation/position-error-budget-v3.md`
