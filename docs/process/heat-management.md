# 热管理（WP2）

> V0.1 · 2026-08-30。目标：控制球铁侧白口与脆硬组织，同时不引入额外变形。
> 下表档位为候选初值（铸铁焊接常识范围），使用前须文献确认；最终数值由第一轮小试标定。

## 预热

| 档位 | 温度 | 说明 |
| --- | --- | --- |
| T0 | 不预热 | 基准，镍基冷焊思路 |
| T1 | 100~150 ℃（候选） | 抑制白口又不显著增大变形〔待文献〕 |
| T2 | 200~300 ℃（候选） | T1 小试仍有白口时上探〔待文献〕 |

> 热焊法（>400 ℃）对本件原则上不采用：对位置度 Ø0.05 而言变形代价过大，仅保留作对比试验。

## 层间 / 后热

- [ ] 层间温度上限：候选 ≤100~150 ℃〔待文献〕；用测温枪/热电偶监控（测温手段见设备调查 §1、§3）
- [ ] 后热缓冷：焊后保温缓冷（石棉/保温毯），禁止急冷
- [ ] 焊后去应力退火（PWHT）对球铁焊缝的作用与变形风险：待定项〔待文献 + 实验〕
- [ ] 与焊接顺序（S1/S2/S3）耦合：层间上限决定跳焊时单轮可连续焊的点数（仿真 + 实验确认）

## 应力与散热路径

- [ ] 逐点锤击消应力：铸铁焊接常用手段，参数与洁净度影响（锤击氧化皮）〔待文献 + 实验〕
- [ ] 夹具热设计方向：**球铁侧禁止强冷**（铜垫板等加速冷却会加重白口），夹具承担定位与拘束；散热功能仅限 Q235B 侧，见 [../../cad/fixture/](../../cad/fixture/)
