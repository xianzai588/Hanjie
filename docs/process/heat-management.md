# 热管理（WP2）

> V0.1 · 2026-08-30 · **技术预研版，须经材料老师审核后才能作为实验依据。**
> 目标：控制球铁侧白口与脆硬组织，同时不引入额外变形。
> **原则：每一种工艺路线独立定义"预热—层间—冷却"温度窗口，窗口内部必须自洽；不设统一层间上限。数值由文献确认 + 第一轮小试标定后才锁定。**

## 温度窗口（按路线独立定义）

| 路线 | 定位 | 预热 | 层间上限 | 冷却方式 |
| --- | --- | --- | --- | --- |
| P0 冷焊/低预热 | 基准，镍基冷焊思路 | 室温~低温（数值待定） | 与 P0 预热水平自洽 | 保温缓冷 |
| P1 中等预热 | P0 白口超标时上探 | 数值待文献 | 与 P1 预热水平自洽 | 保温缓冷 |
| P2 较高预热 | P1 仍不足时上探 | 数值待文献 | 与 P2 预热水平自洽 | 保温缓冷 |

> 热焊法（>400 ℃）对本件不作优先选项：对位置度 Ø0.05 而言变形代价过大，仅保留作对比试验。
> 测温手段（测温枪/热电偶）见设备调查 §1、§3；监控点布置随路线定义一并给出。

## 后热与热处理

- [ ] 后热缓冷：焊后保温缓冷（耐高温保温毯 / 陶瓷纤维保温材料 / 实验室许可的焊接保温材料），避免急冷
- [ ] 焊后去应力退火（PWHT）对球铁焊缝的作用与变形风险：待定项〔待文献 + 实验〕
- [ ] 与焊接顺序（S1/S2/S3）耦合：各路线层间窗口决定跳焊时单轮可连续焊的点数（仿真 + 实验确认）

## 应力与散热路径

- [ ] 逐点锤击消应力：铸铁焊接常用手段，参数与洁净度影响（锤击氧化皮）〔待文献 + 实验〕
- [ ] 夹具热设计（V0.1 原则）：避免直接对球铁熔合区实施强化冷却——过快冷却可能加剧硬脆组织风险；若引入铜质散热/主动冷却结构，须经热循环仿真 + 金相 + 硬度验证其对球铁侧冷却速度与白口层的影响；优先研究 Q235B 壳体侧的可控散热，见 [../../cad/fixture/](../../cad/fixture/)
