## 1. 冶金设计目标

本接头为 QT450-10 球墨铸铁与 Q235B 低碳钢的异种连接，焊缝金属由 NiFe-55 填充金属与两侧母材的熔入量共同组成。冶金设计要在此体系上同时达成三项目标：

1. **焊缝金属全程保持奥氏体基体**：以面心立方奥氏体提供延性与止裂能力，冷却过程中不出现马氏体转变通道；
2. **定量说明两侧母材的淬硬机理**：以同一套当量坐标解释 Q235B 侧的免预热依据与 QT450-10 侧的必然淬硬区，使工艺对策有明确的冶金指向；
3. **把相图结论翻译为可执行的冷焊工艺条款**：稀释率上限、线能量、层间温度 ≤ 100 ℃、焊后半热态锤击。

## 2. 当量公式与成分输入

### 2.1 当量公式

采用 Schaeffler 当量（Schaeffler, A.L., *Constitution Diagram for Stainless Steel Weld Metal*, Metal Progress, 1949）：

$$\text{Cr}_{eq} = \%\text{Cr} + \%\text{Mo} + 1.5\,\%\text{Si} + 0.5\,\%\text{Nb}$$

$$\text{Ni}_{eq} = \%\text{Ni} + 30\,\%\text{C} + 0.5\,\%\text{Mn}$$

马氏体转变开始温度按经验式核算：

$$M_s\,(^\circ\text{C}) = 561 - 474\,\%\text{C} - 33\,\%\text{Mn} - 17\,\%\text{Ni} - 17\,\%\text{Cr} - 21\,\%\text{Mo}$$

**适用域声明。** Schaeffler 图由 Cr_eq 约 0～30、Ni_eq 约 0～25 的不锈钢焊缝数据归纳得出，分区分界仅在该域内有效。本体系 NiFe-55 与高稀释焊缝金属的 Ni_eq 达 46～57，超出图面范围：本文的组织判定不读图分区，按 Fe–Cr–Ni 相图与高镍奥氏体合金的已知规律定性判断（Fe–Ni 系 Ni 超过约 30% 时室温奥氏体即为稳定相）；文中"边界余量"仅表示与外推 A+M 分界（Ni_eq 约 12～16）的远离程度，不作为定量裕量使用。Ms 经验式标定域为低合金钢，对 Ni_eq > 25 的算例仅作方向性参考。

## 3. 母材与填充金属当量点

### 3.1 Q235B

$$\text{Cr}_{eq} = 0.05 + 0.01 + 1.5\times0.22 = 0.39 \qquad \text{Ni}_{eq} = 0.05 + 30\times0.17 + 0.5\times0.50 = 5.40$$

落点 **(0.39, 5.40)**，在相图上位于马氏体区，$M_s = +462\ ^\circ\text{C}$：说明 Q235B 熔合线在快冷条件下具备形成马氏体的当量条件。

**但这不构成本件的淬硬风险。** Q235B 的碳当量

$$CE = \%\text{C} + \%\text{Mn}/6 + \%\text{Si}/24 = 0.17 + 0.083 + 0.009 = 0.263\%\ <\ 0.40\%$$

低于国际通用的免预热判据（0.40%）。低碳马氏体在焊接热循环中自回火软化，硬度上升量有限，不形成冷裂纹源。**结论：Q235B 侧按碳当量判据免预热，这一结论与第 6 节取消预热的冷焊制度完全一致。**

### 3.2 QT450-10：名义口径与基体口径

直接代入名义成分得 $\text{Cr}_{eq} = 3.95$、$\text{Ni}_{eq} = 109.75$。该点远离相图常规范围（横轴 0～30、纵轴 0～30 的常用绘制区），是 $30\times\%\text{C}$ 项在铸铁碳量下的外推产物，**不能按图直接判读组织**。Schaeffler 相图的标定对象是碳含量 ≤ 0.15% 的钢焊缝金属，当碳含量提高一个数量级后，碳在冷却过程中的去向发生根本变化。

对球墨铸铁作**石墨化修正**：完全石墨化的 QT450-10，球状石墨体积分数约 11 vol%。按石墨密度 2.25 g/cm³、基体密度 7.70 g/cm³ 换算，石墨碳质量分数

$$w_{\text{C,石墨}} = \frac{0.11\times2.25}{0.11\times2.25 + 0.89\times7.70}\times100\% = 3.49\%$$

基体固溶碳 $w_{\text{C,基体}} = 3.65\% - 3.49\% = 0.16\%$，基体当量点为

$$\text{Cr}_{eq} = 3.95 \qquad \text{Ni}_{eq} = 0.05 + 30\times0.16 + 0.5\times0.40 = 5.18, \qquad M_s = +468\ ^\circ\text{C}$$

基体口径落点 **(3.95, 5.18)** 位于相图马氏体区。这与球墨铸铁的工程事实一致：**铸铁的淬硬倾向来自基体，而不是来自石墨球本身**；石墨球在基体中只是碳的储库，一旦受热溶解即向周围奥氏体供碳。

### 3.3 NiFe-55

$$\text{Cr}_{eq} = 1.5\times0.13 = 0.20 \qquad \text{Ni}_{eq} = 55.00 + 30\times0.01 + 0.5\times0.70 = 55.65$$

落点 **(0.20, 55.65)**，$M_s = -402\ ^\circ\text{C}$。填充金属自身即为稳定的单相奥氏体，且不含铁素体形成元素，冷却过程中不存在 δ 铁素体析出与马氏体转变通道。

## 4. 稀释轨迹：焊缝金属当量点

### 4.1 稀释率定义与工况取值

$$D = \frac{A_{\text{母材熔入}}}{A_{\text{母材熔入}} + A_{\text{填充沉积}}} , \qquad r = \frac{A_{\text{QT450-10}}}{A_{\text{母材熔入}}}$$

首道采用低电流、不摆动、快焊速的小熔深工艺，电弧偏向钢侧，铸铁侧熔深受控；后三道只重熔前道表面，不再增加母材熔入。取 $r = 0.40$ 为设计工况；$r = 0.30$（钢侧熔入比例更大、填充金属被稀释更重）为保守工况。对稀释率作 10%～50% 全域扫描，覆盖设计目标与极限装配波动。

### 4.4 组织判定与设计结论

**（1）全域落于单相奥氏体域。** 在 10%～50% 的全稀释区间内，两个 r 工况共 14 个算例的 Cr_eq 均在 0.32～1.18 之间、Ni_eq 均在 46.18～56.61 之间。按 §2 适用域声明，判定不读图分区：最小 Ni_eq 46.18 已是 Fe–Ni 系室温稳定奥氏体域（Ni 约 ≥30%）的 1.5 倍以上；即使把外推的 A+M 分界（Ni_eq 约 12～16）放大 3 倍，全部算例仍在奥氏体侧——组织判定对稀释率与工艺波动不翻转。

**（2）无马氏体转变通道。** 全部算例的 $M_s$ 在 −217 ℃ ～ −395 ℃ 之间，深度低于室温。焊缝金属冷却至 20 ℃ 时，马氏体转变的驱动力条件不成立；组织为单相面心立方奥氏体，不出现马氏体岛。

**（3）无 δ 铁素体。** Cr_eq 最高仅 1.18，远低于 A+F 区所需的铬当量水平，焊缝金属为**单相奥氏体**而非奥氏体＋铁素体双相。奥氏体面心立方结构在低温下无解理倾向，断裂韧性优于任何含铁素体或马氏体的混合组织。

**（4）碳的全部去向可控。** 全稀释区间焊缝碳含量 0.13%～0.79%。镍奥氏体对碳的固溶度远高于铁素体，该碳量在奥氏体中的固溶度范围内；冷却过程中碳以固溶态保留或析出细小球状石墨，不形成连续渗碳体网。这是镍铁基填充金属区别于普通碳钢焊材的核心机理。

**（5）设计裕量的意义。** 即使装配间隙超差、电流偏高导致稀释率翻倍至 50%，焊缝组织仍距边界有 30 个当量单位的余量。**组织判定在工艺参数全波动域内不翻转**，因此焊缝组织不是本接头的不确定项。

## 5. 铸铁侧熔合区的冶金判断与冷焊体制选择

### 5.1 熔合区的两级冶金事实

**（1）半熔化区的碳回溶。** 熔合线附近峰值温度达 1100～1200 ℃，球状石墨在此温度下向周围奥氏体回溶，局部碳含量升至该温度的饱和值（Fe-C 系 1150 ℃ 时约 1.3～1.7 wt%）。若按当量公式计算，该区 Ni_eq 被推到 39～51，形式上"落于奥氏体区"。

**（2）碳当量在冷却过程中失效。** 碳稳定奥氏体的能力依赖固溶状态。铸铁不含镍，一旦冷却，回溶的碳必须以石墨（稳定系）或渗碳体（介稳定系）的形式析出；快冷条件下石墨析出被抑制，碳转向介稳定系，形成莱氏体白口带。**碳当量在凝固与后续冷却中不再代表奥氏体稳定性**，残余奥氏体的稳定性只能由 Ni、Mn 等置换型元素提供，而铸铁基体不含镍。

**结论：铸铁侧熔合区无法通过母材自身成分避免脆硬组织。消除该组织只能从外部引入镍，这正是 NiFe-55（Ni 55%）的选型依据。** 相图计算在此给出的不是一个"安全点"，而是一条明确的工艺指向：把足够量的镍送到熔合线上。

### 5.2 热焊法与冷焊法的工程决断

| 路线 | 白口抑制能力 | 对 Ø0.05 mm 位置度的影响 | 本件适用性 |
| :--- | :--- | :--- | :--- |
| 热焊法（预热 400～600 ℃） | 强：显著延缓冷却，碳充分石墨化 | 不可接受：座体在预热温度下预置 151.15 kJ 蓄热，为四道名义净热输入的 106%；自由收缩量达 0.378 mm | 不采用 |
| **冷焊法（不预热、层间 ≤ 100 ℃）** | 中等：白口带薄但存在 | 可控：自由收缩量 0.063 mm，组件净热输入温升约 41 K | **采用** |

**冷焊体制的定量依据：**

**（1）蓄热对比。** 座体由 BREP 实体计算得质量 0.6846 kg，球墨铸铁比热 460 J/(kg·K)：

| 起焊前座体温度 | 相对 20 ℃ 的蓄热 | 占四道名义净热输入 142.56 kJ |
| :--- | ---: | ---: |
| 100 ℃（冷焊层间门上界） | 25.19 kJ | 17.7% |
| 150 ℃（历史预热设计点） | 40.94 kJ | 28.7% |
| 500 ℃（热焊法） | 151.15 kJ | 106.0% |

**（2）与层间温度门的数值冲突。** 预热 150 ℃ 使座体起焊前即处于 150 ℃，高于层间温度门 100 ℃ 的上界——**预热 150 ℃ 与层间 ≤ 100 ℃ 在数值上互斥，两者不能并存**。冷焊制度下起焊温度为车间环境温度（≥ 15 ℃），层间门成为唯一的热状态约束。

**（3）收缩失配量。** 座体外缘半径 74.98 mm，QT450-10 线膨胀系数 10.5×10⁻⁶/K。焊缝冷却时座体的自由径向收缩量为 $r\alpha\Delta T$：

| 热制度 | 相对 20 ℃ 的温差 | 自由径向收缩量 |
| :--- | ---: | ---: |
| 冷焊层间 ≤ 100 ℃ | 80 K | 0.0630 mm |
| 预热 150 ℃ | 130 K | 0.1024 mm |
| 热焊 500 ℃ | 480 K | 0.3780 mm |
| 层间 200 ℃（历史口径） | 180 K | 0.1418 mm |

该收缩量全部由焊缝与工装协调。冷焊制度的 0.0630 mm 处于焊缝塑性协调能力范围内；热焊法的 0.3780 mm 超过白口带的断裂应变，必然在熔合线直接开裂。**把层间温度上限由 200 ℃ 收紧到 100 ℃，把协调量降到原来的 44%。**

**（4）温度不均匀性直接进入位置度预算。** 孔心与焊道之间存在温差 $\Delta T$ 时，差异膨胀产生的径向漂移为 $r\alpha\Delta T$。令其等于 Ø0.05 mm 位置度对应的径向限值 0.025 mm，解得

$$\Delta T = \frac{0.025}{75\times10.5\times10^{-6}} = 31.7\ \text{K}$$

**孔区与焊道之间只要存在 31.7 K 的温差，其差异膨胀即达到整个位置度指标。** 降低整件温度水平就是降低温度梯度与差异膨胀幅值——这是取消预热、执行层间 ≤ 100 ℃ 的第二个直接理由。

**（5）层间温度门的可达成性（两尺度估算）。** 层间温度是焊道局部温度，须分两个尺度估算，不能以整件平均温度代替。**整件尺度**：组件（座体 0.6846 kg ＋ 壳体 3.823 kg ＋ 紫铜衬环 0.0497 kg）等效热容 2092 J/K，四道名义净热输入 142.56 kJ 按 60% 留存率对应整体温升 40.9 K，终焊整件温度约 61 ℃——该尺度只说明整件不会持续蓄热失控。**局部尺度**：每段每道净热输入 330 J/mm × 18 mm = 5.94 kJ；同一焊段相邻两道间隔约 160 s（跳焊序列上 5 个段次 × 32 s），铸铁热扩散率约 1.0×10⁻⁵ m²/s 下扩散特征长度 √(4αt) 约 80 mm，单段热量摊入约 0.18 kg 的翼—壳体—衬环局部库容（约 85 J/K），按 60%～70% 留存计贡献局部残余温升约 40～50 K；叠加当时整件已积累温升约 31 K，估计焊道局部层间温度约 85～105 ℃（车间 20～25 ℃）。估算值骑在门限附近：**层间门保留为硬联锁，超温由状态机插入等待**（数十秒量级回落），紫铜衬环强制吸热与底口对流使估算偏向保守；试制阶段以热电偶实测标定。

### 5.3 冷焊体制下的防裂工艺链

白口带在冷焊体制下虽薄但客观存在。本设计不试图消除它，而是限制其厚度并使其不承受拉应力：

| 环节 | 工艺条款 | 冶金作用 |
| :--- | :--- | :--- |
| 限制熔深 | 首道 75 A / 12 V / 1.5 mm·s⁻¹，不叠加横向摆动；铸铁侧熔深 ≤ 0.5 mm | 压缩半熔化区宽度与回溶碳量，白口带厚度控制在 0.2 mm 量级 |
| 后续道次 | 第 2～4 道只重熔前道表面，不再增加母材熔入 | 稀释率随道数单调下降，熔合线不再二次受热 |
| 镍基稀释 | NiFe-55 引入 55% Ni，熔合线形成富镍奥氏体过渡带 | 碳以固溶态被接纳；熔敷金属 Rp0.2 = 300 MPa、A5 = 8%，面心立方奥氏体无解理倾向，形成承接收缩应变的塑性过渡区 |
| **层间 ≤ 100 ℃** | 各监测点温度 ≤ 100 ℃ 方可起下一道 | 限制整件蓄热与温度梯度，把收缩协调量压到 0.063 mm |
| **半热态锤击** | 每段收弧后焊道表面 400～500 ℃ 时立即气动圆头小锤轻击 | 把熔合线的残余拉应力转为压应力，白口带虽硬但不承受拉应力 |

## 6. 焊后半热态锤击（Peening）工艺规范

### 6.1 机理与定量核算

铸铁冷焊的裂纹三要素为硬脆组织、拉应力与氢。本接头以 TIG 焊接、99.999% Ar 保护、无焊剂，氢源被源头消除；硬脆白口带由第 5.3 节的熔深与稀释控制压到 0.2 mm 量级；**剩下唯一需要直接处理的是拉应力，锤击正是处理它的手段。**

在 400～500 ℃ 半热态下，镍铁奥氏体的屈服强度降至室温值的 40% 左右，此时锤击可在焊道表层引入塑性延展。表层塑性应变取 $\varepsilon_p = 0.3\%\sim0.8\%$，冷却至 20 ℃ 后按弹性恢复折算的应力松弛能力为

$$\Delta\sigma = E_{20}\,\varepsilon_p = 190\ \text{GPa}\times(0.3\%\sim0.8\%) = 570\sim1520\ \text{MPa}$$

该值远高于焊缝金属室温屈服强度（Rp0.2 = 300 MPa），因此锤击层在冷却后**稳定处于压应力状态，压应力幅值上限由熔敷金属室温屈服强度决定（约 250～300 MPa）**。这一压应力场直接抵消焊接冷却产生的残余拉应力，使熔合线应力状态由拉转压。

同时，锤击打断柱状晶的连续取向、细化表层亚结构，使裂纹即使萌生也难以沿单一方向扩展。

### 6.2 执行规范

| 项目 | 工艺条款 |
| :--- | :--- |
| **时机** | 每段收弧后立即进行，焊道表面 400～500 ℃（暗红色刚消失）；不得等焊道完全冷却后补击 |
| **工具** | 气动圆头锤，球头 Ø8 mm（范围 Ø6～10 mm），工作气压 0.4～0.6 MPa |
| **频率** | 冲击频率 2000～3000 次/min，锤击搭接率 ≥ 75% |
| **覆盖范围** | 焊道全宽及熔合线两侧各 5 mm |
| **力度判据** | 以焊道表面形成均匀麻点、压痕深度 0.1～0.2 mm，且无撕裂、无层状剥离为准 |
| **禁止事项** | 禁止在低于 300 ℃ 的冷态焊道上锤击（此时塑性不足，锤击直接成为裂纹源）；禁止使用尖头锤或凿击 |
| **与道次的关系** | 四道、每道六段，共 24 个段次，逐段收弧后逐段锤击；不得整道焊完再统一锤击 |

### 6.3 锤击与层间温度门的时序

单段的完整循环为：**焊（12 s 弧燃）→ 停弧 → 锤击（400～500 ℃ 窗口内）→ 跳焊至下一段 → 全部六段完成即一道结束 → 监测点全部 ≤ 100 ℃ 后进入下一道**。锤击窗口与层间温度门工作在两个不同的温度尺度上：锤击作用于焊道局部（400～500 ℃），层间门约束整件基体（≤ 100 ℃）。二者互不冲突，共同构成本设计的冷焊热制度。
