## 候选技术要点（V0.1 · 风险假设，待证伪）

> 状态标注：技术预研版，须经材料老师审核。

| | A 激光/填丝 | B CMT/脉冲 MIG | C 自动 TIG |
| --- | --- | --- | --- |
| 假设优势 | 热输入最低、速度最快、变形最小潜力 | 低飞溅 + 低热输入，镍基焊丝可机械化送丝 | 技术最成熟，镍基铸铁焊材体系完整（焊条/填充棒路线），设备门槛低 |
| 风险假设（待证伪） | 冷却极快 → 球铁侧白口层风险；装配间隙要求高；镍基送丝难 | 镍基焊丝货源与送丝稳定性；设备依赖 | 热输入相对偏大，需小参数/多点分段压缩；节拍慢 |
| 飞溅/洁净度（假设） | 好 | 好（低飞溅是卖点） | 好（基本无飞溅） |
| 设备依赖（详见 [../03-equipment-inventory.md](../03-equipment-inventory.md)） | 激光器 + 送丝 + 机器人 | CMT/冷弧电源 + 机器人或变位机 | TIG 电源 + 变位机 |
| 决定性未知 | 球铁快冷白口（文献 + 小试） | ERNiFe-CI 丝材可购性与送丝 | 热输入-变形平衡（仿真 + 小试） |
