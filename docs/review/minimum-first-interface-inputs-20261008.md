## 发给资料提供方的最少格式

提交一个带编号的资料包即可：`说明.pdf`注明来源/页码、批次、QT与焊材成分/基体、实际工艺和几何；截面图附标尺与原始轮廓坐标。采用壳底z=0的项目坐标，另给各截面的局部原点、方向和转换关系。

- 热记录CSV：`件号,焊段/截面号,t_s,x_mm,y_mm,z_mm,T_C,U_V,I_A,v_mm_s,测量方法,U`；缺项留空并说明，不补造数值。
- 轮廓CSV：`件号,工序,截面位置_mm,材料/边界名称,点号,x_mm,y_mm,z_mm,法向厚度_mm,U_mm`；增重和去料量另列同件记录。
- 物性CSV：`材料/状态,T_C,E_MPa,nu,alpha_per_K,alpha定义,T_ref_C,屈服_MPa,塑性应变,应力_MPa,rho_kg_m3,来源页码,适用范围`；固液/凝固参照规则用一段说明附原始出处。

## 连续制造计算的输入资格与停止规则

此处门槛针对恢复连续热—力制造计算，不要求在推进任何工程论证前先取得全部资料。用户目前只能做无实物设计，适用公开原始证据可按问题逐项取得；不同来源组成输入包时须核对材料状态、几何、工序及参考态。逐项补证顺序见no-physical-evidence-route-20261008.md，现有目录、组织机理、几何和容量需求仍可用于各自适用范围内的设计论证。

先按目标响应检查组合资料能否限定**本工艺的足迹/吸热、熔合断面、存留材料及高温响应**，形成有来源、范围及迁移理由的输入包。某项结论的约束不足，仅停止依赖该约束的计算；公开证据、截面几何、容量及制造接口仍继续。不启动宽度、物性或求解器搜索。详细判断见evidence-transfer-20261008.md及macroscopic-manufacturing-plan-20261008.md。

输入取得资格后，仅对这一个实际局部接头使用既定顺序热—力表示，检查连续首次熔合、凝固冷态及实际法向去料后的存留状态；质量、应力、塑性和参照连续传递。只作必要独立离散对照，关键响应差≤5%且适用域及绝对余量足以判断即固化结果。温区超域、状态不可继承或有效连接不足时保存实际原因并停止；不裁温、调任意软化或清零历史。
