# 高镍层热机械输入与制造状态接口

日期：2026-10-07。对应CI-A1独立预制→法向修整→低碳Ni99第二层→8P最终组焊主线。

## 已核实的材料依据

[VDM Nickel200/201原厂数据表，2022年3月，第4～5页](https://www.vdm-metals.com/fileadmin/user_upload/Downloads/Data_Sheets/Data_Sheet_VDM_Nickel_200_201.pdf)给出软退火商业纯镍的温度相关弹性模量：20、300、600、900℃分别为205、190、165、134 GPa；Ni201短时Rp0.2在20、300、600℃分别为80、60、40 MPa。它们可以用于高镍基体参考情景；其Ni≥99.2%、C≤0.02%成分及软退火状态与CI-A1熔敷态不同，不能直接标作本件焊缝实测值。

[Washington Alloy ENi-CI原厂产品页](https://www.washingtonalloy.com/ni-99/)给出另一产品焊态的典型Rp0.2约276 MPa、Rm约345 MPa。其熔敷成分C0.055%、Fe0.850%，并非CI-A1约C1.0%、Fe1.8%的同一成分；该值只可说明商业焊态与软退火参考的差别，不能赋给CI-A1或PMZ。本轮不切换产品。

CI-A1原目录给出抗拉典型值480 MPa，未给出本件所需的完整高温塑性曲线。抗拉强度不能当作屈服强度。Ni201的600℃以上屈服和900℃以上弹性模量不能以原厂表名义补齐。

## 制造重放必须保留的物理状态

1. 首层热史由每个已收敛时间步的节点温度、镍单元占有率、实际时间和前沿组成。进入焓与新增质量已分开核验；温度适用域以实际场检查。
2. 300℃初始均温、每翼19.281695 mm连续首层、空气冷却至500℃、转200℃保温炉及后续随炉冷却分别记录。八翼顺序为1—5—3—7—2—6—4—8，道前实际界面200～300℃，炉边界恢复时保留温度场。一翼炉冷已到20.0493℃；八翼实际热史独立计算，不复制一翼残余应力。
3. 新生凝固域剪切参照采用当时偏应变；体积参照由同一冷态包络质量、20℃密度与参考体积确定，热态膨胀由原本构和平衡方程形成。不得把冷态包络指定为高温无应力体积而重复计入收缩，也不得沿用统一1200℃清零规则。存留固体的塑性、应力与参照跨工序保留；参考坐标更新时质量随原材料传递。
4. 法向0.70±0.05 mm修整、第二层后表面加工以及入壳前最终孔加工，应真实删除加工域，并在剩余域重新求平衡。映射同时传递存留材料、固化参照和塑性状态；不以重设零应力代表切削。
5. 最终连接只对已经核验的连续熔合域赋予传力关系。8P完全冷却与卸夹后计算孔轴、孔径，再在同一状态加载、卸载。

## 计算决策

球铁参考温度形状取自[Farahani等2024原论文Fig4](https://doi.org/10.1007/s00170-024-14487-7)，来源牌号为GJS500-14。室温E约170 GPa、900℃约102 GPa；屈服温度形状按QT450工程名义310 MPa/来源图读380 MPa迁移。平均膨胀系数直接乘(T−20)，不再积分一次。牌号、Si含量及重熔组织差异列入材料参考边界，未取得硬化曲线的QT采用理想弹塑性。

Ni201原厂Table4b在20～600℃的Rp1.0−Rp0.2为25 MPa，两个规定塑性偏移点给出H=25/(0.010−0.002)=3125 MPa的塑性弦斜率；零塑性屈服相应为Rp0.2−0.002H。600℃以上的屈服及硬化降至液相线零，900℃以上E按末段斜率延拓，均明确记录为参考延拓。此处理复现原厂两个偏移点，不把它赋为CI-A1熔敷态容量。

机械相域取实际P1出生前沿与P1固体温域的交集；存留量取前后固体域与旧出生域的共同部分。塑性和固化参照按存留体积传递。QT切割单元外域自由度仅从同一QT固体作仿射延拓；液体不跨域提供支承。QT/CI先保留独立自由度，实际整面1400℃热连接取得资格后，在整面低于两侧固相线时进入连续固体传力分支。该整面凝固时序随后按制造响应检查。

质量—密度参照的自由体1000→20℃检查恢复8890 kg/m³、无塑性；参考坐标放大1%而保留原质量时，密度截断误差0.01495%。当前1 s机械检查`mma-one-wing-solid-cold-mass-volume-first1s-20261007`最大平衡残差0.037164 N，完全固体单元最小det(F)=1.010220、有限/线性体积差0.1066%。完整一翼接续正确的`phase-front-dt0125`热史和实际炉冷，在已接受3.5 s状态改用四线程继续，当前输出`mma-one-wing-solid-cold-mass-volume-t4-20261007`；温度与占有率恢复差均为零，再执行法向去料与剩余域平衡。

弧末恢复后出生前沿曾被误初始化，故旧`phase-cooling`及相应炉冷仅为诊断结果，不用于制造。当前按实际累计质量恢复前沿，补一次冷却时间减半与一次局部h0.45对照；比较凝固体积及连续界面凝固覆盖，不由峰温收敛替代制造响应。早期失败场继续保留，未用于孔形或强度结论。

正确凝固域对照最大时间/空间响应差1.4866%/1.5930%，全部已热连接面在22.694017 s成为连续固体；记录为`phase-resolved-cooling-verification.json`。原2 s冷却共同实际取时的凝固体积差最大33.56%，不能继承其后段机械状态。正确炉冷最高温20.049309℃，未将既有应力或塑性改成均温退火零态。

先完成首层整面连续热连接及关键响应离散检查，再建立有来源的高镍弹性/塑性参考情景。对未量定的本构参数报告孔形敏感性及所需输入范围；实际设计仍以13.5 μm热轴额度、3 μm径向微珩上限和50 μm完整位置预算检验。PMZ容量单独评价，不作为停止制造需求分析的理由，也不由上述基体资料代替。
