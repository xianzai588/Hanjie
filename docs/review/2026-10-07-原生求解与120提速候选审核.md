## 新问题一：名义填槽通过不构成供料窗口通过

按保存的CAD和末段I²供料公式独立复算：名义槽体积163.440577 mm³、设计密度8.89 mg/mm³，名义填槽质量1.452986731 g。120 mm/min、0.17 g/s时沉积1.588365599 g，名义总量余量0.135378868 g。130.804629 mm/min仅为上述输入条件下的零余高上限，不能称为不受供料变化影响的绝对上限。

历史输入project/independent-precoat-candidates.yaml曾将CI-A1熔敷率0.15～0.333333 g/s列为工程敏感性区间，并明确不作为厂家保证。当前没有据此取得一个更窄的实际供料下限。在0.15 g/s情景下，120 mm/min仅沉积1.401499058 g，比名义整槽需求少0.051487673 g；同情景下100 mm/min为1.690724490 g。这个反例证明新候选比原方案更依赖供料输入，不能只引用名义0.17 g/s宣布稳定填槽；它并不证明真实设备一定只有0.15 g/s。

再作一个明确限定的深度敏感性估算：保持名义平面面积115.168683 mm²，槽深均匀增加0.10 mm，体积增加11.516868 mm³。120候选剩余质量余量仅0.032993909 g，约为名义沉积量2.077%。若再假设首层速度上浮2%，余量仅约0.000857750 g。这里的+2%是敏感性情景，当前首层卡尚未规定该公差；均匀加深也不是已完成的真实R1.5公差CAD包络。不得把这组估算写成正式最不利公差验收值。

修正要求：先用代数核算明确供料下限、首层速度公差、槽体积公差及端部/转角最低轮廓条件。没有来源支持的供料下限不得临时缩窄。若不能在已知边界下保持覆盖，120只能保留为待确认候选，不能替换当前pWPS。总量大于槽体积仍不证明焊道能均匀覆盖6 mm槽壁和两端。

## 新问题二：提速比较同时包含派生的源深变化

两个input.json与run_mma_startup_check.py表明，有效源深取volume_equivalent_floor_to_top_mm：

| 项目 | 100 mm/min | 120 mm/min |
| --- | ---: | ---: |
| 有效源宽 / mm | 3.2 | 3.2 |
| 有效源深 / mm | 1.952379 | 1.632225 |
| 最终源锚点z / mm | 115.452379 | 115.132225 |
| 液态输运参考因子 | 3 | 3 |
| 最大观察QT液化深度 / mm | 约7.985 | 7.250665 |

源深下降16.398%，源高度随质量等效包络变化。这是现有建模规则的派生结果，不是偷偷手工调源宽；但材料总量闭合本身没有证明实际体积热源深度必须等于包络总高度。因此可以说“在相同包络—热源规则下，提速方案的条件预测改善”，不能说“保持全部热源空间参数不变，仅由焊速使熔深下降”。

净热下降16.906%有独立能量核算依据；液化深度仅下降约9.2%，且仍约7.25 mm。其physical_source_calibrated标记仍为false，不宜将该深度写成实测或已确定的制造结果。[Hu等的原始研究](https://doi.org/10.1016/j.addma.2024.104379)讨论热源参数与熔池轮廓标定，不能由借用其液态传热方法获得CI-A1本件标定资格。

修正要求：在修订卡、报告和候选输入说明中列出上述派生变化与适用边界，不为拆分这一影响再开热源矩阵，也不要求自研完整熔池流体计算。
