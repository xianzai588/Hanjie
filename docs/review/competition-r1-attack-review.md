# COMPETITION-R1 评委攻击式技术预审（RC11）

本预审与当前说明书、参数源文件和提交包保持同一口径。数字设计、文献类比和实物验证分别陈述。

## 常见追问

| 攻击问题 | 一句话答复 | 依据与边界 |
| --- | --- | --- |
| 为什么选6P而不是8P？ | 6P是当前低热输入优先方案，8P是静力承载筛查备选。 | 6P/8P四道净热输入142.56/190.08 kJ；边界规则只按其载荷与60 MPa静力筛查输入切换，不代表疲劳放行。 |
| 52.173 MPa是什么？ | 是静力参考载荷角点下的等效喉部筛查值。 | 模型将喉面积剪切等效项与倾覆正应力作平方组合；字段名为required_allowable_mpa，不是FAT疲劳名义应力。 |
| 1.150代表什么？ | 是60 MPa人工静力筛查值与52.17 MPa筛查值之比。 | 只用于条件承载筛查，不是疲劳裕量，也不是材料或焊缝许用值。 |
| 焊后位置度是否达标？ | 尚未闭合，也没有实物测量结论。 | 七项终加工基准链为0.0138 mm径向、Ø0.0276 mm直径；加目标测量不确定度为Ø0.0296 mm设计分配，但不含焊接收缩。0.20 mm径向余量在0.213 mm压力比较情景下仍未闭合。 |
| 为什么预热候选是150℃？ | 150℃仍是待评定候选，材料批次证明门尚未通过。 | QT450-10牌号类别为铁素体—珠光体；本批质保书和金相缺失。TWI的铁素体/珠光体温度行属于MMA/MIG，没有TIG认可窗口。未完成批次金相和TIG试件前，不能冻结预热值。 |
| 为什么现在不把PWHT固定下来？ | 已把PWHT升为正式比较路线，但三个分支都未放行。 | R007是FC250灰铸铁修复TIG：无PWHT有高硬HAZ；NiFe+PWHT降低HAZ硬度但使焊缝硬度升至约403 HB；Ni-CI+PWHT在该FC250研究中组织/硬度合格。本件须比较材料强度、硬度梯度和热变形后再选。 |
| 52.17 MPa除以FAT能得到疲劳裕量吗？ | 不能，两者应力定义和评定口径不匹配。 | 52.17 MPa是静力喉部筛查值；FAT对应疲劳细节在2×10⁶循环处的名义应力等级。当前删除了两者相除所得的比值。 |
| FAT 63/71/80是否能用在本件？ | 不能直接指定到本件。 | R009是钢制间断角焊缝焊趾研究；其试验中的起止段未显著改变寿命、等效结果至少FAT71，很多高于FAT80。它只提供焊趾类比，不能证明铸铁/钢TIG接头等级。 |
| 焊根疲劳等级是多少？ | 本版不冻结数值，待查标准原文并按接头详图评定。 | R010/R011研究承载角焊缝焊根评定路径；IIW XIII-2460-13、EN 1993-1-9表8的具体类别仍待馆藏核对，不能借用焊趾类别。 |
| 没有实物为什么可以提交？ | 固定题允许研究报告、设计图或研究实物；当前提交的是可复核的数字设计作品。 | 几何、计算、材料类比、参数来源和拒绝逻辑可核验；没有把文献对标写成实焊、硬度或疲劳实测。 |

## 需正面回答的四个问题

| 问题 | 答辩回答 |
| --- | --- |
| 108 mm焊缝能保证压缩机长期疲劳寿命吗？ | 目前不能作寿命保证。6P只在声明的参考包络下通过条件静力筛查；实际载荷谱未知，焊趾与焊根没有本接头FAT等级或试验寿命。R009只作钢焊趾类比，R010/R011提示根部需独立评定；8P也只是静力备选。 |
| 为什么不直接照TWI把预热定为150℃？ | TWI对球铁的温度是MMA/MIG典型值，没有TIG列。本项目QT450-10实际批次组织未确认，所以150℃仍冻结为候选；材料组织证明和TIG工艺评定通过前不放行。 |
| NiFe强度有供方数据，是否足以选定？ | 供方给出的Rm 450 MPa、Rp0.2 300 MPa是典型熔敷金属值，可用于强度量级匹配说明；它不是本接头的许用值。PWHT路线还要核对硬度和变形。 |
| 位置度公差链算术闭合，为什么仍未通过？ | 0.0138 mm径向链及Ø0.0296 mm含目标不确定度分配不含焊接收缩；独立压力比较要求约0.213 mm径向余量，超过现有0.20 mm。因此位置度与加工余量仍待实物回填。 |

## 预审结论

本轮已纠正三类表述：将52.17 MPa及1.150限定为静力筛查；把焊趾和焊根拆开并撤销错误的FAT比值；把QT450-10批次组织证明设为预热、PWHT与WPS/PQR冻结的前置门。当前未闭合项见说明书§9.2与参数文件material_qualification_gate。答辩时按“已完成证据—适用边界—成立条件—失败处置”回答，不把设计或文献对标说成实物验证。
