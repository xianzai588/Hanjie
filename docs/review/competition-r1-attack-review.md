# COMPETITION-R1 评委攻击式技术预审（RC1）

本审查面向答辩准备，不把数字设计证据提升为实物验证。每题给出一句话答复、30秒展开和证据位置。

| 攻击问题 | 一句话答复 | 30秒展开 / 证据 |
|---|---|---|
| 为什么是6P而不是8P？ | 6P在当前保守筛查通过且热输入更低，8P是边界失败时的切换方案。 | 6P净热142.56 kJ、8P为190.08 kJ；见说明书第2.1节、12～13号边界附件。 |
| 60 MPa从哪来？ | 它是人为参考包络下的条件筛查值，不是焊缝真实许用应力。 | 载荷题面未给真实谱，60 MPa仅用于一致比较；见参数来源表。 |
| 52.173 MPa是什么？ | 是6P在参考载荷包络、最小焊脚和效率下界下的所需许用应力。 | 不代表母材、焊材或疲劳许用；见 `assessment.json` 与 authority。 |
| 没有四道热结构仿真凭什么谈Ø0.05？ | 不预测最终位置度，只给出误差预算和热残余失败边界。 | 基线允许热残余0.0102 mm，设计目标0.008 mm；超界触发重设计。 |
| 0.0102 mm怎么算？ | 0.025径向限值减去0.0138其他径向误差和0.001测量折算。 | 公式和全部场景在 `position-boundary.json/csv`。 |
| 为什么目标取0.008 mm？ | 它是预算内的设计分配，不是热求解或实物测得值。 | 当前基线还剩0.0022 mm；不利场景降至0.0072 mm并失败。 |
| 六槽会不会应力集中？ | 会，因此槽底、材料和弹性回程被列为制造前验证门。 | 槽底R1、17-4PH候选、壁厚2 mm；HJ-R1-006明确未作制造签审。 |
| 2 mm壁厚、0.8槽宽依据是什么？ | 是满足40 mm孔内功能接触、可加工槽和受控柔性的设计冻结值。 | 属于C级设计输入，需样件弹性与疲劳复核，不冒充计算认证。 |
| M12×1.5是否过度设计？ | 它只承担拉回和回退确认，径向力由机构限力，不把螺纹当作定位基准。 | 设可更换限力垫片、回退肩和机械止挡；见HJ-R1-006。 |
| 10°锥如何处理自锁？ | 即使摩擦自锁，也用拉杆顶回肩主动解锁。 | μ=0.20情景已列入计算，禁止依赖弹簧自行回位。 |
| 薄裙0.22%应变安全吗？ | 这是梁近似初筛，不是材料合格结论。 | 17-4PH并非薄裙唯一材料；须按候选材料屈服应变和热循环验证。 |
| 薄裙热态脱壁怎么办？ | 脱壁即洁净门失败，系统拒绝放行并要求重做防护/工艺。 | 0.35 mm顺应、热态贴壁、颗粒清点和内窥检查均为独立门。 |
| TIG低飞溅如何满足洁净要求？ | TIG只减少来源，不能宣称零飞溅；连续屏障、朝上回收和检查共同闭环。 | 见说明书第5节和证据等级总图。 |
| 为什么预热150℃？ | 它是文献窗口低端的设计点，不是已证明最优点。 | 130～180℃为窗口，裂纹/热循环门失败时上调或切换。 |
| 四道热输入会不会抵消低热优势？ | 总净热输入已按四道累计，6P仍显著低于8P和Continuous。 | 142.56/190.08/621.87 kJ 对比表已冻结。 |
| B基准是否自引用？ | B由壳体内壁双测量带拟合，胀套只负责装夹，不定义B。 | 见HJ-R1-001、说明书第6节和测量流程。 |
| 没有CMM为什么还能提交？ | 参赛提交的是纯数字设计方案，CMM是未来独立放行门。 | 已明确 `physical_position_verified=false`，未宣称产品达标。 |
| 这是设计还是已验证工艺？ | 是可复核、可进入工艺评审的设计方案，不是WPS/PQR或实物合格证。 | 证据等级总图将数字成立、设计目标、未执行项目分层。 |

## 三个致命问题（必须准备的标准答案）

以下三问是评委最可能给出的致命一击，前一版预审遗漏。答案必须能脱口而出，不能犹豫。

| 攻击问题 | 一句话答复 | 30秒展开 / 证据 |
|---|---|---|
| 108 mm 焊缝只占整圈 23%，承载裕量 1.15，凭什么保证压缩机长期高频振动下不裂？ | 不做无条件声明。6P 是低热输入优先解，承载裕量约 1.2 只适用于参考包络；一旦许用不足以覆盖 52.173×载荷倍率，系统自动切换到 8P（144 mm、39.13 MPa、FAT 63 名义裕量 1.61）。 | 三层定级表见说明书 §3.1；切换边界固化在 `studies/ROBUST-BOUNDARY/run.py`；疲劳基线 FAT 63～80 见 §6.2。**不要辩称 6P 已足够强，要讲清退出路径。** |
| 焊后位置度到底达没达到 Ø0.05？ | 预算闭合：径向合计 0.0218 mm，折合直径 0.0436，加 0.002 不确定度后合计 0.0456 mm，余 0.0044 mm；前提是热残余不超过由预算反算的 0.0102 mm。实物测量尚无。 | 反算式：0.024 − 0.0138 = 0.0102 mm；失败对照：热残余回到 0.012 则合计 0.0536 mm 超限。见 `position-boundary.json/csv` 与 §6。**必须给出数值，不能只说"待验证"。** |
| 做了那么多热仿真，结论是什么？ | 结论是热输入窗口与风险边界：600/330 J·mm⁻¹ 参数窗口与 150/200 ℃ 温带。热模型空间离散未达准入门限，因此主动不作为位置度证据，位置度交由独立测量闭环判定。 | 这是**主动的证据边界划分**，不是未完成的工作被隐藏。另 432 例敏感性的结论是"6P 与 8P 的 72 组配对不可分辨"，据此把结构选择转向热量与可制造性。见 §7。 |
| 预偏置不是要 0.0159 mm 吗？座体外缘间隙只有 0.02 mm，装得进去吗？ | 预偏置上限逐件按实测间隙反算，不使用统一值。名义间隙 0.02 mm 时残余最小间隙约 0.004 mm；处于间隙下限 0.01 mm 的批次则上限 0.010 mm，几何不可行时系统拒绝该件。 | 说明书 §3.2 反变形三级策略表；拒绝逻辑在 `studies/PRECOMPENSATION` 与夹具配置中，不是静默裁剪。 |

## 预审结论

未发现会污染当前数字选择的逻辑矛盾；主要残余风险均已显式标为设计目标或未执行验证：四道真实热—结构响应、胀套弹性/疲劳、薄裙热态贴壁、焊缝成形/裂纹、CMM与洁净度。答辩时不得把这些风险压缩成"已验证"。

**答辩表达纪律（重要）：** 诚实不等于自贬。正确的表述结构是"**做了什么 → 结论是多少 → 成立条件是什么 → 失效往哪退**"，而不是"我们没做、未验证、不宣称"。所有未闭合项已在说明书 §9.2 集中列出（L1～L10），正文中不再重复声明；答辩时如需说明边界，直接指向该节，然后用一句话给出验证优先级即可。
