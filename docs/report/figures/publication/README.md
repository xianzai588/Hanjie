# 说明书插图

通过 `python docs/report/build_publication_figures.py` 重建。五张图均为170 mm宽、85～100 mm高，提供300 dpi PNG、SVG和PDF。正文优先使用PNG，后续排版和绘图修改可使用SVG/PDF或编辑生成脚本。

| 文件名 | 图的用途 | 采用口径 |
| --- | --- | --- |
| design-route | 座体结构与制造路线 | 完整圆环为基准，八翼开口为创新候选；座体连续性与八段焊缝分别表达 |
| process-comparison | 主流工艺选型 | 据工艺机理列条件，不设主观权重或评分 |
| precision-budget | Ø0.05 mm控形预算 | 直径方向28＋2＋6.5＋13.5＝50 μm；设计分配与实测结果分别评价 |
| station-resources | 预制、缓冷和检测资源 | 完整圆环保守规划：两层各10 h预留、各10工艺位，第二层后延迟PT24位，合计44热过程/等待位 |
| precoat-section | 材料链与制造先后 | 圆环8个局部预制窗口；QT→CI-A1→低碳Ni99→NiFe55→Q235B；层次示意不按厚度比例 |

配色采用深蓝 `#24364B`、灰绿 `#3F6B68`、赭色 `#A48352`，以白底和浅灰结构图作为辅助。中文使用项目内Noto Sans SC及Noto Serif SC字体；SVG文字转为路径，PDF嵌入字体，跨系统查看无需替换中文字体。源码支持 `HANJIE_FIGURE_FONT_SANS` 和 `HANJIE_FIGURE_FONT_SERIF` 环境变量。

数据对象、数值性质、输入文件和工艺来源见 `figure-sources.json`。图中不含实测组织照片、运行日志或未经计算的仿真云图。该生成脚本只整理已有设计与资源输入，不启动热结构仿真。

完整圆环的最终连接每段有效18 mm，两端各1 mm过渡，实际路径20 mm/段/道；两道320 mm、净热96 kJ、纯弧燃193.94 s。资源图中每层10 h时隙分为300→20℃按50℃/h缓冷5.6 h、保温2 h、升温/转运2.4 h预留，属于资源规划输入。原八翼288 mm/86.4 kJ及8/9/24位核算保留在候选资料内，不用作圆环用量或圆环实算热史。
