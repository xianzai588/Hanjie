## 2. 硬性要求

- 焊后轴承孔轴线位置度偏差 ≤ **Ø0.05 mm**
- 不得产生可能进入压缩机内部的焊渣、飞溅物
- 方案须覆盖五个维度：
  1. 工艺选择与优化
  2. 材料选配与连接
  3. 焊接结构设计
  4. 质量检测与评价
  5. 自动化焊接方案

## 3. 项目主线

**基于六点柔顺连接结构的 QT450-10/Q235B 主轴承座低变形自动 TIG 异种焊接及数字化质量控制方案**。

主候选：自动 TIG + 镍铁基填充材料；对比路线：CMT/低飞溅 GMAW、激光填丝。主候选仍需在设备与小试可用时完成工艺评定。

三个核心问题：

1. **焊得住** —— 异种材料焊接性：白口、脆硬组织、裂纹、焊材、热输入、预热/后热、接头可靠性
2. **焊不歪** —— P ≤ Ø0.05 mm：焊缝数量/位置/顺序、热输入、夹具、定位、热管理、反变形
3. **稳定焊** —— 视觉定位、路径生成、自动焊接、参数采集、异常检测、批量质量追溯

## 5. 证据边界

- 官方仅给出题面材料、壳体尺寸、轴承孔直径、位置度限值和洁净度要求；未给出的轴承座厚度、外廓细节、焊缝尺寸、装配间隙和基准细节统一见 [05-design-assumptions.md](05-design-assumptions.md)。
- 数值模型输出的 `P_sim` 是按内孔分层拟合轴线构造的比较指标，不是 CMM 认证结果。
- 没有设备时，实验、金相、硬度、NDT、CMM 和真实过程采集均标记为“可选/待实施”，不能用生成数据替代实测。
