# R4 工艺设计修复与数值核验

本目录保存接触、材料焓、焊缝出生、完全卸夹计量、服役载荷与实际夹具热网络的计算程序，以及已完成算例的输入和结果摘要。当前交付版本为修订审阅稿；完整热耦合家族尚在计算，不能按已通过的正式提交稿使用。

当前完整热耦合家族：

- `8p-thermal-tool-bore006-h15-dt025-s05`：制造孔径下界。
- `8p-thermal-tool-bore008-h15-dt025-s05`：基准空间与时间步。
- `8p-thermal-tool-bore008-h1125-dt025-s05`：空间加密。
- `8p-thermal-tool-bore008-h15-dt0125-s025`：时间加密。

入口为 `run_bore_worker.py --case <目录名>`；每组完成冷却后继续独立卸夹和计量。`verify_actual_bore_family.py` 等待完整家族，核验位置度、孔径、夹具热网络与托垫等高预算、逐段温度和轻击窗口。通过数值检查后，仍需统一实际服役孔径及双头气路、节拍和资源配置，再由交付生成入口检查正式发布条件。

旧 `8p-paired-physical-*` 为已完成的冷工具参考家族，其空间差与孔径检查未通过；保留真实失败结果供设计修复，不替代新热耦合家族。`service-t15-affine-*` 为孔径40.014 mm的服役参考，不可直接冒充新制造窗口的服役验证。

版本库保存程序、几何、输入、稳定的结果摘要和较小的计算历史。大型原始网格/场数据（NPZ）、轻击全表面逐时历史、运行日志和持续更新的检查点保留本地，避免将未完成运行快照与最终证据混用；这些文件可由对应入口和输入重新计算。完整修复过程见 `docs/review/2026-10-03-报告复核与修复.md`。
