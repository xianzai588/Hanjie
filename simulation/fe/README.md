# 二维热—结构代理模型交叉检查

`run_fe_cases.py` 使用 `scikit-fem` 的三角形网格和 SciPy 稀疏线性代数，执行五组二维热—结构代理复核，并对 baseline/rigid/S3 做 41/51/61/81 网格检查：

- `FE-001`：基准刚性结构、6 点、S1；
- `FE-002`：基准刚性结构、6 点、S3；
- `FE-003`：柔顺结构、柔顺夹具、6 点、S3；
- `FE-004`：基准刚性结构、柔顺夹具、6 点、S3。
- `FE-005`：柔顺结构、刚性夹具、6 点、S3。

## 模型边界

模型包含：

- 带壳体、轴承座中心区和 6 个柔顺翼的二维平面网格；
- 逐段瞬态热传导、外边界对流和焊段热源时间序列；
- 按最大热循环生成等效残余本征应变；
- 平面应力弹性求解，夹具用支撑点 + 径向弹簧表示；
- FE 内孔节点导出后调用 `simulation/scripts/position_tolerance.py`。

二维 FE 中把翼端到壳体内壁的 1.2 mm 装配间隙以“焊接桥接区”连接，避免把真实焊接接头错误地建成脱开结构；该桥接区暂按座体材料等效，焊缝金属的独立本构和完整三维几何仍待补充。

模型不包含：

- 三维壳体高度方向热源、完整焊缝几何、相变塑性、残余应力全场和真实材料温度曲线；
- 真实焊机、CMM、金相或硬度数据。

因此报告中应称为“二维热—结构代理模型交叉检查”，并用它检查方案排序中的反例和趋势，不把 `P_FE` 写成焊后绝对位置度或实物认证。FE-002/003 及 FE-004/005 分别提供同顺序的结构与夹具匹配对照；当前网格最细相邻变化仍为 29.224%，未通过 5% 参考门，不得宣称二维 FE 已收敛或柔顺方案已获完整焊接 FE 证明。

特别限制：五组案例峰值温度约为 458–562 °C，远未达到钢/铸铁熔化温度，因此当前 FE 没有模拟熔池形成、熔合、焊缝金属激活、温度相关塑性或相变；结构求解采用最大温度驱动的等效残余本征应变、平面应力和等效径向弹簧夹具。其定位是独立结构反例检查，不是完整焊接 FE。

## 运行

```powershell
python simulation/fe/run_fe_cases.py
```

输出：`simulation/cases/FE-00x/`、`simulation/fe/results/fe-summary.csv`、`fe-convergence.csv`、`fe-summary.md` 和图表。
