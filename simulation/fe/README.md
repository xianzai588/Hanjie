# 高分辨率二维有限元复核

`run_fe_cases.py` 使用 `scikit-fem` 的三角形网格和 SciPy 稀疏线性代数，执行三组高分辨率二维热—结构复核：

- `FE-001`：基准刚性结构、6 点、S1；
- `FE-002`：基准刚性结构、6 点、S2；
- `FE-003`：柔顺结构、柔顺夹具、6 点、S3。

## 模型边界

模型包含：

- 带壳体、轴承座中心区和 6 个柔顺翼的二维平面网格；
- 逐段瞬态热传导、外边界对流和焊段热源时间序列；
- 按最大热循环生成等效残余本征应变；
- 平面应力弹性求解，夹具用支撑点 + 径向弹簧表示；
- FE 内孔节点导出后调用 `simulation/scripts/position_tolerance.py`。

二维 FE 中把翼端到壳体内壁的 1.2 mm 装配间隙以“焊接桥接区”连接，避免把真实焊接接头错误地建成脱开结构；该桥接区暂按座体材料等效，焊缝金属的独立本构和完整三维几何仍待补充。

模型不包含：

- 三维壳体高度方向热源、完整焊缝几何、相变塑性、残余应力全场和真实材料温度曲线；
- 真实焊机、CMM、金相或硬度数据。

因此报告中应称为“高分辨率二维 FE 热—结构复核”，并用它检查方案排序中的反例和趋势，不把 `P_FE` 写成实物认证。当前 FE-003 柔顺结构的 `P_FE` 高于 FE-001/002，需把刚性连续座体保留为对照，不得宣称柔顺方案已获高保真模型证明。

## 运行

```powershell
python simulation/fe/run_fe_cases.py
```

输出：`simulation/cases/FE-00x/`、`simulation/fe/results/fe-summary.csv`、`fe-summary.md` 和图表。
