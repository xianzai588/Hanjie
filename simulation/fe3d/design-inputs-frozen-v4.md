## 分析流程（冻结）

### Phase 1: 热分析
1. 预热至 150°C（均匀场）
2. 移动 Goldak 热源，按 S3 顺序逐段施加
3. 层间等待至 ≤200°C
4. 完全冷却至 50°C

### Phase 2: 结构分析
1. 热应变 + 弹塑性本构
2. 夹具约束保持至冷却 50°C
3. 释放夹具约束
4. 继续冷却至 20°C

### Phase 3: 后处理
1. 提取 Ø40 孔内表面节点坐标（释放后、20°C）
2. 最小二乘拟合孔轴线
3. 计算轴线位置度相对名义位置
4. 提取应力、变形、温度历程

## 输出指标（冻结）

### 主要输出
1. 孔轴线位置度 P (mm)
2. 最大等效应力 σ_eq_max (MPa)
3. 焊缝区峰值温度 T_peak (°C)
4. HAZ 宽度 (mm)（>723°C 区域）
5. 最大周向温差 ΔT_max (°C)
6. 总焊接周期时间 t_cycle (s)

### 辅助输出
- 特征点温度历程 T(t)
- 应力应变场云图
- 变形场云图
- 孔轴线偏移矢量
