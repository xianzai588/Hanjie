## Gate B 验证门（未来真实求解后执行）

### B.1 网格收敛验证

**判据**：相邻网格级主要指标变化率 < 阈值

| 指标 | G71 vs G61 | G81 vs G71 | 通过标准 |
| --- | ---: | ---: | --- |
| 位置度 P | < 5% | < 5% | 两级都 < 5% |
| 峰值温度 T_peak | < 10% | < 10% | 两级都 < 10% |
| 最大应力 σ_eq_max | < 15% | < 15% | 两级都 < 15% |

**网格序列**：
- G51: 焊缝 0.6 mm（1.2× 粗化）
- **G61**: 焊缝 0.5 mm（**基准**）
- G71: 焊缝 0.4 mm（0.8× 加密）
- G81: 焊缝 0.3 mm（0.6× 加密）

### B.2 热场合理性验证

**检查项**：

- [ ] 焊缝中心峰值温度 1300-1600°C（TIG 熔池范围）
- [ ] QT450-10 侧 HAZ 宽度 3-8 mm（> 723°C 区域）
- [ ] Q235B 侧 HAZ 宽度 4-10 mm
- [ ] 热源移动速度 = 1.5 mm/s（设定值）
- [ ] 层间温度 ≤ 200°C

**依据**：文献中 TIG 焊接球铁/低碳钢的典型热循环特征

### B.3 边界条件验证

**检查项**：

- [ ] 壳体底面固定支撑已施加
- [ ] 轴承座孔径向约束已施加（焊前+焊中）
- [ ] 约束在 T = 50±5°C 时释放
- [ ] 释放后继续冷却至 20°C
- [ ] 无过约束（自由度检查）

### B.4 材料参数验证

**检查项**：

- [ ] E(T) 随温度单调递减
- [ ] α(T) 随温度单调递增或稳定
- [ ] σ_y(T) 随温度单调递减
- [ ] 材料参数来源已标注（文献插值）
- [ ] 不确定性影响已评估

## ⚠️ 验证协议原则

### 关键原则：结果出来前编写判据

`FE3D-BASE-verification-protocol.md` 在运行前编写完成，明确：

1. 网格收敛判定方法（变化率阈值）
2. 热场合理性判定标准（温度范围、HAZ 宽度）
3. 边界条件验证清单
4. 孔轴线位置度提取算法（最小二乘拟合）

**目的**：避免确认偏误（结果出来后反向调整判据）

**执行要求**：严格按照协议验证，结果不符合时诊断模型问题，而非修改判据。

## 📞 问题诊断流程

如果 Gate B 不通过：

### B.1 网格收敛不通过

**症状**：位置度/温度/应力变化率 > 阈值

**诊断**：
1. 检查网格质量（畸变、长宽比）
2. 检查焊缝区网格密度是否足够
3. 继续加密至 G91

**修正**：调整网格策略，重新求解

### B.2 热场不合理

**症状**：峰值温度超范围、HAZ 过宽/过窄

**诊断**：
1. 检查 Goldak 热源参数（a_f, a_r, b, c）
2. 检查热效率 η = 0.55 是否合理
3. 检查热源移动速度实现

**修正**：调整热源参数，重新标定

### B.3 边界条件问题

**症状**：释放时机不明确、位移跳变异常

**诊断**：
1. 检查约束施加位置
2. 检查释放时刻温度场
3. 检查过约束

**修正**：调整边界条件定义

### B.4 材料参数问题

**症状**：温度相关性异常、不确定性过大

**诊断**：
1. 检查材料参数单调性
2. 检查插值方法
3. 评估不确定性影响

**修正**：更新材料数据来源，重新评估
