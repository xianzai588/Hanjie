# 中文排版字体

正文使用 Noto Serif SC Regular，标题使用 Noto Sans SC Bold，图表使用 Noto Sans SC Regular。

字体来自 Google Fonts 官方仓库 `ofl/notoserifsc` 与 `ofl/notosanssc`，按字重 400/700 生成静态 TrueType 文件，保留 GB2312 常用中文、仓库正文使用字形、拉丁文、希腊字母与工程符号。字体名称已分别设置，避免 PDF 将黑体标题错误映射为宋体。

许可证为 SIL Open Font License 1.1，原文附于本目录。可随可编辑源文件分发；改写正文后重新构建时无需安装系统中文字体。
